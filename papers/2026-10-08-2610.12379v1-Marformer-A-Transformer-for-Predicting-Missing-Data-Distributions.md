# Marformer: A Transformer for Predicting Missing Data Distributions

**Authors:** Prabhav Singh, Xiheng Tom Wang, Haojun Shi, Jason Eisner
**Published:** 2026-10-08 | **arXiv:** [2610.12379v1](http://arxiv.org/abs/2610.12379v1)

## Summary
This paper introduces Marformer, a transformer-based model that predicts conditional probability distributions over missing variables given observed data—without building a full joint model. Rather than generating complete data, it directly estimates marginal distributions for each unobserved variable, making it faster than generative approaches and applicable to Bayesian decision-making problems like Value of Information calculations.

## Theoretical Background
The paper builds on two main foundations. First, **conditional probability inference**: when you observe some variables in a multivariate system, you want to predict distributions over unobserved ones—a classic problem in statistics and probabilistic inference. Second, it adapts the **masked prediction paradigm** from BERT (a transformer model trained to predict hidden words from context), applying the same attention-based refinement mechanism to probability distributions instead of text embeddings.

Classical approaches include graphical models (Bayesian networks, Markov random fields) and methods like multiple imputation or EM algorithms, which either require knowing the data-generating process or fitting full joint distributions. Marformer sidesteps this by treating each variable's marginal as a learnable entity refined through cross-attention, similar to how BERT learns contextual word representations.

## Core Contributions
1. **Direct marginal prediction framework**: Instead of sampling from or modeling $p(X_1, \ldots, X_n)$, the model predicts $p(X_i | X_{obs})$ for each missing variable independently using a single forward pass—fundamentally different from generative approaches.

2. **Transformer architecture for distributions**: Each variable gets a hidden vector representing its marginal; attention layers iteratively refine these by cross-referencing other variables' distributions. This is a novel application of attention to probabilistic inference.

3. **Model-agnostic training**: No need to specify the true data-generating process (e.g., Gaussian, Bayesian network structure) during training—the model learns the pattern from data alone.

4. **Empirical superiority**: Outperforms classical methods even when those methods are given the ground-truth model family and priors, on both synthetic benchmarks (Bayesian networks, multivariate Gaussians, structured annotations) and real annotation data.

## Connections to Other Work
- **[[BERT]]**: Architectural inspiration—masked prediction and iterative refinement via attention.
- **Generative models** (VAEs, diffusion models, autoregressive): Marformer avoids the computational and memory overhead of modeling the full joint; trades expressiveness for speed.
- **Missing data imputation** (EM, multiple imputation, KNN): Classical statistical approaches; Marformer is faster and doesn't require model specification.
- **Probabilistic graphical models**: Unlike explicit structure learning, this method learns distributions implicitly through attention weights.
- **Value of Information (VOI) and Bayesian decision theory**: The downstream application—computing optimal decisions under uncertainty and the value of acquiring more data.

## Practical Applications
1. **Medical diagnosis under incomplete tests**: Predict the probability distribution over undiagnosed conditions given observed symptoms and test results, guiding which additional tests to order.

2. **Survey and annotation workflows**: In data labeling pipelines, predict the distribution of missing labels for documents/images given partial annotations, informing which items to label next (active learning).

3. **Financial portfolio valuation**: Given partial market data (some asset prices, volumes observed; others missing), estimate conditional price distributions for portfolio risk assessment without assuming a specific pricing model.

4. **Sensor networks and IoT**: In sensor systems with intermittent failures or dropouts, predict the distribution of missing sensor readings to inform control decisions.

5. **Customer analytics and CRM**: Estimate missing customer attributes (e.g., income, preferences) from partial observations, guiding targeted marketing decisions.

## Product & Startup Ideas
1. **Intelligent Survey & Data Collection Platform**: SaaS tool that uses Marformer to predict the value of collecting each additional data point in user surveys, recommending which questions to ask next to maximize decision quality while minimizing respondent burden.

2. **Adaptive Medical Diagnostic Assistant**: Clinical decision-support system that suggests the highest-value tests to order by predicting conditional distributions of diagnoses given current symptoms/test results—reduces unnecessary testing.

3. **Active Learning Labeling Service**: Automated data annotation platform that uses Marformer to identify which unlabeled items, if labeled, would most improve downstream ML models (maximizes ROI per labeling dollar spent).

4. **Real-time Financial Risk Dashboard**: Institutional trading/risk management product that ingests partial market data and outputs conditional distributions of missing asset prices/volatilities, enabling faster portfolio rebalancing decisions.

5. **IoT Anomaly Detection & Prediction**: Enterprise IoT platform that handles sensor dropouts gracefully by predicting conditional distributions of missing sensor measurements, allowing real-time alerting without data imputation latency.

## Technical Limitations
1. **Marginal independence assumption**: Predicting each variable's marginal independently (via separate hidden vectors) may miss strong dependencies between missing variables; the model learns correlations only through attention, which could be fragile for highly coupled systems.

2. **Scalability to high dimensions**: No evaluation on datasets with thousands of variables; attention computation scales as $O(n^2)$ in the number of variables, limiting applicability to very wide datasets.

3. **Limited real-world evaluation**: Only one real dataset (annotation) tested; synthetic experiments may not capture distributional mismatches (e.g., heavy-tailed data, structural breaks) in production.

4. **Distribution mismatch**: Model trained on one missing-data distribution might perform poorly when test data has a different sparsity pattern or missingness mechanism (e.g., MCAR vs. MNAR).

5. **No uncertainty quantification**: The model outputs point predictions of marginals; no confidence intervals or calibration analysis—important for decision-making under uncertainty.

6. **Comparison fairness**: Classical baselines (EM, imputation) may be suboptimally tuned; no ablation studies on architecture choices (e.g., why separate hidden vectors per variable?).

## Open Questions
1. **How does performance degrade with different missingness patterns?** E.g., if training assumes uniformly random missingness but test data has systematic (non-random) missingness—does the model generalize?

2. **Can the model reliably estimate tail probabilities?** Medical and finance applications often care about extreme events; standard training may underestimate rare outcomes.

3. **What is the sample complexity?** How much training data does Marformer need vs. classical methods for comparable performance in high-dimensional settings?

4. **Can you extract interpretable structure from attention weights?** Do learned attention patterns recover the true conditional independence graph (like in graphical models)?

5. **How well does it work with mixed data types?** Evaluation uses discrete networks and continuous Gaussians separately; real data mixes continuous, categorical, and ordinal variables.

6. **Does the model benefit from adversarial or domain-specific pretraining?** Could it be pretrained on large synthetic or transfer datasets, then fine-tuned for specific domains?

## Key Takeaway
Transformers can directly predict marginal distributions of missing data faster and without model assumptions than classical and generative methods.
