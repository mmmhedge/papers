# Don't Drop the BATON: Long-Horizon Robot Manipulation via Agentic Subtask Exploration and Transition-aware Memory

**Authors:** Bingxin Xu, Yuzhang Shang, Emilio Ferrara
**Published:** 2026-08-17 | **arXiv:** [2608.16889v1](http://arxiv.org/abs/2608.16889v1)

## Summary
This paper addresses the challenge of long-horizon robot manipulation — tasks requiring many sequential contact-heavy skills — by decomposing them into independently explored subtasks coordinated by an LLM agent with transition-aware memory. The key insight is that exploring whole multi-stage tasks is exponentially expensive (cost scales as T^K for K stages), but exploring individual subtasks and composing them is much cheaper (cost becomes T*K), if you handle the transitions between subtasks correctly. On a benchmark called RoboMemArena, BATON achieves 11.6% higher task success than prior state-of-the-art.

## Theoretical Background
The paper builds on recent work combining [[Vision-Language-Action Models]] (VLA models — neural networks that take images and natural language instructions and output robot actions) with LLM-based planning agents. Prior work showed that freezing a VLA and letting an LLM agent plan in language, invoke the VLA only for contact-rich manipulation segments, and write task memory in natural language was promising. However, this approach breaks at scale: (1) test-time exploration cost explodes exponentially with task length, and (2) there is no explicit representation of how one subtask's output state constrains the next subtask's input requirements. The paper addresses both issues through hierarchical decomposition and transition-aware state verification.

## Core Contributions
1. **Subtask-level exploration strategy**: Instead of exploring full K-stage trajectories at test time, BATON explores each stage independently in isolation, reducing search cost from exponential (T^K) to linear (T*K) and localizing failure attribution.

2. **Transition-aware memory system** with three mechanisms:
   - **Verifier agent**: Uses wrist camera observation to confirm scene readiness before invoking the VLA (entry condition enforcement)
   - **Handoff transition**: Corrects state disturbances from predecessor subtask residue before moving to successor
   - **Lookahead transition**: Selects strategy variants whose outcomes the downstream subtask can actually use (exit condition matching)

3. **Parameter-free adaptation**: All composition and verification happens in language/symbolic space — no fine-tuning of neural networks required.

## Connections to Other Work
This work relates to [[hierarchical reinforcement learning]] (learning policies at multiple levels of abstraction), [[task decomposition]], and [[in-context learning]] with LLMs. It differs from pure behavioral cloning by adding explicit transition constraints and from standard RL by freezing learned policies and orchestrating them symbolically. The approach echoes ideas from [[classical task planning]] (using symbolic representations and verifiers) but grounds them in modern vision-language models rather than hand-coded primitives. The memory mechanism is reminiscent of [[retrieval-augmented generation]] but applied to motor control.

## Practical Applications
1. **Manufacturing assembly lines**: Complex multi-step assembly (e.g., inserting parts, fastening, alignment checks) where subtask reuse across similar tasks reduces engineering effort.
2. **Household robotics**: Sequenced cleaning, organization, and meal prep tasks where individual skill modules (grasping, wiping, placing) are explored once and recombined.
3. **Medical/surgical assistance**: Sterile multi-stage procedures (e.g., suturing, catheter placement) where state verification between steps is critical for safety.
4. **Warehouse automation**: Picking → packing → sealing workflows where transition states matter (e.g., box must be open before item placement, sealed before tape).
5. **Teleoperation systems with weak supervision**: Operators demonstrate subtasks once; the agent composes and verifies transitions autonomously.

## Product & Startup Ideas
1. **RoboCompose**: A SaaS platform where manufacturers upload video demonstrations of individual subtasks; the system decomposes, learns, and auto-generates composable task sequences for collaborative robots. Revenue: per-task licensing + integration fees.

2. **Transition-Safe Robot OS**: A middleware layer that wraps any VLA model with automatic state verification and handoff correction, marketed to enterprises running heterogeneous robot fleets. Revenue: software licensing + support contracts.

3. **Subtask Marketplace**: A crowdsourced library of verified short-horizon robot skills (e.g., "grasp mug handle," "open drawer," "wipe surface") with transition metadata. Companies buy and compose these rather than training from scratch. Revenue: marketplace commission + premium skill curation.

4. **Robotic Process Automation 2.0**: Extend RPA (currently software-only) to physical tasks using BATON's decomposition; automate warehouse and manufacturing workflows without custom engineering per site. Revenue: per-site deployment + per-task execution fees.

5. **Safety-Critical Robot Trainer**: A B2B tool for regulated industries (pharma, food, surgery) that enforces transition verification and generates audit logs proving each subtask succeeded before the next began. Revenue: compliance certification + audit trail licensing.

## Technical Limitations
1. **Subtask boundary assumption**: The approach assumes tasks naturally decompose into clean, reusable stages. Many real tasks have implicit dependencies that are hard to formalize (e.g., glue must dry before the next step). Manual segmentation burden remains.

2. **VLA competence bottleneck**: The method still relies on a pre-trained VLA for contact-rich segments. If the VLA cannot perform a single subtask well, decomposition won't help. No mechanism to improve the base VLA itself.

3. **Transition verification cost**: The verifier agent adds observation overhead (wrist camera checks, scene validation). In fast-paced or partially observable environments, this could introduce latency or miss valid states.

4. **State diversity in isolation**: Exploring subtask *i* in isolation assumes the state distribution matches what comes after subtask *i-1* in the full task. If predecessor residue is highly variable, isolated exploration may not capture the true complexity.

5. **Scalability to very long horizons**: While T*K beats T^K, a 20-stage task with T=10 episodes per stage still requires 200 episodes of real robot interaction. This is non-trivial for physical systems.

6. **No generalization guarantees**: The method is evaluated on one benchmark (RoboMemArena). Transferability to novel task structures or robot morphologies is unclear.

## Open Questions
1. **Automatic subtask segmentation**: Can the system learn where to split a long task into subtasks, rather than relying on manual specification?

2. **Transition learning from fewer examples**: How many demonstrations of each subtask boundary are needed to learn robust entry/exit conditions? Can meta-learning help?

3. **Compositional generalization**: Can subtasks learned for one task sequence transfer to entirely different tasks with only a few new examples?

4. **Real robot validation**: The paper is on RoboMemArena (likely a simulator). How do results hold on real hardware with noise, dynamics mismatch, and wear?

5. **Scaling beyond VLA inversion**: As VLAs improve, could the entire system be trained end-to-end while preserving the transition-aware decomposition structure?

6. **Human-in-the-loop refinement**: Can a human operator easily inspect and correct transitions when BATON fails, without retraining?

## Key Takeaway
Decompose long-horizon robot tasks into independently explored subtasks with explicit transition verification, reducing exploration cost from exponential to linear.
