# Now everyone can put data to work

**Source:** OpenAI
**Published:** 2026-09-10 | **Link:** [https://openai.com/index/put-data-to-work](https://openai.com/index/put-data-to-work)

## Summary
OpenAI has released a Data agent feature within ChatGPT Work that lets users connect company data, extract insights, and create interactive dashboards using natural language. This democratizes data analysis by removing the need for specialized technical skills or custom code.

## Key Points
- A new "Data agent" feature integrated into ChatGPT Work enables non-technical users to analyze business data
- Users can connect data sources, query them conversationally, and generate visual dashboards without writing SQL or Python
- The agent interprets natural language requests and translates them into data operations
- Designed to make data exploration and insight generation accessible to broader organizational audiences

## Why It Matters
This lowers the barrier to enterprise data utilization. Organizations can now empower all employees to ask questions of their data and derive insights independently, rather than waiting for data teams or analysts. It also shows how LLM-based agents are moving from research prototypes into production tools that reshape knowledge work.

## Connections to Other Work
Relates to broader trends in [[agents]] making complex tasks accessible via conversational interfaces. Similar to semantic search and [[large-language-models]] applied to structured data retrieval. Connects to the evolution of BI tools from specialist software toward natural-language frontends.

## Key Takeaway
LLM agents now let non-technical workers query company data and build dashboards via conversation.
