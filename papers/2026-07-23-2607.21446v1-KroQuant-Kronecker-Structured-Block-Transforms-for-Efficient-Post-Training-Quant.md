# KroQuant: Kronecker-Structured Block Transforms for Efficient Post-Training Quantization of Diffusion Transformers

**Authors:** Yann Bouquet, Alireza Khodamoradi, Kristof Denolf, Mathieu Salzmann
**Published:** 2026-07-23 | **arXiv:** [2607.21446v1](http://arxiv.org/abs/2607.21446v1)

## Summary
This paper presents KroQuant, a method to compress diffusion transformers (neural networks that generate images by progressively removing noise) to 4-bit precision without severely degrading image quality. The key insight is using Kronecker-structured transforms—mathematically efficient linear transformations based on tensor products—to handle outliers in activation values during quantization, while keeping the computational cost low enough to run during image generation.

## Theoretical Background
Post-training quantization (PTQ) reduces neural network precision from 32-bit floats to lower bit-widths (here, 4 bits) to save memory and speed up inference. The core challenge: when you quantize activations—intermediate values flowing through layers—outliers (unusually large values) get clamped or distorted in 4-bit formats, breaking the network's behavior.

Prior work uses invertible linear transforms to rescale activations before quantization. SmoothQuant applies simple per-channel scaling (fast but crude); learned full-matrix transforms (dense $d \times d$ operations) give better results but are computationally prohibitive at inference time. Hadamard transforms (structured matrices based on recursively combining +1 and -1 values) offer a middle ground but require large block sizes.

This paper builds on Kronecker products—a way to construct large matrices from smaller ones by tensor multiplication—to create transforms that are both learnable and computationally efficient. The Kronecker structure naturally decomposes into small matrix multiplications that modern GPUs (via tensor cores) execute very fast.

## Core Contributions
1. **KroQuant transform**: A learned, Kronecker-factored invertible transform applied block-wise (32 elements per block) to activations, storing <50% of parameters versus per-channel scaling.
2. **GPU efficiency**: The block-local Kronecker structure maps to small tensor-core operations; measured ~14% speedup over SmoothQuant on MI350 hardware.
3. **Offline calibration**: Combines the online transform with LoRaQ (low-rank adaptive quantization) to absorb residual per-weight errors without additional runtime cost.
4. **Empirical validation**: Tested on recent large diffusion transformers (PixArt-Σ, SANA, FLUX.1-schnell) at W4A4 (MXFP4e2 format); outperforms SVDQuant and LoRaQ on standard image-quality benchmarks (MJHQ-30K, SDCI).

## Connections to Other Work
Builds directly on [[SmoothQuant]] (per-channel activation rescaling) and extends it with structured transforms. Compares against [[SVDQuant]] and [[LoRaQ]] (low-rank weight calibration). The Kronecker factorization connects to broader work on structured neural network compression and tensor decomposition methods. Related to quantization challenges in [[Transformers]] more broadly, though specialized here for diffusion models (which differ from LLMs in how activations behave across denoising steps).

## Practical Applications
1. **Mobile/edge image generation**: Running FLUX or similar on phones/edge devices by reducing model size 8× while maintaining quality.
2. **Inference cost reduction**: Speeding up batch image generation in cloud services (e.g., Stability AI, Midjourney competitors) to cut GPU time and energy.
3. **Latency-critical applications**: Real-time image editing or interactive design tools that require sub-second latency.
4. **On-device creative tools**: Embedding diffusion models in design software or AR apps without downloading gigabyte-scale models.

## Technical Limitations
1. **Block size fixed at 32 elements**: May not be optimal for all layer widths or hardware; requires problem-specific tuning.
2. **Hardware specificity**: Speedups measured on MI350 (AMD GPU); generalization to other accelerators (H100, TPU) not demonstrated.
3. **Diffusion-specific**: Method tested only on diffusion transformers; unclear if it transfers to LLMs or other domains.
4. **MXFP4e2 format**: Non-standard 4-bit format; requires custom kernel support, limiting adoption.
5. **Online-only evaluation**: No comparison on downstream tasks (e.g., model accuracy for style transfer); only perceptual image quality metrics.
6. **Calibration data dependency**: Offline calibration requires representative dataset; sensitivity to distribution shift not thoroughly analyzed.

## Open Questions
1. Does KroQuant generalize to lower bit-widths (2-3 bits) or mixed-precision schemes (e.g., W2A4)?
2. How sensitive is the method to calibration dataset size and quality? Can it work with minimal or synthetic calibration data?
3. Can the Kronecker structure be extended to attention weights and layer norms, not just linear layers?
4. How does performance degrade when the learned transform is applied to out-of-distribution inputs at inference time?
5. What is the optimal block size as a function of layer dimension, and can it be learned or adapted per-layer?
6. Does the method work on non-diffusion transformer architectures (LLMs, vision transformers) without retraining?

## Key Takeaway
Kronecker-structured quantization makes 4-bit diffusion transformers fast and accurate by replacing dense transforms with efficient block-wise tensor operations.
