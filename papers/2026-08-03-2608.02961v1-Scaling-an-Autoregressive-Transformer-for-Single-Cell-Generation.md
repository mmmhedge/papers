# Scaling an Autoregressive Transformer for Single-Cell Generation

**Authors:** Aleksandr Sharipov, Yusif Mukhtarov, Igor Molybog
**Published:** 2026-08-03 | **arXiv:** [2608.02961v1](http://arxiv.org/abs/2608.02961v1)

## Summary
We study a self-supervised generation task for single-cell gene expression vectors: given a set of vectors from a cell type, we aim to generate additional gene expression vectors of that cell type. For this task we characterize both the biological fidelity of the generated gene expression vectors and the scaling behavior of the pretraining loss. The model is a causal transformer paired with a learned quantized VAE tokenizer, trained with a cross-entropy loss.

## Core Contributions
1. To evaluate the model, we condition it on held-out gene expression vectors of a cell type and generate vectors of gene expression, comparing the resulting distribution over gene expression vectors to the ground truth distribution of that cell type.
2. We study the scaling properties of the proposed architecture by varying the number of trained parameters and the amount of training data.
3. We study a self-supervised generation task for single-cell gene expression vectors: given a set of vectors from a cell type, we aim to generate additional gene expression vectors of that cell type.
