# Agent Policy-Value Audit: Separating Transition Composition from Event Selection in Financial LLM Agents

**Authors:**  Mingyang,  Chen,  Yida,  Xu,  Huiwen et al.
**Published:** 2026-10-02 | **arXiv:** [2610.04040v1](http://arxiv.org/abs/2610.04040v1)

## Summary
This paper reveals a critical flaw in how financial AI agents are typically evaluated: standard performance tests conflate two distinct sources of profit — the agent's ability to time trades correctly (event selection) versus passive exposure to market drift (transition composition). The authors propose the Agent Policy-Value Audit, a statistical technique that isolates selection skill by holding an agent's action patterns fixed while randomly reassigning them across different market events. Applied to real earnings-event data, their audit shows that a deployed LLM agent's apparent +15.2 basis points/event profit is actually -10.6 bps of selection skill masked by +25.8 bps of passive composition — meaning the agent adds no real value.

## Theoretical Background
Financial performance evaluation traditionally relies on paired hypothesis tests that compare an agent's returns to zero, assuming any positive realized return indicates skill. This framework implicitly assumes that the agent's transaction patterns (e.g., flat-to-long position changes) are independent of market conditions. The paper builds on causal inference and experimental design principles: to isolate selection skill, you must separate what an agent *does* (its action distribution) from *when* it does it (its event timing). The core insight is Bayesian: an upward-drifting market can make even random event selection profitable if an agent is structurally biased toward bullish trades. The audit extends this by treating observed transitions as a "treatment assignment" and measuring the counterfactual payoff under random shuffling, similar to permutation testing in statistics.

## Core Contributions
1. **Formal decomposition framework**: Decomposes agent deployment value into composition benchmark (payoff from observed transitions applied randomly) and selection value (actual payoff minus benchmark), providing a causal attribution.
2. **Empirical validation of type-I error reduction**: Demonstrates that standard paired tests falsely attribute passive exposure to skill in 11.6% of no-skill simulations, while the audit-based method reduces false positives to 5.3% — a clinically significant improvement.
3. **Retrospective audit of real agent**: Applied to 723 earnings events at 44 U.S. consumer firms, showing that a deployed LLM agent's +15.2 bps gross profit is entirely explained by composition bias; its actual selection skill is -10.6 bps.
4. **Practical audit methodology**: Develops a computationally tractable procedure for retrospective decomposition that does not require in-sample retraining or access to agent internals.

## Practical Applications
1. **Vendor evaluation in institutional trading**: Buy-side and sell-side firms can use the audit to rigorously evaluate third-party algorithmic trading systems or AI-driven execution algorithms before committing capital.
2. **Regulatory risk assessment**: Compliance and risk teams can audit deployed fintech agents to detect whether performance is genuine alpha or spurious statistical artifact, reducing reputational and regulatory risk.
3. **Portfolio manager due diligence**: Hedge funds and asset managers can apply the audit retroactively to assess whether in-house LLM-based trading strategies actually improve over passive/random strategies.
4. **Earnings-season hedge optimization**: Trading desks can use event-selection decomposition to decide whether to allocate capital to earnings-driven strategies or revert to simpler, more robust approaches.
5. **Machine-learning model monitoring**: Financial institutions can continuously apply the audit to monitor whether production agents maintain true selection skill or whether past performance was composition-driven luck.

## Technical Limitations
1. **Eligibility constraints**: The audit assumes eligibility rules (which events can receive which transitions) are well-defined and don't change over time; violation of this assumption (e.g., regime shifts in what types of trades are feasible) could invalidate the benchmark.
2. **Dependence on action-change granularity**: Results hinge on how transitions are discretized (e.g., flat-to-long vs. long-to-long); overly coarse discretization may mask selection skill operating at fine-grained levels.
3. **Assumes transition distribution is independent of event quality**: If the agent *learns* to apply certain transitions more often to higher-signal events (without explicit conditioning), the random shuffling of fixed transitions may underestimate selection value.
4. **Limited to retrospective analysis**: The method requires historical data; it cannot be used prospectively to detect emerging agent drift or to guide real-time tuning.
5. **Event pool specificity**: Results are specific to the earnings-event setting; generalization to other event types (M&A, FDA approvals, macroeconomic announcements) is untested and may face different composition biases.
6. **No handling of execution-dependent payoffs**: The audit assumes payoff is solely a function of event timing and transition type; it cannot account for agent's impact on market impact, slippage, or other endogenous costs.

## Open Questions
1. **How does the audit scale to multi-dimensional action spaces?** The paper uses discrete ordered transitions; how would the method extend to continuous position sizing or multi-asset portfolios?
2. **Can we bound selection value non-asymptotically?** The paper uses permutation testing; are there concentration inequalities that would allow formal confidence intervals on the decomposition?
3. **Does transition distribution adapt to regime changes?** In a real deployment, does the agent's learned transition distribution shift in ways that preserve selection skill across market regimes, or does skill decay?
4. **How sensitive is the audit to event pool definition?** If the event set is misspecified (e.g., including false positives or missing true earnings dates), how much does this corrupt the composition benchmark?
5. **Can we detect *dynamic* selection skill?** The current audit treats transition probabilities as static; could a refined method detect whether the agent conditions transitions on event-level features (news sentiment, volatility, etc.) in a skill-generating way?
6. **How do institutional constraints affect audit validity?** In practice, trading desks face position limits, leverage constraints, and liquidity constraints; how do these edge cases change the counterfactual benchmark?

## Key Takeaway
LLM trading agents often appear profitable only because they repeatedly make bullish trades in rising markets; isolating their true selection skill requires auditing them against random trade timing, not just comparing returns to zero.
