# Analytic Planning under Uncertainty with Moment Closure

**Authors:** Shishir Sharma, Doina Precup
**Published:** 2026-08-03 | **arXiv:** [2608.02519v1](http://arxiv.org/abs/2608.02519v1)

## Summary
This paper develops a method for planning under uncertainty in reinforcement learning by analytically propagating probability distributions through the Bellman backup—rather than relying on sampling or ignoring uncertainty entirely. The key insight is a "compatibility principle" that lets the uncertainty (mean and covariance) be computed in closed form when using Gaussian transitions and radial-basis value functions, reducing variance and improving robustness in continuous control tasks.

## Theoretical Background
Model-based reinforcement learning aims to learn a model of the environment's dynamics and use it for planning. In stochastic environments, the agent must reason about uncertainty in future states. Traditionally, this meant either: (1) sampling trajectories, which introduces high variance in learning targets, or (2) using point estimates (ignoring covariance), which wastes information about confidence. The Bellman backup—the core recursive update rule in RL—computes expected value as the reward plus discounted expected value of the next state. This paper asks: can we compute this expectation analytically over the full state distribution?

The paper builds on two pillars: quadratic action-value functions (a parameterization that captures structure in value estimation) and moment closure techniques (methods from physics and control theory that approximate intractable expectations using low-order statistics—here, mean and covariance).

## Core Contributions
1. **Compatibility principle**: A theoretical result showing when the Bellman expectation becomes analytic in distributional moments. Specifically, when the value function class is compatible with the transition model's structure, you can compute E[V(s')] from just μ and Σ of p(s').
2. **Concrete instantiation**: A closed-form Bellman backup pairing Gaussian transition models with radial-basis value functions, yielding an algorithm that tracks both predicted mean and covariance without sampling.
3. **Empirical validation**: Demonstration that this reduces target variance and improves calibration (confidence estimates are better-aligned with actual error) in continuous control under stochastic observations.

## Connections to Other Work
This work sits at the intersection of distributional RL (methods that track full return distributions rather than point estimates) and uncertainty quantification in model-based RL. It relates to:
- **Uncertainty-aware planning**: Prior work often used ensemble methods or variational inference to approximate predictive distributions; this offers an alternative via analytic propagation.
- **Policy gradient and actor-critic methods**: The quadratic parameterization connects to natural gradient methods and trust region approaches that implicitly exploit structure.
- **Moment matching techniques**: The compatibility principle echoes ideas from [[Probabilistic Inference]] and extended Kalman filters, which also close expectations via moment assumptions.
- **Risk-sensitive RL**: By preserving covariance, the method enables risk-aware objectives (e.g., minimizing variance) without extra computational overhead.

3. **Financial portfolio optimization**: Continuous rebalancing under market uncertainty, where covariance tracking is essential for risk control.

## Technical Limitations
1. **Gaussian assumption**: Transition models must be (approximately) Gaussian; multimodal or heavy-tailed dynamics will violate the moment-closure approximation, degrading performance.
2. **Radial-basis value functions**: The closed form relies on this specific function class; extending to neural network value functions likely requires approximations, defeating the analytic advantage.
3. **Scalability to high dimensions**: Storing and propagating full covariance matrices Σ is O(d²) in state dimension d; for very high-dimensional state spaces, dimensionality reduction is necessary.
4. **Limited to continuous control**: The derivation assumes continuous action spaces; extension to discrete actions unclear.
5. **Short planning horizons**: Covariance typically grows with time-steps (uncertainty compounds); long-horizon planning may require additional approximations or lose the calibration benefit.
6. **Model bias**: If the learned transition model is biased, propagating its moments faithfully still yields biased predictions; the method assumes a reasonably accurate model.

## Open Questions
1. How does performance degrade gracefully when the Gaussian or radial-basis assumptions are violated? Can adaptive moment closure (higher-order cumulants) improve robustness?
2. Can the compatibility principle extend to other value function classes (e.g., polynomial, neural networks with particular architectures)?
3. How does the method compare to ensemble planning and variational inference baselines in very high-dimensional tasks (e.g., image-based control)?
4. Can you use the covariance estimate to actively improve the model (e.g., exploration bonuses driven by high epistemic uncertainty)?
5. Does the approach work with learned reward functions that also carry uncertainty?

## Key Takeaway
Closed-form planning under uncertainty is tractable when transition and value models are compatible; here, Gaussians plus radial-basis functions yield analytical covariance propagation.
