# Spiking Neural Network Predicting Sequence of the External Worlds States in Model-Based Reinforcement Learning

**Authors:** Mikhail Kiselev
**Published:** 2026-09-23 | **arXiv:** [2609.27459v1](http://arxiv.org/abs/2609.27459v1)

## Summary
This paper builds a spiking neural network (SNN)—a biologically-inspired neural model where neurons communicate via discrete electrical pulses rather than continuous signals—to predict sequences of world states in model-based reinforcement learning. Instead of learning a full world dynamics model, it chains together a trained single-step predictor using entirely spiking mechanisms, and tests this approach on the classic Atari Pong game. The work is significant because SNNs are far more energy-efficient than standard neural networks, potentially enabling RL agents to run on neuromorphic hardware.

## Theoretical Background
Model-based reinforcement learning (RL) trains agents to maximize rewards by learning an explicit model of how the environment responds to actions. Traditional approaches use standard neural networks; this paper uses spiking neural networks, which mimic biological neurons by firing discrete spikes at discrete time steps rather than outputting continuous values. Prior work has explored SNNs for control tasks, but applying them to multi-step world state prediction—chaining predictions forward in time—is less established. The paper builds on the concept of world models (learned representations of environment dynamics) but implements the prediction chain using purely spiking mechanisms rather than continuous approximators.

## Core Contributions
1. A spiking neural network architecture designed specifically to chain single-step state predictions into multi-step sequences without learning a monolithic world dynamics model.
2. A demonstration that all necessary computational mechanisms for sequential prediction can be implemented as spiking neuron ensembles (no hybrid continuous-spiking layers).
3. Empirical validation on Atari Pong, showing the approach can work on a standard RL benchmark.

## Connections to Other Work
This relates to broader work on [[model-based reinforcement learning]], [[world models]], and neuromorphic computing. It differs from standard approaches like planning with learned models (e.g., MuZero, Dreamer) by prioritizing biological plausibility and energy efficiency via spikes. The work sits at the intersection of computational neuroscience and RL—similar to research on biologically-plausible learning rules in neural networks, but focused on inference rather than training.

## Practical Applications
- **Neuromorphic robotics:** Deploying RL agents on low-power neuromorphic chips (Intel Loihi, IBM TrueNorth) for real-time control without constant power consumption.
- **Autonomous agents in edge devices:** Mobile robots or IoT systems with strict power budgets that still need to plan ahead.
- **Brain-computer interfaces:** Spiking models align better with neural recording data, enabling more interpretable closed-loop neurotech systems.
- **Space and satellite systems:** Missions where power is extremely limited but RL-based decision-making is needed.

4. **Closed-loop bioelectronic devices:** Implantable or wearable neurotech that uses spiking RL for adaptive stimulation, based on the interpretability of spike-based reasoning.

## Technical Limitations
- **Limited scalability evidence:** Only tested on Pong; no results on high-dimensional or complex environments (e.g., visual RL with large image inputs).
- **Conversion complexity:** Converting trained standard RL models to spiking versions or training SNNs end-to-end remains non-trivial; the paper doesn't detail training procedures.
- **Temporal dynamics:** Spiking networks inherently have discrete time steps; handling variable-latency decisions or continuous control may be awkward.
- **Comparison baseline:** No direct comparison to standard neural network versions on the same task (no wall-clock time, energy, or accuracy trade-off analysis).
- **Hardware dependence:** Benefits only accrue if actual neuromorphic hardware is available; on CPUs/GPUs, SNNs are typically slower than standard networks.

## Open Questions
- How does prediction accuracy degrade when chaining many spiking steps? Is there error accumulation?
- Can end-to-end training of the spiking architecture match or exceed standard approaches, or is it limited to inference only?
- How sensitive is performance to the number of neurons and spike thresholds in each ensemble?
- Does this scale to high-dimensional state spaces (e.g., high-resolution images) or continuous control tasks?
- What is the actual energy consumption on real neuromorphic hardware versus theoretical savings?

## Key Takeaway
Spiking neural networks can chain state predictions for RL agents, promising major energy savings on specialized neuromorphic hardware.
