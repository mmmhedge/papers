# An Evaluation Framework for Structured Audio Captions Validated by Controlled Perturbations

**Authors:** Liang-Yuan Wu, Sripathi Sridhar, Mark Cartwright, Magdalena Fuentes
**Published:** 2026-07-23 | **arXiv:** [2607.21424v1](http://arxiv.org/abs/2607.21424v1)

## Summary
This paper proposes a new evaluation framework for assessing automatically generated audio captions that go beyond simple text descriptions. The authors argue that modern audio captioning systems now produce structured outputs (with separate components for acoustic properties, semantic descriptions, measurements, etc.), but existing evaluation metrics are designed for flat text and miss this complexity. They introduce a multi-axis framework combining LLM-based semantic evaluation with computational metrics for acoustic accuracy, and validate it using controlled error injection.

## Theoretical Background
Automated audio captioning (AAC) extends the well-studied field of image captioning to the audio domain — systems must convert sound into natural language descriptions. Traditional evaluation metrics for captioning (like BLEU, METEOR, CIDEr) compare generated text to reference captions word-by-word or phrase-by-phrase, treating output as a monolithic sequence. Recent work has shifted toward structured representations that explicitly separate different properties (e.g., sound types vs. acoustic characteristics vs. spatial information), similar to how structured knowledge representations organize facts. Large Language Models (LLMs) — neural networks trained on vast text corpora that can follow instructions and judge semantic quality — have become popular as "judges" for evaluating generated text because they capture nuance that surface-level metrics miss. The paper builds on AudioCards, an existing dataset of structured audio descriptions.

## Core Contributions
1. **Multi-axis evaluation framework**: Rather than a single holistic score, the framework evaluates structured captions across five independent dimensions: tag-sets (categorical sound labels), free-form descriptions, logical reasoning steps, numeric measurements (e.g., duration, frequency), and spectral profiles (acoustic characteristics).
2. **Hybrid evaluation approach**: Combines LLM judges (for semantic fidelity) with deterministic computational metrics (for acoustic precision), recognizing that different axis types require different evaluation strategies.
3. **Controlled perturbation validation protocol**: Instead of assuming the metric is correct, the authors inject typed, graded errors into ground-truth annotations (e.g., replacing correct tags with incorrect ones, adding paraphrases, introducing acoustic distortions) and verify that the framework reliably detects real problems while accepting minor variations. This is a rigorous sanity-check.
4. **Empirical validation**: Demonstrates that the framework distinguishes between meaning-preserving paraphrases (which should not harm scores) and genuine corruptions (which should).

## Practical Applications
1. **Audio description systems for accessibility**: Automatically generate structured, detailed descriptions of audio content for visually impaired users; the framework ensures captions capture both semantic and acoustic details accurately.
2. **Podcast/audiobook indexing and search**: Structure-aware captioning and evaluation enables better searchability (e.g., "find segments with jazz music and speech together") and quality assurance for commercial platforms.
3. **Music production and sound design**: Help producers evaluate automatically generated technical descriptions of their audio (frequency ranges, timbre, dynamics) for documentation or AI-assisted mixing.
4. **Audio content moderation**: Assess whether automatically generated captions of flagged audio match ground-truth properties, ensuring moderation systems aren't fooled by acoustic tricks.
5. **Multilingual audio content creation**: Generate structured captions in one language/format, then validate consistency across translations or formats before publishing.

## Product & Startup Ideas
1. **AudioStudio Pro**: A DAW plugin / cloud service that auto-generates searchable structured captions for audio files using the proposed framework; charges per-file or subscription. Markets to podcasters, audiobook producers, and music libraries.
2. **AccessAudio**: Automated audio description platform for video/streaming services that produces structured, validated captions; integrates directly with production pipelines and flags low-confidence outputs.
3. **SoundArchive API**: B2B service for large audio repositories (libraries, archives, broadcasters) that ingests audio and returns structured, quality-assured metadata and descriptions, with a dashboard showing evaluation scores across all axes.
4. **AudioQA**: Automated quality assurance tool for audio production teams — analyze batches of audio and their captions, flag inconsistencies or errors, and report on evaluation metrics; white-label for studios.
5. **Captions-as-a-Service (CaaS)**: Freemium SaaS platform where users upload audio, get structured captions generated and evaluated in real-time, with a simple UI for correction and export in multiple formats.

## Technical Limitations
1. **LLM judge variability**: LLM-based evaluation depends on model quality and prompt engineering; results may vary across different LLM versions and may not be reproducible without fixing the model version.
2. **Dataset-specific design**: The framework is validated on AudioCards; generalization to other audio domains (e.g., music, environmental sounds, speech) or different structured formats is unclear.
3. **Acoustic metric limitations**: Deterministic metrics for spectral profiles require clear ground-truth acoustic features; in noisy or ambiguous cases, they may not capture perceptual relevance.
4. **Perturbation protocol assumptions**: The controlled error injection assumes errors can be typed and graded in isolation; in practice, errors often interact (e.g., one wrong tag might make a description less coherent).
5. **Scalability and cost**: LLM-based evaluation is expensive and slow compared to surface-level metrics; not practical for evaluating millions of captions without significant infrastructure.
6. **Multimodal grounding**: The framework doesn't directly compare captions to the audio itself — it only evaluates against reference captions. Systematic audio-caption misalignment could go undetected.

## Open Questions
1. **Generalization**: How does the framework perform on audio domains outside AudioCards (e.g., music, technical recordings, speech-heavy content)? Do the five axes need adjustment?
2. **LLM judge scaling**: Can cheaper or smaller LLMs serve as judges without significant degradation? What is the minimum model size?
3. **Human correlation**: How well do the evaluation scores correlate with human judgments? Are there axes where the framework disagrees systematically with humans?
4. **Error recovery**: Can the framework be extended to suggest corrections (not just detect errors)? Can it rank multiple candidate captions?
5. **Interactive evaluation**: Can the framework support incremental evaluation (e.g., as captions are generated or edited) rather than batch validation?
6. **Cross-lingual structured captions**: How robust is the framework when captions and ground truth are in different languages?

## Key Takeaway
A new evaluation system for structured audio captions uses multiple independent metrics and validates reliability through controlled error injection testing.
