# ADPTNet: Adaptive with Prescriptive Timescales Non-Linear SSM for Sequence Modelling

**Authors:** Matei-Ioan Stan, Oliver Rhodes
**Published:** 2026-09-27 | **arXiv:** [2609.34034v1](http://arxiv.org/abs/2609.34034v1)

## Summary
ADPTNet is a neuromorphic neural architecture that combines non-linear recurrence with data-adaptive long-range memory and GPU parallelization, addressing the energy inefficiency of Transformers. The key innovation is using fixed timescales (inspired by auditory cortex biology) with linear attention and Riemannian optimization to achieve both complex reasoning and computational efficiency — demonstrating competitive or superior performance on sequence tasks while using fewer parameters.

## Theoretical Background
This work builds on state-space models (SSMs) — linear recurrent architectures like [[Mamba]] that efficiently capture long-range dependencies — and the broader neuromorphic computing goal of mimicking biological neural systems to reduce energy consumption. The paper leverages dynamical systems theory (specifically Lyapunov stability analysis) to provide theoretical guarantees about system behavior, and introduces local topological conjugates — mathematical constructs from dynamical systems that preserve qualitative dynamics while enabling tractable optimization. The auditory cortex inspiration refers to evidence that biological hearing systems operate on multiple fixed timescales to process sound across frequency bands, suggesting this principle could improve artificial sequence modelling.

## Core Contributions
1. **ADPTNet architecture**: Combines non-linear recurrence with prescriptive (controllable) timescales via Lyapunov spectrum parametrization — achieving what prior work struggled with: simultaneously data-adaptive, long-range capable, GPU-parallelizable, and non-linearly recurrent.
2. **Theoretical guarantees**: Provides dynamical systems proofs that enable explicit parametric control of timescale behavior, moving beyond heuristic tuning.
3. **Efficient parallelization**: Introduces Conv DEER and Forward DEER — two Jacobian-free extensions to the DEER parallel simulation algorithm that enable non-linear RNN parallelization via iterated convolutions without computational overhead.
4. **SpikingADPTNet**: A neuromorphic variant achieving state-of-the-art on Spiking Speech Commands (83.56%), bridging discrete spiking neural networks with this framework.
5. **Empirical validation**: Outperforms Hawk (previous long-range + adaptive baseline) on Selective Copying; matches Mamba on CIFAR-10 while beating Transformers and selective models with fewer parameters.

## Connections to Other Work
This work directly competes with and improves upon [[Mamba]] (linear SSMs) and [[Hawk]] (selective models balancing memory and adaptability). It tackles the same core problem as recent work on [[Transformers|transformer alternatives]] for efficient sequence modelling, but takes a dynamical systems + neuromorphic path rather than pure linear SSM or attention-based solutions. The use of Riemannian optimization connects to broader optimization literature, while the spiking neural network variant bridges to neuromorphic hardware acceleration research. The constant-timescale property enables parallelization innovations missing in standard non-linear RNNs.

## Practical Applications
1. **On-device speech/audio processing**: SpikingADPTNet's neuromorphic variant enables ultra-low-power inference on edge devices (hearing aids, IoT, embedded systems) with state-of-the-art accuracy.
2. **Long-sequence time-series forecasting**: Energy-efficient processing of long sensor streams (weather, financial, medical monitoring) without Transformer's quadratic complexity.
3. **Neuromorphic hardware deployment**: Constant timescales align naturally with spiking neuromorphic chips (Intel Loihi, IBM TrueNorth), enabling direct hardware implementation.
4. **Real-time sequential decision-making**: Robotics and autonomous systems that require fast, parallelizable inference with long memory (navigation, planning).
5. **Sequential vision tasks**: CIFAR-10 results suggest viability for frame-based video understanding on low-power devices.

## Product & Startup Ideas
1. **Edge AI audio inference engine**: SaaS/SDK for deploying SpikingADPTNet on mobile/IoT for real-time speech commands, noise cancellation, or language identification — 10-100× lower power than Transformer-based alternatives.
2. **Neuromorphic chip compiler**: Developer tools to automatically convert ADPTNet models to run on neuromorphic hardware (Loihi 2, TrueNorth), enabling startups to access niche markets (defense, space, medical implants).
3. **Industrial time-series analytics**: Real-time anomaly detection and forecasting for manufacturing/energy grids using long-range memory with minimal compute — licensing the architecture to enterprises.
4. **On-device video understanding**: Lightweight sequential vision models for surveillance, autonomous vehicles, and drones that require long temporal context and run on edge GPUs with constrained power budgets.
5. **Biological signal processing platform**: Consumer wearables and clinical devices analyzing ECG, EEG, or EMG streams in real-time with adaptive timescales tuned to human physiology — patent-defensible via the theoretical Lyapunov framework.

## Technical Limitations
1. **Limited experimental scope**: Evaluation focuses on synthetic tasks (Selective Copying), CIFAR-10, and speech commands. Missing comparisons on large-scale NLP (language modelling, translation) where Transformers dominate, making real-world competitive advantage unclear.
2. **Timescale sensitivity**: While theory guarantees control, practical selection of Lyapunov parameters likely requires problem-specific tuning — the paper doesn't provide principled, automated tuning procedures.
3. **Neuromorphic variant immaturity**: SpikingADPTNet is early; hardware deployment details and true energy savings vs. Transformers on real neuromorphic chips are not demonstrated.
4. **Parallelization trade-offs unstated**: Conv DEER claims "no computational overhead" but fine-grained complexity analysis (memory bandwidth, communication cost) and wall-clock time comparisons vs. standard GPUs are absent.
5. **Non-linear expressivity unclear**: No ablation isolating the contribution of non-linearity vs. timescale adaptation; unclear if non-linearity is necessary or if data-adaptive linear SSMs suffice.
6. **Theoretical-practical gap**: Lyapunov proofs assume perfect parametrization and continuous dynamics; discretization and numerical precision effects are not analyzed.

## Open Questions
1. **Scalability to language modelling**: How does ADPTNet scale to billion-parameter regimes on text? Can it match or exceed recent open-source LLMs (Llama, Mistral)?
2. **Automatic timescale discovery**: Can the Lyapunov parametrization be learned end-to-end (e.g., via meta-learning or differentiable topology search) rather than hand-tuned?
3. **Energy benchmarks on real hardware**: Actual watt/inference and latency measurements on neuromorphic chips (Loihi 2) vs. GPUs for equivalent tasks?
4. **Generalization across domains**: Does a single ADPTNet architecture with fixed timescales generalize across speech, vision, and language, or does each require domain-specific tuning?
5. **Why fixed timescales?** Ablation comparing fixed vs. learned/adaptive timescales across tasks — when is prescriptive better than adaptive?
6. **Mechanistic understanding**: Which timescales (which eigenvalues of the Lyapunov spectrum) solve which sub-problems? Can we interpret what each timescale is learning?

## Key Takeaway
ADPTNet achieves efficient long-range sequence modelling by pairing non-linear dynamics with biologically-inspired fixed timescales, enabling GPU parallelization and matching Transformer accuracy with fewer parameters.
