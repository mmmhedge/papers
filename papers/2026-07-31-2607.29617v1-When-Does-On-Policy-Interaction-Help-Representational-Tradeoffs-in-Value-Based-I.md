# When Does On-Policy Interaction Help? Representational Tradeoffs in Value-Based Imitation Learning

**Authors:** Luca Viano, Antoine Moulin, Audrey Huang, Volkan Cevher, Philip Amortila et al.
**Published:** 2026-07-31 | **arXiv:** [2607.29617v1](http://arxiv.org/abs/2607.29617v1)

## Summary
This paper asks when asking an expert for feedback during training helps an imitation learning agent learn better. The key insight is that interactive feedback relaxes what the learner needs to represent—it only needs to capture the expert's *value function* (which rewards are good), not the expert's exact *policy* (which actions to take). The authors present OVI, an algorithm that leverages this insight and show it outperforms standard approaches, especially when the learner is less capable than the expert.

## Theoretical Background
Imitation learning trains agents to mimic expert behavior from demonstrations. The standard baseline, Behavior Cloning (BC), directly fits the expert's action distribution—but this fails when the learner can't perfectly replicate the expert's policy, causing errors to compound over time. Two techniques address this empirically: (1) DAgger, which interactively queries the expert along the learner's own trajectories, and (2) value-based methods, which estimate reward functions rather than copying actions directly. This paper bridges these two ideas theoretically using representational complexity arguments—the key question is: *what does a learner actually need to represent to succeed?* The paper builds on prior work in offline reinforcement learning and leverages value function realizability, the assumption that a learner can express the expert's true value function with its network architecture.

## Core Contributions
1. **Theoretical characterization**: Proves that on-policy interaction reduces representational burden from requiring expert-policy realizability to only requiring expert-value-function realizability. This is a strictly weaker assumption.
2. **OVI algorithm**: Proposes a statistically efficient interactive value-based IL algorithm that is computationally efficient given a linear maximization oracle.
3. **Necessity result**: Establishes a negative result—without interaction, any offline IL algorithm must scale with the complexity of the entire expert policy class, showing interaction is fundamentally necessary under value-realizability-only assumptions.
4. **Empirical validation**: Demonstrates OVI's superiority over policy-based and value-based baselines, with largest gains when the learner is substantially less expressive than the expert.

## Connections to Other Work
This work directly engages with [[Behavior Cloning]], the baseline imitation learning approach, and [[DAgger]], the canonical interactive imitation learning algorithm. It relates to broader questions in [[Reinforcement Learning]] about representation learning and the expressivity gap between learner and expert. The value-function realizability assumption connects to offline RL theory (e.g., Bellman completeness and Eluder dimension). The paper also relates to policy distillation in large language models, where a smaller model must learn from a larger expert—a practically important regime the paper explicitly motivates.

## Practical Applications
1. **Robot learning**: Training robots on task demonstrations when robot actuators are less precise/capable than human demonstrators—OVI reduces the need for exact action replication.
2. **Language model distillation**: Compressing large foundation models into smaller ones by learning from their value estimates (e.g., reward models) rather than exact token predictions.
3. **Autonomous driving**: Training a vehicle controller from expert driving data when the vehicle's decision-making capacity differs from the human expert's.
4. **Game AI**: Teaching agents from expert gameplay in resource-constrained settings (mobile games, edge devices) where exact policy cloning fails.

## Product & Startup Ideas
1. **AI tutoring platform**: Interactive system that learns to teach students by querying expert educators only about value-based feedback ("is this correct?") rather than copying full lesson plans, enabling scalable curriculum personalization.
2. **Robotic process automation (RPA) service**: Automate office workflows by learning from employee demonstrations, using value-function feedback instead of precise action replication—works even with lower-capability automation systems.
3. **Compressed model marketplace**: SaaS offering that automatically distills enterprise LLMs into smaller, customer-deployable models using value-function interaction instead of behavior cloning.
4. **Autonomous fleet training platform**: Software for training smaller, cheaper autonomous vehicles from expert driver data by learning value representations rather than exact driving policies.
5. **Game AI modding tool**: Developer tool that allows indie game creators to train competitive NPC agents from pro-player clips with minimal compute by learning value estimates interactively.

## Technical Limitations
1. **Linear maximization oracle assumption**: The computational efficiency result requires access to an efficient linear maximization oracle, which may not exist for complex action spaces or nonlinear value functions.
2. **Value-function realizability**: The main benefit assumes the learner's network can represent the expert's value function—this is still a strong assumption that may fail in practice, and the paper doesn't characterize when this holds.
3. **Expert querying cost**: Interactive methods assume cheap expert queries. Real experts (humans, GPT-4) are expensive; the paper doesn't model query cost or budget constraints.
4. **Finite-horizon or discounted settings**: Results may not generalize to undiscounted, infinite-horizon problems common in robotics.
5. **Empirical scope**: Experiments are synthetic/controlled; unclear how well OVI scales to high-dimensional vision-based tasks or naturalistic expert data with noise.
6. **Computational overhead**: Interactive on-policy learning requires running the learner policy in the environment repeatedly; offline methods avoid this cost entirely.

## Open Questions
1. **When does value-function realizability hold?** Can the paper characterize—theoretically or empirically—which network architectures and expert classes satisfy this assumption?
2. **Efficient linear maximization beyond tabular cases**: How can the computational efficiency result extend to continuous/large action spaces without the linear oracle?
3. **Noisy expert feedback**: What happens if expert value estimates are imperfect or uncertain? Does the algorithm remain efficient?
4. **Sample complexity tradeoffs**: Can you quantify the sample complexity of on-policy queries vs. offline samples? When is interaction more data-efficient than offline learning?
5. **Multi-agent extension**: If the expert itself is learned or adaptive, does the approach still work? What if multiple learners query the same expert?
6. **Partial feedback**: What if the expert can only provide partial value function estimates (e.g., preference comparisons) rather than exact values?

## Key Takeaway
Interactive learning reduces what an agent must copy from an expert's exact actions to just their reward structure, enabling faster learning with less capable learners.
