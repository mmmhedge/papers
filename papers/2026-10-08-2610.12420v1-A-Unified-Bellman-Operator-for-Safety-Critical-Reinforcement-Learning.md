# A Unified Bellman Operator for Safety-Critical Reinforcement Learning

**Authors:** Nishanth Arun Rao, Royina Karegoudra Jayanth, Benjamin Eysenbach, Jaime Fernández Fisac
**Published:** 2026-10-08 | **arXiv:** [2610.12420v1](http://arxiv.org/abs/2610.12420v1)

## Summary
This paper proposes a new mathematical framework (a "Bellman operator") for training reinforcement learning agents in safety-critical environments—domains like autonomous driving or robotics where mistakes can cause harm. The key innovation is that it unifies the two conflicting goals (task performance and safety constraints) into a single value function, rather than forcing a choice between guaranteed safety with limited learning or flexible learning with average safety. The authors prove the approach converges theoretically and demonstrate it works in continuous control simulations with near-zero safety violations.

## Theoretical Background
Reinforcement learning agents learn by estimating value functions—predictions of future rewards—using the Bellman equation, a recursive relationship that connects current and future values. In safety-critical settings, agents must satisfy hard constraints (e.g., "never exceed velocity X"). Prior work splits into two camps: **safety filters** use pre-computed safe regions to block unsafe actions (guarantees safety but limits learning), and **constrained RL** methods (like Lagrangian approaches) jointly optimize task and safety objectives but only guarantee average constraint satisfaction, meaning occasional violations occur.

This paper builds on **two-timescale stochastic approximation**, a mathematical framework where fast and slow learning processes run simultaneously at different speeds, enabling convergence analysis of complex coupled systems. The theoretical proof uses **occupation-averaged differential inclusions**—a technique from dynamical systems theory for analyzing limits of discrete stochastic processes.

## Core Contributions
1. **Unified Bellman Operator**: A novel Bellman update rule that combines task value and safety value into a joint value function—the core algorithmic contribution. This is distinct from Lagrangian methods that weight objectives with a scalar multiplier.

2. **Convergence Guarantee**: Rigorous proof that temporal difference learning with this operator converges under two-timescale dynamics (fast safety estimation, slow joint value estimation), using occupation-averaged differential inclusions to analyze the limiting behavior.

3. **Hard Safety Guarantee at Convergence**: Once trained, the resulting policy maintains safety *at all times* (not on average), eliminating the classical safe RL trade-off.

4. **Empirical Validation**: Demonstrates the approach on continuous control tasks with neural network function approximators, showing stable learning with near-zero test-time violations.

## Connections to Other Work
This work directly addresses limitations of [[Constrained Markov Decision Processes (CMDPs)]] and Lagrangian safe RL methods, which optimize average constraint satisfaction. It relates to **safety filters** and **reachability analysis** (computing provably safe regions), but enables learning within safe regions rather than enforcing them a priori. The two-timescale framework echoes techniques used in [[actor-critic methods]] and [[multi-agent reinforcement learning]] where multiple objectives are learned simultaneously. The result also connects to **robust optimal control** literature, which seeks policies robust to constraint violations. The emphasis on *anytime* safety (not asymptotic) aligns with concerns in [[alignment]] and deployment of RL agents in real systems.

## Practical Applications
1. **Autonomous Vehicles**: Training driving policies that never exceed safety thresholds (e.g., collision distance) during learning, not just after convergence.
2. **Robotic Manipulation**: Learning pick-and-place tasks while ensuring joint torque limits or obstacle avoidance are *never* violated during training.
3. **Power Grid Control**: RL agents for grid balancing that maintain voltage/frequency constraints at every timestep, not in expectation.
4. **Medical Dosing Automation**: Automated drug delivery systems that learn optimal dosing while never exceeding safe concentration levels.
5. **Industrial Process Control**: Chemical plant optimization that respects temperature, pressure, and toxic emission limits in real-time.

## Technical Limitations
1. **Scalability to High Dimensions**: Neural network approximations in high-dimensional state spaces may suffer from overparameterization; convergence proofs assume tabular or linear function approximation in places.
2. **Constraint Specification Burden**: Requires explicit mathematical formulation of all safety constraints; vague constraints ("be safe") cannot be encoded.
3. **Offline Safety Knowledge**: The framework assumes safety value function can be estimated accurately; if the agent never explores safe regions during training, estimates remain poor.
4. **Sample Efficiency**: Two-timescale learning requires many samples; may be prohibitive for expensive-to-simulate domains (real robot experiments).
5. **Local Convergence**: Proofs guarantee convergence to a local optimum satisfying constraints; global optimality is not ensured, especially with nonlinear approximators.
6. **Assumption of Ergodicity**: Convergence analysis assumes the Markov chain is ergodic (can reach all states from any state); sparse reward or discontinuous constraint sets may violate this.

## Open Questions
1. **Global Optimality in Deep RL**: Can the framework be extended to guarantee finding the *globally* optimal safe policy when using deep neural network approximators? Current theory handles linear approximation.
2. **Partial Observability**: How does the approach scale to partially observable MDPs (POMDPs) where the agent has imperfect state information, common in robotics?
3. **Constraint Uncertainty**: What if safety constraints are *unknown* or partially observable (e.g., unsafe state discovered only after collision)? Can the framework adapt online?
4. **Multi-Constraint Hierarchies**: How to handle competing constraints (e.g., "never exceed speed limit" vs. "reach destination quickly")? Current framework assumes compatible constraints.
5. **Transfer & Generalization**: Can safe policies learned in one environment transfer to similar environments with different dynamics or constraint configurations?
6. **Computational Complexity**: What is the sample and computational complexity compared to Lagrangian or filter-based baselines? No complexity analysis provided.

## Key Takeaway
A new learning algorithm unifies task performance and safety constraints into one framework, guaranteeing the trained policy never violates safety rules—not just on average, but always.
