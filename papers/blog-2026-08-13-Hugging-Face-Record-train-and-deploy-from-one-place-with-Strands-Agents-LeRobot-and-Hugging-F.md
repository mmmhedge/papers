# Record, train, and deploy from one place with Strands Agents, LeRobot, and Hugging Face Storage Buckets

**Source:** Hugging Face
**Published:** 2026-08-13 | **Link:** [https://huggingface.co/blog/amazon/strands-lerobot-streaming-data-loop](https://huggingface.co/blog/amazon/strands-lerobot-streaming-data-loop)

## Summary
Hugging Face announces an integrated platform combining Strands Agents, LeRobot, and Hugging Face Storage Buckets to streamline the end-to-end workflow of recording robot demonstrations, training behavioral policies, and deploying embodied agents. This addresses fragmentation in the robotics development pipeline by unifying data collection, model training, and deployment in a single environment.

## Key Points
- **Unified workflow**: Single platform for recording → training → deployment eliminates context switching between tools
- **Strands Agents integration**: Robot control and agent orchestration framework
- **LeRobot support**: Behavioral cloning and imitation learning from demonstrations
- **Storage integration**: Centralized dataset management via Hugging Face Storage Buckets reduces data pipeline friction
- **End-to-end traceability**: Experiments, models, and artifacts stay connected throughout development cycle

## Why It Matters
Robotics and embodied AI development currently requires gluing together multiple incompatible tools (data labeling platforms, training frameworks, deployment systems). This integration reduces operational overhead, improves reproducibility, and lowers the barrier for teams to move from research prototypes to deployed agents. It also strengthens Hugging Face's position as infrastructure for applied ML beyond NLP.
