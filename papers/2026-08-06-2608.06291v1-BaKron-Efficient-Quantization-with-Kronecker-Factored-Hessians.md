# BaKron: Efficient Quantization with Kronecker-Factored Hessians

**Authors:** Johann Birnick, Rayan Saab
**Published:** 2026-08-06 | **arXiv:** [2608.06291v1](http://arxiv.org/abs/2608.06291v1)

## Summary
We accelerate a family of algorithms for neural network quantization whose geometry is informed by any Kronecker-factored approximation of the Hessian. GPTQ-style adaptive rounding typically uses one-sided information derived from input activations. Two-sided Kronecker-factored Hessian approximations can additionally capture correlations across output coordinates, but applying GPTQ directly in the vectorized weight domain is computationally expensive.

## Theoretical Background
Efficient machine learning depends on reducing compute and memory without losing the behavior of the original system. Approximation methods therefore need both empirical gains and clear error or stopping guarantees.

The paper is positioned against prior approaches described in its abstract and asks whether a more targeted representation, evaluation method, or optimization procedure can improve the relevant trade-off.

## Core Contributions
1. Building on the two-sided adaptive-rounding formulation used by BoA and YAQA, we introduce BaKron, an efficient solver that combines anti-diagonal parallelism with a recursive divide-and-conquer construction.
2. We also provide practical benchmarks, consider a range of Hessians that BaKron can be called with, find an efficient technique to compute these Hessians, and evaluate the algorithm experimentally.
