# $Σ$-Mem: An Online Reliability Memory for LLM-based Multi-Agent Systems

**Authors:** Peilin Feng, Suorong Yang, Soujanya Poria
**Published:** 2026-07-30 | **arXiv:** [2607.27958v1](http://arxiv.org/abs/2607.27958v1)

## Summary
This paper introduces Σ-Mem, a memory system that tracks which agents in a multi-agent LLM system are reliable and trustworthy. Instead of just storing conversation history, it learns from past correct/incorrect answers to build a dynamic model of each peer agent's competence and their relationships, enabling better coordination decisions without retraining the underlying models.

## Theoretical Background
Multi-agent systems with LLMs face a coordination problem: when multiple agents generate responses, a central model cannot always verify which answers are correct, especially when responses are plausible-sounding but potentially correlated errors. Prior work treats agents symmetrically or uses fixed trust assumptions. This paper builds on two foundations: (1) spectral methods for matrix updates — using Weyl's inequality to guarantee that incremental reliability updates don't destabilize the system, and (2) reputation/trust systems from distributed computing, adapted here for LLM agents. The key insight is modeling reliability as **real symmetric matrices** (mathematical objects with stable update properties) that capture both individual agent competence and pairwise peer relationships.

## Core Contributions
1. **Σ-Mem architecture**: An online reliability memory that maintains two forms of evidence — individual competence (how often an agent is correct) and peer relationships (correlation patterns) — as symmetric matrix states updated from feedback signals.
2. **Spectral stability guarantee**: Uses Weyl's inequality to prove that event-level updates cause bounded spectral perturbations, permitting safe online adaptation without model retraining.
3. **Unified interface**: Single memory system supports three distinct use cases — residual steering (nudging a central model), peer routing (directing queries to best agents), and reliability-weighted voting (aggregating answers by trustworthiness).
4. **Empirical validation**: Demonstrates generalization to unseen peers, unseen task domains, and counterfactual reliability shifts; shows consistent performance gains as feedback accumulates.

## Connections to Other Work
Σ-Mem relates to several existing paradigms:
- [[Multi-agent coordination]] and [[Mixture of Experts]] — but with learned, dynamic trust weights rather than fixed routing.
- [[Uncertainty quantification]] in LLMs — Σ-Mem infers reliability without explicit confidence scores.
- [[Reputation systems]] from blockchain and distributed systems — adapted for language model agents with correctness feedback as the signal.
- [[Ensemble methods]] — extends voting schemes (majority vote, weighted averaging) with memory-backed adaptation.
- Complements work on [[RLHF]] and [[alignment]] by providing a mechanism to detect which agents follow training objectives reliably in practice.

## Practical Applications
1. **Research collaboration platforms**: Multi-researcher systems where agents (LLMs or humans + LLMs) propose hypotheses; Σ-Mem learns which collaborators are reliable on different problem types.
2. **Fact-checking and content verification**: News organizations or social media platforms using multiple fact-checking agents; memory tracks which agents are accurate on politics vs. science vs. local news.
3. **Autonomous reasoning systems**: Code generation, math solving, or legal document analysis where multiple specialist agents contribute; system learns which agents excel at which tasks.
4. **Scientific peer review**: Automated systems that route submissions to appropriate reviewers and weight their feedback based on historical accuracy.
5. **Customer support routing**: Contact centers with multiple LLM agents; system learns which agents handle billing issues vs. technical issues accurately, improving over time.

## Product & Startup Ideas
1. **Multi-Agent Orchestration Platform**: SaaS product offering Σ-Mem as a plug-and-play reliability layer for enterprises running teams of specialized LLM agents, with dashboards showing agent competence heatmaps and performance trends.
2. **Adaptive AI Content Moderation**: Content moderation system using multiple specialized models (toxicity, hate speech, misinformation); Σ-Mem learns domain-specific reliability (e.g., better on Arabic than English) and auto-routes flagged content.
3. **Consulting Query Router**: Firms with multiple specialist LLM agents (tax, labor law, IP law); Σ-Mem learns which agents give correct answers by practice area and client type, improving consultant-query matching.
4. **Research Proposal Evaluation**: Academic funding bodies deploy multiple AI reviewers; Σ-Mem learns which agents are well-calibrated, catch flawed proposals, and generalize across disciplines — improving reviewer recommendations.
5. **Synthetic Data Quality Monitor**: Data generation using multiple LLM agents; Σ-Mem tracks which agents produce clean, non-biased synthetic data for specific domains, enabling adaptive scheduling and quality gates.

## Technical Limitations
1. **Feedback requirement**: The system requires post-decision correctness labels to update reliability matrices. In real-time systems where ground truth is delayed or unavailable (e.g., long-horizon reasoning, open-ended tasks), adaptation stalls.
2. **Scalability of matrix operations**: Storing peer relationship matrices grows quadratically with agent count; at thousands of agents, storage and update costs may become prohibitive.
3. **Assumption of stationarity within tasks**: The method assumes reliability is relatively stable within a task domain. In rapidly shifting domains (trending topics, new tools), old reliability evidence may become misleading.
4. **Cold-start problem**: New peers or task domains start with no reliability history; the system must fall back to uniform trust until evidence accumulates.
5. **Adversarial robustness**: No discussion of poisoning attacks — a malicious agent could manipulate reliability matrices through systematic wrong answers that correlate with others.
6. **Limited to classification tasks**: The approach measures reliability as correctness/incorrectness; for generative or open-ended tasks (creative writing, summarization), defining "correctness" feedback is ambiguous.

## Open Questions
1. How does Σ-Mem perform when correctness feedback is noisy or delayed? What is the learning curve as feedback latency increases?
2. Can the method handle non-stationary reliability (agents improving over time, or degrading due to concept drift)?
3. Does peer relationship evidence (the second matrix) actually improve decisions over individual competence alone? An ablation would clarify this.
4. How does performance scale to hundreds or thousands of agents? Is there a practical limit?
5. Can the memory be initialized or warm-started from pre-training or domain knowledge, rather than starting from zero?
6. Does Σ-Mem transfer across different task families (e.g., from math to code to language understanding)? Current results show generalization to unseen tasks within a domain.
7. Can adversarial agents or distribution shifts be detected from spectral properties of the reliability matrices themselves?

## Key Takeaway
Multi-agent LLM systems can dynamically learn which peers are trustworthy by maintaining spectral memory of competence, enabling stable adaptation without retraining.
