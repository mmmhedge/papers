# Algorithms for Equilibria in Concurrent Stopping Games

**Authors:** Léonard Brice, Thomas A. Henzinger, K. S. Thejaswini
**Published:** 2026-07-27 | **arXiv:** [2607.24219v1](http://arxiv.org/abs/2607.24219v1)

## Summary
This paper studies how to find Nash equilibria—stable strategy profiles where no player wants to unilaterally change their behavior—in concurrent stopping games, where multiple agents act simultaneously and the game terminates almost surely. The authors prove that finding equilibria with payoff constraints is generally undecidable, but offer two tractable paths: approximate equilibria (solvable in exponential time) and a risk-sensitive equilibrium concept (NP-complete, hence more computationally friendly).

## Theoretical Background
Nash equilibrium is the foundational solution concept in game theory—a strategy profile where no player can improve their payoff by deviating unilaterally. Concurrent games extend this to multi-agent settings where players act in parallel rather than taking turns. A stopping game is one that reaches a terminal state with probability 1 under any strategy profile, making them a natural model for finitary interactions. The paper builds on prior work establishing that many equilibrium existence problems in games are computationally intractable; the key innovation is identifying structural relaxations—approximation (ε-Nash equilibria) and alternative solution concepts (risk-sensitive equilibria)—that restore tractability.

## Core Contributions
1. **Undecidability result**: The constrained existence problem (does an equilibrium with prescribed payoff intervals exist?) is undecidable even for 10-player concurrent stopping games.
2. **Approximate equilibria algorithm**: A polynomial-time algorithm in the bit-size of ε that finds ε-Nash equilibria with constrained payoffs, though exponential in game size.
3. **PSPACE-hardness for pure equilibria**: Establishes a lower bound showing approximation alone doesn't fully solve hardness.
4. **Extreme risk-sensitive equilibria (XRSE)**: Introduces an alternative solution concept where players care about best/worst achievable payoffs (not expected values), making the constrained existence problem NP-complete rather than undecidable.

## Practical Applications
1. **Distributed protocol design**: Finding equilibria in concurrent message-passing systems where agents have payoff constraints (e.g., latency or throughput targets).
2. **Multi-robot coordination**: Robots acting in parallel with safety or energy-efficiency payoff bounds; risk-sensitive equilibria model conservative robots that optimize worst-case outcomes.
3. **Auction mechanism design**: Concurrent bidding systems where auctioneer constrains equilibrium payoffs for fairness.
4. **Network resource allocation**: Concurrent competing flows with QoS constraints; XRSE useful when pessimistic agents want to guarantee minimum throughput.

## Product & Startup Ideas
1. **Equilibrium-solver SaaS for game design**: A tool for game designers, economists, and mechanism designers to compute approximate equilibria in concurrent games with payoff constraints—useful for esports tournament design, voting systems, auction platforms.
2. **Risk-aware multi-agent optimizer**: Commercial optimization engine for supply chain or logistics networks where agents operate concurrently and some are risk-averse; uses XRSE to guarantee worst-case performance bounds.
3. **Protocol verification tool**: Static analyzer for distributed systems and smart contracts that verifies whether concurrent protocols admit equilibria meeting performance SLAs.
4. **Robotic swarm coordinator**: Middleware for autonomous systems (drones, warehouse robots) that computes equilibrium strategies when agents act in parallel, with hard payoff constraints (energy, collision-avoidance).
5. **Causal game simulator**: Educational/research platform for game theorists to explore equilibrium existence across game classes and parametrizations.

## Technical Limitations
1. **Undecidability**: The constrained existence problem cannot be solved algorithmically in the general case—no finite algorithm can always answer "yes" or "no."
2. **Exponential blowup**: The approximate equilibria algorithm, while polynomial in ε-bit-size, is exponential in the game representation, limiting scalability to large concurrent games.
3. **Risk-sensitive equilibria are a different animal**: XRSE changes the solution concept entirely (best/worst payoffs instead of expectation), so results don't apply to traditional Nash equilibrium existence.
4. **Stopping games only**: Results apply only to games that terminate almost surely; non-stopping concurrent games (infinite play) require different machinery.
5. **Hardness lower bounds**: PSPACE-hardness on turn-based games leaves a gap—exact complexity for concurrent pure equilibria remains open.

## Open Questions
1. Can the exponential dependence on game size for approximate equilibria be improved (e.g., via structure exploitation or approximation schemes)?
2. What is the exact complexity of finding pure ε-Nash equilibria in concurrent games?
3. Do risk-sensitive equilibria form a well-behaved solution concept beyond existence—e.g., do they refine uniqueness, stability, or strategic properties?
4. Can equilibrium approximation and risk-sensitivity be combined to get both computational tractability *and* strategic robustness?
5. How do these results extend to stochastic games with non-stopping behavior (infinite-horizon discounted payoffs)?

## Key Takeaway
Exact Nash equilibrium existence in concurrent games is undecidable, but approximate equilibria and risk-sensitive variants become tractable.
