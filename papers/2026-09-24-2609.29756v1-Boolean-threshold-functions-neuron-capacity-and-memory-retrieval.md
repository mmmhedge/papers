# Boolean threshold functions, neuron capacity, and memory retrieval

**Authors:** Xinyuan Xie
**Published:** 2026-09-24 | **arXiv:** [2609.29756v1](http://arxiv.org/abs/2609.29756v1)

## Summary
This paper determines exactly how many Boolean threshold functions exist — a fundamental question about how much information a single neuron can store and retrieve. By proving a precise formula for this count, the work improves decades-old bounds and settles open conjectures about memory capacity in neural networks, showing that neurons can reliably distinguish between true and false memories up to a sharp threshold of n−1 stored patterns.

## Theoretical Background
A Boolean threshold function is a rule that takes binary inputs and outputs binary results using a weighted sum followed by a sign operation — the basic computation performed by a single artificial neuron. The capacity question asks: how many distinct such functions are possible with n input bits? This traces back to classic work by Kahn, Komlós, and Szemerédi in the 1980s, who bounded this count but left a gap in the error term. The paper also engages with the Kanter–Sompolinsky Hamiltonian, a statistical physics model for associative memory that describes how neural networks might store and retrieve multiple patterns. The Kalai–Linial–Odlyzko conjecture, a longstanding open problem in theoretical computer science, predicted that at n−1 memories a phase transition occurs — beyond which spurious (false) memories become unavoidable.

## Core Contributions
1. **Exact threshold function count**: Proves $T_n = 2\binom{2^n-1}{n}(1+O(n^{-99}))$, tightening the error term from $O(n)$ down to $O(n^{-99})$ — a dramatic improvement in precision.

2. **Sharper neuron capacity bound**: Establishes that a single threshold neuron can store $n^2 - \log_2(n!) + 1 + O(n^{-99})$ bits of information.

3. **Phase transition confirmation**: Identifies $r = n−1$ as a sharp threshold in the memory retrieval model — at this point, for almost all random memory collections, the only stable (ground state) configurations are the true memories and their negatives, with no spurious attractors.

4. **Linear dependence probability**: Proves a precise formula for the probability that r random binary vectors are linearly dependent, confirming a conjecture of Kahn–Komlós–Szemerédi.

5. **Specification number resolved**: Settles an open problem on the specification number of Boolean threshold functions posed by M. Anthony.

## Practical Applications
1. **Neuromorphic computing**: Understanding single-neuron capacity informs design of spiking neural networks and analog neuromorphic chips, where precision about information limits is crucial for system planning.

2. **Memory-augmented architectures**: Guides the design of neural networks with explicit memory modules (e.g., Neural Turing Machines, external memory buffers) by quantifying when retrieval fails.

3. **Quantization in deep learning**: Helps set optimal precision (bit-width) when compressing neural networks, since capacity bounds reveal how much information must be preserved per neuron.

4. **Brain-inspired AI**: Informs biologically plausible learning models and artificial neural tissue simulation, where understanding single-cell limits improves network efficiency.

## Product & Startup Ideas
1. **Neuromorphic edge chip design tool**: Software that uses precise neuron capacity bounds to auto-optimize network architecture for low-power embedded devices (IoT, robots), reducing parameter count without sacrificing accuracy.

2. **Memory-critical AI for robotics**: Real-time learning systems for autonomous agents that use these capacity results to guarantee spurious-memory-free retrieval during continuous online learning.

3. **Compressed neural network optimizer**: A compilation tool that leverages exact capacity formulas to identify redundant neurons and prune networks more intelligently than existing heuristics.

4. **Formal verification for neural systems**: A tool suite for hardware designers and safety-critical AI teams to mathematically certify that neural accelerators won't produce false memory states given bounded input and model constraints.

5. **Educational AI platform**: Interactive learning software that visualizes neuron capacity and memory phase transitions, helping students and practitioners understand why real networks fail at certain scales.

## Technical Limitations
1. **Binary restriction**: Results apply only to Boolean functions on {−1, 1}^n. Real neurons use continuous activations and graded outputs; extension to ℝ-valued neurons is non-trivial.

2. **Threshold neurons only**: Limited to threshold functions (sign of linear combinations). Modern neurons use ReLU, sigmoid, and other nonlinearities with fundamentally different capacity profiles.

3. **Worst-case memory assumption**: Analysis assumes random, unstructured memory patterns. Structured or correlated patterns (common in real data) may exhibit different phase transitions.

4. **No learning dynamics**: Results are static — they characterize capacity at equilibrium but don't model how learning algorithms (gradient descent) actually store or retrieve memories, or whether optimal capacity is achievable in practice.

5. **Scaling gap**: While the error improves to O(n^{-99}), this still leaves a non-zero gap; exact closed form remains unknown for small n.

## Open Questions
1. **Real-valued neurons**: Can the approach extend to neurons with continuous activations and nonlinear response functions? Where are the phase transitions?

2. **Learning dynamics**: How much information can a threshold neuron actually store *during* learning with gradient descent? Does it achieve the theoretical capacity?

3. **Correlated patterns**: How do memory retrieval thresholds change when memories are structured (e.g., images, natural language) rather than random?

4. **Network effects**: How do capacity bounds for single neurons compose into bounds for entire networks? When do scaling laws break?

5. **Hardness of retrieval**: Is there a computational (not just information-theoretic) distinction between memorizing n−1 patterns reliably vs. n patterns with errors?

## Key Takeaway
Single neurons can precisely store and retrieve n−1 memories before spurious ones emerge — a theorem tightening decades-old bounds and confirming a phase transition conjecture.
