# ProximalFM: Amortized Proximal Causal Inference under Hidden Confounding

**Authors:** Christophe Muller, Ayub Kharel, Alex Luedtke, Chan Park, Eric Tchetgen Tchetgen et al.
**Published:** 2026-10-06 | **arXiv:** [2610.08078v1](http://arxiv.org/abs/2610.08078v1)

## Summary
This paper addresses a fundamental problem in causal inference: estimating treatment effects when some important confounding variables are unobserved. The authors propose ProximalFM, a deep learning method that uses proxy variables and transformer-based foundation models to quickly estimate causal effects without requiring dataset-specific tuning or solving computationally unstable equations.

## Theoretical Background
Causal inference aims to estimate how interventions affect outcomes. Standard methods assume all confounders (variables that influence both treatment and outcome) are measured, which is often violated in practice. Proximal causal inference sidesteps this by using proxy variables — observed variables that are influenced by hidden confounders — to identify causal effects despite unmeasured confounding. Formally, this requires solving an ill-posed integral equation (a mathematically unstable problem with many potential solutions). Recent work has shown that prior-data fitted networks (PFNs) — neural networks trained on synthetic data to approximate Bayesian posterior distributions — work well for causal problems with measured confounding (backdoor adjustment) and instrumental variables. This paper extends that idea to the proximal setting.

## Core Contributions
1. **Novel PFN application to proximal inference**: First to apply amortized Bayesian methods to proximal causal inference, enabling fast single-pass inference instead of solving ill-posed equations for each new dataset.
2. **Handling stochastic oracle targets**: Introduces a variation of PFNs that accounts for Monte Carlo error in oracle counterfactual estimates (the "ground truth" causal effects used during training), a problem not addressed in prior PFN work.
3. **Posterior distribution over CATE**: Unlike prior proximal work that focuses on point estimates, ProximalFM directly targets the full Bayesian posterior of the conditional average treatment effect (CATE), providing uncertainty quantification.
4. **Empirical robustness**: Demonstrates consistent strong performance across diverse proximal regimes without hyperparameter tuning, particularly when confounding is severe and proxies are weak.

## Connections to Other Work
This builds on [[Attention Is All You Need]] (transformers as sequence processors) and recent advances in [[generative-models]] for tabular data. Sits at the intersection of structural causal models (SCMs) and neural approximation of Bayesian inference.

## Practical Applications
1. **Medical causal inference**: Estimating drug effects when patient health status (unobserved severity) confounds both treatment assignment and outcomes, using proxy variables like biomarkers.
2. **Econometrics**: Estimating policy effects (e.g., education subsidies → earnings) when unobserved ability confounds both policy exposure and outcomes, using proxy variables like past test scores.
3. **Marketing attribution**: Measuring campaign effectiveness when unobserved brand affinity confounds both ad exposure and purchases, using proxy variables like browsing behavior.
4. **Labor economics**: Estimating wage returns to training when unobserved motivation confounds both training uptake and wages, using proxy variables like previous job search effort.

## Product & Startup Ideas
1. **CausalAI-as-a-Service**: API that takes observational datasets, automatically identifies and validates proxy variables, and returns Bayesian posterior estimates of treatment effects for A/B test design and observational study analysis.
2. **Pharmaceutical trial optimization**: Pre-trial tool that uses electronic health records to estimate hidden confounding strength and optimal proxy variable selection, de-risking early-phase trial design.
3. **Policy evaluation dashboard**: SaaS platform for government/NGOs to quickly evaluate policy effectiveness from observational data without commissioning expensive RCTs, with quantified uncertainty bands.
4. **Personalized medicine platform**: System that estimates heterogeneous treatment effects (CATE) for individual patients from observational data, accounting for unobserved severity and comorbidities, to support clinical decision-making.
5. **Market econometrics consulting tool**: Automated competitor/pricing analysis that infers causal market effects from observational data even when key market variables are unobserved, for strategic business decisions.

## Technical Limitations
1. **Synthetic training data assumption**: Requires access to oracle counterfactuals during training (training SCMs must perfectly generate true causal effects). This is impossible in real causal problems; the paper relies on simulations where ground truth is known by construction.
2. **Proxy variable validity**: Performance degrades when proxies are weak or the proxy-confounder relationship is misspecified. The method cannot validate whether chosen proxies actually satisfy proximal assumptions in real data.
3. **Identifiability not guaranteed**: The proximal framework assumes mathematical identifiability conditions hold (specific functional relationships between confounders, proxies, treatment, and outcome). Violations in real data may not be detectable.
4. **Scalability to high dimensions**: No analysis of how performance degrades with many hidden confounders or high-dimensional outcomes. Transformer computational cost may become prohibitive.
5. **Causal model misspecification**: If the true structural causal model differs from training SCMs, the learned posterior may not reflect true uncertainty. The method does not robustly handle model misspecification.

## Open Questions
1. **Real-world validation**: Can the method work on real observational data where oracle counterfactuals don't exist? How would one validate that learned posteriors are calibrated?
2. **Proxy validation**: Can the method detect or flag when proxy assumptions are violated in real data?
3. **Sensitivity analysis**: How does performance degrade under violations of proximal assumptions (e.g., unobserved direct effects, multiple confounders)? Can we bound this degradation?
4. **Computational scaling**: What is the sample complexity and computational cost as dimension of hidden confounding grows? Can sparse or low-rank structures be exploited?
5. **Hybrid semi-parametric approaches**: Can this be combined with classical debiased machine learning methods for improved robustness to model misspecification?

## Key Takeaway
Transformers can amortize Bayesian causal inference for hidden confounding via proxy variables, enabling fast uncertainty-quantified treatment effect estimates without retuning per dataset.
