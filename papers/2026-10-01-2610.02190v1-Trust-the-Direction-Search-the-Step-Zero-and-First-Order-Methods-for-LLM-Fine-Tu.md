# Trust the Direction, Search the Step: Zero-and-First-Order Methods for LLM Fine-Tuning

**Authors:** Cristian McGee, El Houcine Bergou, Aritra Dutta
**Published:** 2026-10-01 | **arXiv:** [2610.02190v1](http://arxiv.org/abs/2610.02190v1)

## Summary
This paper proposes ZFO (Zero-and-First-Order), a new optimization method that simplifies step-size selection during LLM fine-tuning by separating direction selection from step size. Instead of choosing how far to move in a direction independently, ZFO uses gradient information plus two extra function evaluations to estimate local curvature and pick an adaptive step size along a one-dimensional search line. The method is cheaper than full line search and shows consistent improvements over fixed-step baselines in practice.

## Theoretical Background
Large-scale neural network optimization relies on first-order methods (like SGD or Adam) that use gradients to determine descent directions, but choosing the right step size remains notoriously difficult — too small and training crawls, too large and it diverges. Line search, a classical technique from optimization, solves this by evaluating the objective at multiple points along a direction to find a good step, but is expensive for neural networks. Zeroth-order methods approximate gradients using only function evaluations (no backprop needed), making them useful when gradients are unavailable or noisy. This paper bridges both: it trusts a first-order optimizer for direction but uses zeroth-order evaluations (function calls) to smartly choose step size by estimating curvature locally along that direction.

## Core Contributions
1. **Decoupled framework**: Separates direction selection (trusted first-order optimizer) from step-size selection (adaptive zeroth-order search), which is conceptually simpler than joint optimization.
2. **Efficient curvature estimation**: Shows theoretically that using only two extra function evaluations plus the current gradient can reliably estimate local curvature along the search direction via finite differences.
3. **Adaptive step selection**: Constructs a local quadratic model of the objective along the direction and selects a near-optimal step within a bounded interval, costing less than traditional line search.
4. **Convergence guarantees**: Provides theoretical analysis showing ZFO converges to a stationary point neighborhood with specified rates.
5. **Empirical validation**: Demonstrates consistent improvements over fixed-step first-order baselines on language models across multiple datasets and settings.

## Connections to Other Work
This work sits at the intersection of [[optimization]] for deep learning and adaptive step-size selection. It relates to classical line-search methods (which are expensive for neural networks) and zeroth-order optimization (which avoids backprop but is typically slower). The approach echoes ideas in [[Attention Is All You Need]] and subsequent work on efficient LLM training, which often focus on reducing computational overhead. It also connects to [[RLHF]]-style fine-tuning where step-size robustness is crucial. The bounded search interval concept resembles trust-region methods (which constrain steps to a local region where a model is reliable), and the use of shared function evaluations parallels recent work on gradient-free optimization for black-box settings.

## Practical Applications
1. **Fine-tuning on limited compute**: Scenarios where backprop overhead is high relative to forward passes (e.g., very large models with memory constraints) benefit from the zeroth-order curvature estimation without full backprop on line-search points.
2. **Hyperparameter sensitivity reduction**: Organizations using fixed learning rates across many models can use ZFO's adaptive step to eliminate manual tuning and improve convergence robustness.
3. **Federated or privacy-constrained learning**: When gradient information is sensitive or noisy (e.g., differential-privacy-protected gradients), ZFO's curvature-aware step compensates for gradient noise with adaptive steps.
4. **Continual or online fine-tuning**: Adapting pre-trained LLMs to new domains/tasks in production where step-size drift causes instability — ZFO's adaptive mechanism stabilizes this.
5. **Multi-task fine-tuning**: Simultaneous fine-tuning on heterogeneous tasks with different loss landscapes; adaptive steps per task reduce need for per-task hyperparameter tuning.

## Technical Limitations
1. **Two additional function evaluations per step**: Even though cheaper than full line search, ZFO adds non-negligible overhead compared to vanilla first-order methods in very-large-batch settings where a single forward pass already dominates.
2. **Local quadratic model assumption**: Assumes the objective is locally well-approximated by a quadratic along the search direction; breaks in highly non-convex regions or near saddle points, potentially selecting suboptimal steps.
3. **Bounded search interval design**: The paper doesn't fully specify how to set the search interval bounds adaptively; fixed bounds may be too loose (wasting evaluations) or too tight (missing better steps) for new problems.
4. **Convergence to neighborhood, not exact point**: Theory guarantees convergence to a neighborhood of a stationary point, not an exact solution; the neighborhood size depends on hyperparameters that aren't always clear to set.
5. **Gradient requirement**: Despite zeroth-order claims, still requires reliable first-order gradient information for direction selection — doesn't work in truly gradient-free settings (e.g., black-box simulators).
6. **Limited to fine-tuning scope**: Evaluated mainly on LLM fine-tuning; generalization to other large-scale learning tasks (vision, RL) or non-convex landscape structures common outside language modeling is unclear.

## Open Questions
1. **Adaptive interval bounds**: Can the bounded search interval be set automatically and online, shrinking/expanding based on curvature estimates, rather than fixed beforehand?
2. **Higher-order models**: Would fitting a cubic or higher-polynomial model along the direction (using more function evaluations) yield better step selection for the same compute cost?
3. **Batch-size interaction**: How does ZFO interact with large-batch training (where gradient noise is low) vs. small-batch (high noise)? Does curvature estimation remain reliable?
4. **Distributed and asynchronous settings**: Can ZFO be implemented in distributed training with stale gradients or communication delays? How much does staleness hurt the curvature estimate?
5. **Comparison to modern adaptive methods**: How does ZFO compare to more recent adaptive optimizers like LAMB or mixed-precision Adam in wall-clock time, not just convergence curves?
6. **Non-convex landscape structure**: Does the method exploit or struggle with loss landscape properties specific to LLMs (e.g., mode connectivity, lottery tickets)?

## Key Takeaway
ZFO decouples direction from step size in LLM training, using cheap curvature estimates to pick adaptive steps faster than fixed learning rates.
