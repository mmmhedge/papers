# \k{appa}-LoRA: Condition Numbers Reveal Which LoRA Matrices Worth Updating

**Authors:** Jianghui Wang, Silong Yong, Francesco Orabona, Marco Canini, Katia P. Sycara et al.
**Published:** 2026-07-24 | **arXiv:** [2607.22489v1](http://arxiv.org/abs/2607.22489v1)

## Summary
This paper shows that not all weight matrices in LoRA (Low-Rank Adaptation) fine-tuning contribute equally to model improvement. The authors propose κ-LoRA, which selectively updates only the matrices with the largest condition numbers — a mathematical measure of how "unbalanced" a matrix is. By updating just the top 50% of matrices this way, the method cuts fine-tuning time by 16% and memory use by 4.5% while maintaining accuracy, making large model adaptation cheaper for resource-constrained settings.

## Theoretical Background
LoRA is a parameter-efficient fine-tuning technique that decomposes weight updates into products of low-rank matrices rather than updating full-parameter models. The condition number of a matrix is the ratio of its largest to smallest singular value — a standard concept from linear algebra that measures how "stretched" a matrix is in different directions. Matrices with small condition numbers are well-balanced (similar singular values across all directions), while large condition numbers indicate some directions are much more important than others. This paper leverages condition numbers as a diagnostic tool to identify which LoRA matrices should actually be trained.

## Core Contributions
1. **Empirical discovery**: First demonstration that condition numbers of weight matrices predict LoRA's effectiveness — matrices with larger condition numbers drive most performance gains because they contain underdeveloped directions in rich subspaces.
2. **κ-LoRA method**: A selective fine-tuning strategy that ranks weight matrices by condition number and updates only the top 50%, reducing trainable parameters by 50% without accuracy loss.
3. **Spectral rebalancing insight**: Analysis showing that selected matrices' condition numbers decrease during training, revealing the mechanism is not arbitrary parameter selection but targeted spectral rebalancing — actively developing underexploited directions.

## Technical Limitations
1. **Condition number as proxy**: Condition numbers are computed on initial weights; it's unclear how well they predict performance across all domains, architectures, or layer types — the paper doesn't test failure cases.
2. **Fixed 50% threshold**: The choice to update top 50% of matrices appears heuristic; no principled method for selecting the cutoff is provided, limiting generality.
3. **Scope**: Experiments are mainly on language model fine-tuning; effectiveness on other modalities (vision, multimodal) or on models with radically different architectures is untested.
4. **Interaction with other techniques**: The paper doesn't explore how κ-LoRA interacts with quantization, knowledge distillation, or other compression methods — real deployment often combines multiple techniques.
5. **Theoretical justification**: While the empirical observation is strong, there's no principled theory explaining why condition number predicts adaptation value in general.

## Open Questions
1. **Is the 50% threshold universal?** Does the optimal cutoff depend on model scale, task, or layer type? Can it be predicted from data?
2. **Why condition number specifically?** Could other spectral properties (e.g., effective rank, leverage scores) be equally or more predictive?
3. **Dynamics of condition numbers**: How do condition numbers evolve during pre-training? Can they be used to select LoRA targets earlier in the pipeline?
4. **Cross-task consistency**: Does the same set of high-condition-number matrices matter across different fine-tuning tasks on the same base model?
5. **Theoretical analysis**: Can you prove that high-condition-number matrices span richer adaptation subspaces, or is the connection empirical?
6. **Combination with other efficiency techniques**: How does κ-LoRA compose with quantization, pruning, or layer-wise learning rate scheduling?

## Key Takeaway
Selecting which LoRA matrices to update by condition number cuts fine-tuning cost in half while keeping accuracy.
