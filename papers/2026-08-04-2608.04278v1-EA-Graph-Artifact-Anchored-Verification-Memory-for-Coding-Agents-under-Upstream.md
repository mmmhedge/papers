# EA-Graph: Artifact-Anchored Verification Memory for Coding Agents under Upstream Drift

**Authors:** Hwai-Jung Hsu, Cheng-Jan Chi, Hanna Everett
**Published:** 2026-08-04 | **arXiv:** [2608.04278v1](http://arxiv.org/abs/2608.04278v1)

## Summary
Coding agents increasingly work across sessions, but prose notes can preserve a conclusion without the program state that supported it. After an upstream change, a repository may still build even though earlier verification claims are no longer valid. EA-Graph is an artifact-anchored memory for verification claims.

## Theoretical Background
AI agents combine models with tools, memory, and execution loops. Reliability therefore depends on decisions across a trajectory, not only the quality of isolated answers.

The paper addresses the trade-off identified in its abstract through a targeted method, representation, or evaluation framework.

## Core Contributions
1. It represents artifacts at sub-path granularity, resolves aliases to leaf definitions, anchors each claim to the content used to establish it, and keeps evidence strength separate from freshness.
2. EA-Graph is evaluated on generated repositories whose behavior-to-artifact ground truth is known by construction.
3. Coding agents increasingly work across sessions, but prose notes can preserve a conclusion without the program state that supported it.
