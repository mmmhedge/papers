# Embedding Prediction Helps Image Generation

**Authors:** Sihan Xu, Ji Xie, Zilin Wang, Hui Shen, Stella X. Yu
**Published:** 2026-10-01 | **arXiv:** [2610.02203v1](http://arxiv.org/abs/2610.02203v1)

## Summary
This paper proposes a new approach to condition image generation in diffusion transformers by predicting image embeddings rather than reusing static text or class labels. Instead of keeping the conditioning signal fixed throughout the denoising process, the method dynamically updates it at each step based on predictions from a separate transformer model, achieving competitive image quality (FID 1.32 on ImageNet) with significantly less training compute.

## Theoretical Background
Diffusion transformers (DiT models) generate images by iteratively removing noise from random input over many steps. Traditionally, these models are conditioned on a single fixed embedding derived from class labels or text prompts. The paper builds on [[Attention Is All You Need]] style transformer architectures and the diffusion model framework, where generation proceeds by gradually transforming noise into coherent images. The key insight is that condition embeddings could themselves be predicted dynamically—similar to how autoregressive language models predict the next token, but applied to continuous embedding sequences rather than discrete tokens. Next-Embedding Predictive Autoregression (NEPA) treats embedding prediction as a sequence modeling task, where a transformer learns to forecast what embedding should come next in a sequence.

## Core Contributions
1. **Dynamic Conditioning via Embedding Prediction**: Instead of static conditioning embeddings, the method recomputes conditioning signals at every denoising step using predictions from a NEPA model, allowing the condition to adapt to the current noise level.
2. **Multi-Embedding Prediction**: A training procedure where NEPA predicts multiple future embeddings (corresponding to different noise levels in the generation process) simultaneously, improving efficiency.
3. **Embedding Conditioned Generation (ECG)**: A framework showing how to integrate predicted embeddings into DiT generators such that the conditioning evolves during sampling.
4. **Efficiency Gains**: Achieves FID 1.32 on ImageNet 256×256 using roughly one-third the training compute of baseline REPA, demonstrating that embedding prediction is a computationally efficient alternative to static conditioning.

## Connections to Other Work
This work relates to [[Diffusion Models]] and [[Denoising Diffusion Probabilistic Models]] by reimagining how conditioning information flows through the generation process. It connects to [[Autoregressive Models]] in spirit—applying sequence prediction to embeddings rather than tokens. The approach also touches on [[Transformer Architecture]] improvements, as it explores how transformer-based conditioning can be made more adaptive. Unlike [[RLHF]] or [[alignment]] research, this is purely generative; it differs from [[Adapter]] methods by predicting rather than learning fixed projections.

## Practical Applications
1. **Fast, Efficient Image Generation**: Reduced compute requirements make diffusion-based image generation more accessible for consumer hardware and production systems with strict latency constraints.
2. **Adaptive Conditional Image Synthesis**: Real-time applications (e.g., interactive design tools) where the conditioning signal needs to evolve based on intermediate generation state.
3. **Resource-Constrained Deployment**: Mobile or edge devices where running smaller NEPA + DiT models is preferable to large monolithic generators.
4. **Fine-grained Control**: Systems where generation quality can improve by having the model "reason" about what embedding should guide each denoising step, rather than relying on a static prompt.

## Product & Startup Ideas
1. **Low-Latency Image Generation API**: A cloud service offering fast, cost-efficient image generation via NEPA-DiT, undercutting latency/cost of existing diffusion APIs by 2–3×.
2. **Adaptive Design Assistant**: An interactive design tool (Figma-like) that generates or refines images in real-time, with conditioning that evolves as the user refines their intent.
3. **Mobile Image Synthesis App**: Consumer mobile app for on-device image generation (e.g., art, profile pictures), leveraging the compute efficiency to run without internet.
4. **Conditional Image Search & Retrieval**: A search engine that uses predicted embeddings to rank and generate images matching dynamic, multi-step user queries (e.g., "make it brighter, now add texture").
5. **Enterprise Content Generation**: B2B platform for e-commerce or media companies to auto-generate product images or thumbnails with adaptive conditioning for consistency and quality at scale.

## Technical Limitations
1. **Single-Network Overhead**: While efficient overall, NEPA adds a second transformer to every sampling step, which could be problematic in extremely latency-critical scenarios (e.g., interactive real-time rendering).
2. **Limited Evaluation Scope**: Experiments focus only on class-conditional ImageNet 256×256. Generalization to text-to-image, higher resolutions, or more complex conditioning (e.g., multiple attributes) is unexplored.
3. **Embedding Prediction Errors**: No analysis of how errors in NEPA predictions propagate through generation or degrade final image quality; unclear how robust the method is to prediction mistakes.
4. **Lack of Theoretical Justification**: Why predicted embeddings should work better than static ones lacks formal motivation; intuition is reasonable but not rigorously justified.
5. **Scalability Questions**: Does the 1/3 compute savings hold at higher resolutions or with larger base models? Training stability and convergence behavior at different scales are not thoroughly examined.

## Open Questions
1. How does NEPA embedding prediction degrade gracefully? What happens if NEPA predicts poorly for a given noise step, and can the generator recover?
2. Can this approach extend to text-to-image or multi-modal conditioning, where the embedding space is more complex?
3. Is there a way to distill or compress NEPA to eliminate or reduce the per-step inference overhead?
4. How sensitive is the method to NEPA architecture, training data, and hyperparameters? Could NEPA be jointly optimized with DiT end-to-end?
5. Could predicted embeddings improve other aspects of image generation (e.g., diversity, semantic consistency across generations)?

## Key Takeaway
Predicting dynamic embeddings at each denoising step improves image generation efficiency, cutting training compute by two-thirds while maintaining quality.
