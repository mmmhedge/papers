# Multi-Depth Temporal Fusion for Feedforward, Locally Trained Spiking Neural Networks

**Authors:** Aidin Attar, Eleonora Cicciarella, Michele Rossi
**Published:** 2026-09-29 | **arXiv:** [2609.37047v1](http://arxiv.org/abs/2609.37047v1)

## Summary
This paper presents a new spiking neural network (SNN) architecture that processes images and event streams using biologically-inspired spike timing. The key innovation is Multi-Depth Temporal Fusion (MDTF), which combines early and late temporal features intelligently rather than replacing them, and trains the network using only local learning rules (STDP). The work matters because it achieves strong image classification while remaining efficient and trainable without backpropagation — important for neuromorphic hardware and energy-constrained systems.

## Theoretical Background
Spiking neural networks (SNNs) are neural networks that communicate via sparse, event-driven spikes rather than continuous activations, mimicking biological neurons. Time-to-first-spike (TTFS) encodes information in the latency between stimulus onset and first spike — earlier spikes signal stronger evidence. Spike-timing-dependent plasticity (STDP) is a local learning rule inspired by neuroscience that strengthens or weakens connections based on the precise timing of pre- and post-synaptic spikes. The paper builds on traditional feedforward CNN architectures but replaces global backpropagation with local, online learning mechanisms. Residual connections (skip connections that preserve earlier feature maps) are borrowed from deep learning but adapted here to preserve temporal information across layers, not just identity mappings.

## Core Contributions
1. **Multi-Depth Temporal Fusion (MDTF)**: A novel fusion strategy that preserves early spike latencies and selectively integrates intermediate and deeper features only when they temporally agree — avoiding information loss from naive feature replacement.
2. **Local training framework**: Demonstrates that fully unsupervised STDP (for the backbone) plus reward-modulated STDP (for classification) can achieve competitive accuracy without global backpropagation, enabling online, layer-wise learning.
3. **Strong empirical validation**: Shows +18.2 percentage-point and +29.2 percentage-point improvements over traditional STDP/R-STDP baselines on Fashion-MNIST and CIFAR-10, respectively.
4. **Data efficiency analysis**: Proves the network maintains high accuracy even when removing 50%+ of late or weak spikes, confirming sparse event processing is sufficient.

## Connections to Other Work
This work sits at the intersection of [[neuromorphic computing]] and [[biologically-plausible learning]] — it pushes SNNs toward practical performance on standard vision benchmarks while respecting biological constraints. It extends classical [[spike-timing-dependent plasticity|STDP]] research by combining it with multi-scale temporal reasoning, akin to how [[residual networks]] in standard deep learning preserve multi-scale features. The use of consensus mechanisms for temporal fusion parallels ensemble and attention-like approaches in conventional networks, but applied here to spike latencies. It addresses a key tension in SNNs: achieving high accuracy without sacrificing the efficiency and learnability that make SNNs attractive on neuromorphic hardware.

## Practical Applications
1. **Neuromorphic edge devices**: Embedded visual processing on ultra-low-power neuromorphic chips (e.g., Intel Loihi, IBM TrueNorth) for autonomous robots, drones, or IoT sensors.
2. **Event camera processing**: Real-time object detection and classification from dynamic vision sensors (DVS), which output sparse spike-like events natively.
3. **Low-latency real-time inference**: Security cameras or autonomous vehicles needing sub-millisecond decisions with minimal power draw.
4. **Online learning systems**: Adaptation and learning on the device without cloud connectivity, preserving privacy and enabling rapid domain adaptation.

## Product & Startup Ideas

2. **Wearable health monitoring**: Glasses or ear-worn devices running SNNs locally for real-time gesture or activity recognition with days of battery life.

## Technical Limitations
1. **Still lags dense networks on large-scale tasks**: CIFAR-10 performance is good but likely below state-of-the-art ResNets or Vision Transformers; scalability to ImageNet not demonstrated.
2. **TTFS bottleneck**: Information is compressed into first-spike latency, which limits representational capacity compared to rate-coded or burst-coded SNNs.
3. **STDP convergence uncertainty**: Local learning rules lack global optimization guarantees; training dynamics and convergence speed not theoretically characterized.
4. **Hardware mismatch**: Neuromorphic hardware constraints (e.g., limited on-chip memory, arbitrary connectivity restrictions) not explicitly modeled; results may not transfer directly.
5. **Limited event-stream validation**: Most results on static images converted to spike latencies; evaluation on real event cameras (DVS) with natural dynamics is minimal.
6. **Hyperparameter sensitivity**: No analysis of sensitivity to STDP learning rates, time constants, or reward signal design; reproducibility across domains unclear.

## Open Questions
1. How does MDTF generalize to deeper networks (>4 layers)? Does fusion benefit saturate or become unstable?
2. Can reward-modulated STDP learn without external reward signals — e.g., through self-supervised objectives (contrastive learning)?
3. What is the theoretical convergence guarantee (if any) for the proposed local learning pipeline? Can it match backprop in the limit?
4. How do real DVS event streams (with temporal dynamics, flicker, noise) affect TTFS encoding and MDTF fusion?
5. Can this architecture transfer to other modalities (audio, sensor fusion)?
6. Is there a principled way to learn fusion weights or thresholds in MDTF, rather than fixing them heuristically?

## Key Takeaway
SNNs with temporal fusion and local learning now match standard networks on image tasks while using far fewer spikes and no backpropagation.
