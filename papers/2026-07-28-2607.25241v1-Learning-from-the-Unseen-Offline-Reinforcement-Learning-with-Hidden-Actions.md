# Learning from the Unseen: Offline Reinforcement Learning with Hidden Actions

**Authors:** Zeyu Bian, Ying Zhou, Yifan Cui
**Published:** 2026-07-28 | **arXiv:** [2607.25241v1](http://arxiv.org/abs/2607.25241v1)

## Summary
This paper tackles offline reinforcement learning in a realistic but understudied setting: when the dataset contains only noisy proxies for true actions, not the actions themselves. The authors develop LURE, a statistically principled estimator that recovers policy values from such incomplete data and validate it on medical decision-making (sepsis treatment). This matters because real-world datasets—clinical records, logs from automated systems—often hide the actual decisions behind measurements or side effects.

## Theoretical Background
Offline reinforcement learning (RL) learns policies from fixed historical datasets without online interaction. Standard methods assume actions are directly observed; this breaks when data contains only indirect signals. The paper leverages causal inference ideas: specifically, the observation that next states encode information about hidden actions in Markov decision processes (MDPs — sequential decision models where the future depends only on the current state). The authors use influence functions (a statistical tool measuring how individual data points affect an estimator) and multiple robustness (an estimator remains consistent if any one of several nuisance models is correctly specified), concepts borrowed from semiparametric statistics and causal inference.

## Core Contributions
- **First formalization** of offline RL with hidden actions and identification conditions (when policy values become recoverable from data)
- **LURE estimator**: explicitly designed for this setting, multiply robust, and asymptotically normal (enabling confidence intervals and hypothesis tests)
- **Proof that next-state information suffices** to identify policies under hidden actions in infinite-horizon discounted MDPs
- **Empirical validation** on synthetic tasks and MIMIC-III clinical data for sepsis management

## Connections to Other Work
This extends [[offline reinforcement learning]] by handling a real-world data quality issue that standard methods ignore. It bridges classical [[causal inference]] (particularly double robustness and semiparametric estimation) with policy evaluation. Related: work on confounding in RL, measurement error in observational studies, and off-policy evaluation robustness. The multiply robust structure echoes recent trends in making RL estimators more stable across model misspecification.

## Practical Applications
- **Clinical decision support**: MIMIC-III application directly shown; learning treatment policies from patient records where exact doses/timings are incomplete or noisy
- **Autonomous systems logs**: Learning from robot or vehicle behavior when sensors provide indirect action signals
- **Financial trading**: Inferring investment decisions from transaction effects when actual orders are proprietary or partially obscured
- **Recommendation systems**: Learning user preference models from clickstreams where true user intent is latent

## Product & Startup Ideas
1. **Clinical RL platform**: SaaS tool for hospitals to extract treatment policies from EHR data without manual action annotation—sell to hospital networks as decision-support add-ons
2. **Offline RL for IoT**: Startup offering policy learning from noisy smart-home or industrial sensor data where true device actions are hidden; target facilities management companies
3. **Financial backtesting with hidden orders**: Tool for hedge funds to infer trading strategies from market impact and price movements when order books are incomplete (regulatorily sensitive but valuable)
4. **Autonomous vehicle policy audit**: Service to extract and audit driving policies from fleet telemetry where exact control inputs are lossy
5. **Robotics data monetization**: Platform for manufacturers to learn manipulation policies from logs without sharing raw action streams—enables privacy-preserving policy transfer

## Technical Limitations
- **Assumption of Markov structure**: Requires that next states carry sufficient information about actions; breaks if actions have delayed effects or hidden state matters
- **Infinite-horizon discount factor**: Finite-horizon problems (common in practice) may need separate treatment
- **Identification conditions**: Still requires some correct nuisance model specification; purely misspecified models will fail
- **Computational complexity**: Not addressed; scalability to high-dimensional state/action spaces unclear
- **Sample complexity**: Asymptotic normality proved but finite-sample rates and required dataset sizes not derived
- **Causal assumptions**: Relies on standard SUTVA-like assumptions (no interference, positivity) that may not hold in all applications

## Open Questions
- What are finite-sample complexity bounds? How large must datasets be for good estimation?
- Can you extend LURE to finite-horizon or episodic settings?
- How to handle settings where next-state information is *also* partially observed?
- Does the method scale to high-dimensional continuous state/action spaces, or does performance degrade?
- Can you combine LURE with function approximation (neural networks) and retain theoretical guarantees?
- How sensitive is LURE to violations of the Markov assumption?

## Key Takeaway
Learning policies from data where true actions are hidden is now theoretically and empirically tractable using next states as proxies.
