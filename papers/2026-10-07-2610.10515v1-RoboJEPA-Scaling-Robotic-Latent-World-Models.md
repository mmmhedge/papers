# RoboJEPA: Scaling Robotic Latent World Models

**Authors:** Artem Zholus, Nicolas Beltran-Velez, Jianhao Yuan, Sarath Chandar, Tushar Nagarajan et al.
**Published:** 2026-10-07 | **arXiv:** [2610.10515v1](http://arxiv.org/abs/2610.10515v1)

## Summary
This paper introduces RoboJEPA, a large-scale world model (8 billion parameters) that learns to predict future robot states from images across 12 different robot embodiments. The key finding is that prediction error follows a predictable power law with compute, and this error reliably predicts how well the model can actually control real robots — solving long-horizon tasks without any task-specific training.

## Theoretical Background
World models are neural networks that learn an internal representation of an environment's dynamics — they predict "what happens next" given a current state and action. This paper builds on the Joint Embedding Predictive Architecture (JEPA), which learns to predict future states in a learned latent space (a compressed representation) rather than directly predicting raw pixels. The core insight is borrowed from language model scaling research: the idea that model capabilities often improve predictably as a function of scale (power laws), which lets researchers extrapolate performance beyond what they can directly measure. Multi-embodiment learning means training a single model on data from many different robot types, which can improve generalization.

## Core Contributions
- **Establishes empirical scaling laws for robotic world models**: Shows that imagination error (prediction error in latent space) follows a second-order power law in compute, allowing reliable extrapolation beyond trained scales.
- **Demonstrates zero-shot robotic control**: The learned world model can plan and execute long-horizon tasks on real robots by treating a goal image as a target and generating action sequences to reach it — no task-specific fine-tuning required.
- **Validates imagination error as a proxy metric**: Proves that latent prediction error is strongly correlated with downstream planning performance, meaning researchers can evaluate model quality without expensive real-robot rollouts.
- **Multi-embodiment scaling at unprecedented scale**: First to show that scaling laws hold across multiple robot morphologies trained on real-world data, and releases the largest JEPA model (8B parameters) trained to date along with code and checkpoints.

## Connections to Other Work
This work sits at the intersection of [[generative-models]] (learning to predict future observations), [[agents]] (using models for planning and control), and scaling law research pioneered in [[large-language-models]]. It extends JEPA, which was originally developed for vision tasks, to the robotics domain. The zero-shot planning approach relates to goal-conditioned reinforcement learning and inverse models, but uses a learned world model rather than explicit reward functions. The scaling law findings echo discoveries in transformer-based [[large-language-models]] and suggest that robotics may benefit from similar "scale first" development strategies.

## Practical Applications
- **Robot fleet management**: A single large world model can control many different robot types (arms, mobile bases, humanoids), reducing the need for embodiment-specific training pipelines.
- **Sim-to-real transfer shortcuts**: Scaling laws let engineers predict real-world performance without expensive robot hardware experiments, accelerating development cycles.
- **Long-horizon manipulation**: Tasks like "pick up object X and place it on shelf Y" can be specified as goal images, enabling robots to plan multi-step strategies without explicit reward engineering.
- **Zero-shot task generalization**: New tasks can be specified via goal images without retraining, useful for dynamic industrial and warehouse environments.
- **Robot learning data efficiency**: Scaling laws show how much data is needed to reach target performance, informing data collection strategies for new embodiments.

## Product & Startup Ideas
1. **RoboScale**: A cloud platform that trains and hosts large multi-embodiment world models; robotics labs pay per inference to get zero-shot planners for new tasks without owning training hardware.
2. **GoalBot SaaS**: A no-code interface where warehouse/manufacturing operators specify robot tasks as images or videos; the backend uses RoboJEPA-like models to generate control policies instantly.
3. **Embodiment Marketplace**: Open-source ecosystem where roboticists contribute hardware data to a shared world model pool; contributors get access to a pre-trained 8B+ model that works on their robot type.
4. **Robotics Lab-in-a-Box**: Pre-trained world model weights + lightweight inference engine; robotics startups download and deploy for their custom embodiment with minimal compute.
5. **Predictive Robot Simulator**: Sell the scaling law framework and tools as a service; researchers estimate robot capability requirements (latency, horizon, accuracy) and get cost/compute recommendations.

## Technical Limitations
- **Multi-embodiment bias**: While training across 12 embodiments improves generalization, it may also average away embodiment-specific optimal behaviors; unclear if the trade-off is always favorable.
- **Goal image specification**: Requiring a goal image limits applicability to tasks without clear visual targets (e.g., "move smoothly at 0.5 m/s" or contact-based tasks).
- **Prediction error may not capture all failure modes**: Imagination error correlates with planning performance, but this doesn't guarantee robustness to distribution shifts or unseen obstacles.
- **Compute scaling limits**: Power law fits break at some scale; the paper doesn't identify where saturation occurs or if the law holds beyond 8B parameters.
- **Real-world data diversity**: All training data comes from existing robot setups; new embodiments or environments may violate the scaling law assumptions.
- **No guarantees on safety-critical tasks**: Zero-shot planning could fail unpredictably in safety-critical applications; the paper doesn't address failure recovery or human-in-the-loop correction.

## Open Questions
- **Where does the power law break?** Does imagination error saturation set a hard ceiling on real-world performance, or do larger models find qualitatively different solution strategies?
- **Transfer to novel embodiments**: How do scaling laws generalize to robot morphologies unseen during training? Is there a minimum data quantity per new embodiment?
- **Multimodal prediction**: Can the model learn multiple plausible futures (e.g., objects rolling in different directions)? Does multimodality degrade or improve planning?
- **Failure analysis**: What types of tasks or scenes cause the model to make high-magnitude prediction errors? Are there systematic blind spots?
- **Efficiency trade-offs**: Is an 8B parameter model necessary, or do smaller models + test-time compute scaling (like chain-of-thought for robots) achieve similar planning performance?
- **Closed-loop vs. open-loop planning**: All results appear to be open-loop (plan once, execute). How does performance degrade without replanning, and can the model learn to replan adaptively?

## Key Takeaway
Robotic world models improve predictably with scale, and their prediction error directly predicts real-world task success without needing physical robot experiments.
