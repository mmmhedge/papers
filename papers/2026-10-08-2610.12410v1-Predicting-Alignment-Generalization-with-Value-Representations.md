# Predicting Alignment Generalization with Value Representations

**Authors:** Andy Liu, Mehar Bhatia, Karolina Stanczak, Mona Diab, Vered Shwartz et al.
**Published:** 2026-10-08 | **arXiv:** [2610.12410v1](http://arxiv.org/abs/2610.12410v1)

## Summary
This paper tackles a critical problem in LLM safety: when you fine-tune a model to follow one value or behavior (like "be helpful"), it often changes how it behaves on other values in unexpected ways. The authors develop methods to predict these "spillover effects" and find that analyzing what happens inside the model when it processes values works much better than just reading descriptions of those values. They also create the first empirical taxonomy of LLM values based on how they actually generalize.

## Theoretical Background
This work sits at the intersection of three areas. First, [[alignment]] — the challenge of making AI systems behave according to human values — which typically involves post-training techniques like reinforcement learning from human feedback (RLHF) or supervised fine-tuning. Second, [[mechanistic-interpretability]] — understanding what's happening inside neural networks — which here focuses on model activations (the intermediate numerical representations produced by different layers). Third, representation learning — the idea that you can capture what a concept "means" to a neural network by looking at patterns in its internal states rather than descriptions. Prior work has shown that fine-tuning on narrow behavioral targets can cause unintended downstream effects, but there's been little systematic study of whether and how to predict these effects.

## Core Contributions
1. **Formalizes alignment generalization prediction** — introduces a clear task of predicting how fine-tuning on one value generalizes to held-out values, and constructs a large-scale "generalization matrix" across 66 real-world values.
2. **Activation-based value representations vastly outperform text** — shows that correlations of 0.45 can be achieved by analyzing what activations the model produces when applying values in context, versus only 0.05 from text-based baselines (a 9× gap).
3. **Links value similarity to model robustness** — demonstrates that the learned value representations can predict which combinations of values in a multi-value alignment target will lead to more robust models.
4. **Discovers evidence of a shared value space** — proposes that values may cluster in a model-independent semantic space, grounded in actual generalization dynamics rather than human intuition.

## Connections to Other Work
This extends long-standing concerns in [[alignment]] about specification gaming and value drift — where training for one objective causes unintended side effects. It also relates to work on measuring concept similarity in neural networks (e.g., centered kernel alignment, probing classifiers) and [[mechanistic-interpretability]] research on understanding what models learn. The paper's finding that *internal representations matter more than descriptions* echoes broader insights that neural networks encode concepts in ways humans don't easily articulate. Finally, it connects to work on behavioral compatibility and multi-objective optimization in [[reinforcement-learning]].

## Practical Applications
1. **Alignment target design** — before deploying a model, developers could use these methods to predict whether a proposed set of values will cause harmful spillovers, enabling safer policy selection.
2. **Red-teaming and robustness testing** — identify which value combinations are most likely to conflict, prioritizing stress-testing on those combinations.
3. **Transfer learning across organizations** — when one AI lab wants to adapt a model trained by another, these representations help predict whether the downstream values will generalize cleanly.
4. **Multi-objective model tuning** — optimize which values to emphasize during training to maximize both compliance and robustness on held-out scenarios.

## Product & Startup Ideas
1. **AlignmentLens** — a hosted API that takes an LLM, a proposed set of values, and returns a predicted generalization matrix showing spillover risks before deployment.
2. **ValueTax** — a diagnostic tool for model developers showing which value combinations are "risky" and recommending alternative framings based on the empirical value taxonomy.
3. **RobustAlign** — a fine-tuning service that automatically selects value training weights based on predicted generalization patterns to maximize downstream robustness.
4. **ValueAudit** — third-party compliance platform that organizations use to verify their LLMs won't generalize harmful side effects when exposed to new contexts (regulatory reporting).
5. **CoherenceScore** — a model evaluation product that benchmarks how cleanly a model's value representation generalizes across deployment domains.

## Technical Limitations
1. **Limited to 66 predefined values** — generalization to new, unseen values not in the training set is unvalidated; the taxonomy may not be exhaustive.
2. **Activation-based methods require model access** — can't be applied to black-box APIs or closed-source models, limiting real-world use.
3. **Correlation of 0.45 is modest** — while much better than 0.05, it still leaves substantial prediction error; real-world deployment would require higher confidence.
4. **Single-model evaluation** — unclear whether learned representations transfer across different LLM architectures or families without retraining.
5. **Causality unclear** — the paper shows correlation between value similarity and robustness, but doesn't establish causal mechanisms or why generalization happens.
6. **Post-training context** — focused on fine-tuned models; unclear how this applies to base models or other training paradigms.

## Open Questions
1. **Transfer and generalization across models** — do learned value representations work on GPT, Claude, Llama? Or must they be re-learned per model?
2. **Temporal stability** — if a model is updated or retrained, do its value representations and generalization patterns stay consistent?
3. **Mechanistic explanations** — *why* do certain values interact? Can we explain the generalization matrix through circuit analysis or other interpretability tools?
4. **Scaling** — does the method scale to hundreds or thousands of values? How does representational quality degrade?
5. **Interactive fine-tuning** — could these predictions be used in a closed-loop system to iteratively select training targets and predict outcomes, improving model alignment over time?
6. **Adversarial robustness** — can adversaries exploit predicted value interactions to induce specific harmful behaviors?

## Key Takeaway
Internal model activations predict how values will spill over and interact far better than text descriptions, enabling safer alignment design.
