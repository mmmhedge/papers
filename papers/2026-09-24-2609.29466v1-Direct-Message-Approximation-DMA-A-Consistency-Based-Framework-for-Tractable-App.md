# Direct Message Approximation (DMA): A Consistency-Based Framework for Tractable Approximate Inference on Factor Graphs

**Authors:** Ralf Herbrich, Rainer Schlosser, Jan Lemcke, Johann Ukrow, Anna Kazachkova et al.
**Published:** 2026-09-24 | **arXiv:** [2609.29466v1](http://arxiv.org/abs/2609.29466v1)

## Summary
This paper introduces Direct Message Approximation (DMA), a new framework for performing probabilistic inference on factor graphs — data structures used to represent probabilistic models. Unlike existing methods (expectation propagation and variational message passing), DMA approximates messages flowing between factors and variables directly, which avoids numerical instabilities and simplifies computation. The authors prove theoretical guarantees about approximation quality and demonstrate the approach works well for uncertainty quantification in Bayesian neural networks.

## Theoretical Background
Factor graphs are graphical models representing probability distributions as products of factors. Classical inference on these graphs uses message passing — variables and factors iteratively exchange information (messages) to compute marginal probabilities. Two dominant families exist: expectation propagation (EP) and variational message passing (VMP). EP and VMP both approximate marginal distributions at factor-variable edges, which requires iterative refinement and can produce numerical problems like negative-precision messages. The paper builds on the theoretical framework of probabilistic inference and information geometry, grounding approximation quality in Kullback-Leibler (KL) divergence — a standard measure of how much one probability distribution differs from another.

## Core Contributions
1. **Direct message approximation paradigm**: Rather than approximating marginals (the standard approach), DMA approximates factor-to-variable messages directly, circumventing the need for inner-loop iterations.
2. **Consistency condition**: For normalizable factors, a principled rule (exactness when all other incoming messages are point masses/Dirac deltas) governs message construction, ensuring messages remain well-behaved.
3. **Master theorem with guarantees**: A proof that bounds the error in final marginal probabilities (via KL divergence) in terms of message approximation error, holding for any graph topology. Three structural corollaries eliminate negative-precision messages, collapse-to-point-estimates issues, and inner-loop iterations.
4. **Closed-form product-factor message**: An explicit $O(1/r^2)$ convergence guarantee for the backward message of product factors — a case that has historically resisted exact treatment.
5. **Concrete instantiation for BNNs**: Explicit DMA messages for product and leaky-ReLU factors, assembled into a Bayesian neural network inference algorithm requiring only one forward/backward sweep per training example with no learning-rate tuning.

## Technical Limitations
1. **Scalability unclear**: No explicit complexity analysis or runtime comparisons against EP/VMP; applicability to very large graphs (e.g., 1M+ variables) is unstated.
2. **Non-normalizable factors**: The consistency condition applies only to normalizable factors; behavior on non-normalizable factors is not addressed.
3. **Graph type restrictions**: Guarantees are stated for "any graph," but the practical scope (loopy vs. tree-structured, heterogeneity of factor types) is unclear.
4. **Limited experimental validation**: The BNN experiments validate predictive uncertainty widening but lack systematic comparisons to existing approximate inference methods or uncertainty baselines.
5. **Approximate message quality**: While DMA avoids inner-loop iterations, the approximations to messages themselves (e.g., for product/leaky-ReLU) remain heuristic; no worst-case approximation guarantees are proven for these specific factors.
6. **Model mismatch assumption**: The paper mentions "model mismatch," but sensitivity analysis on misspecified models is absent.

## Open Questions
1. **Computational complexity**: What is the wall-clock time comparison versus EP/VMP on real-world factor graphs? Does DMA scale to industrial-scale graphical models?
2. **Extension to other factors**: Can the closed-form message constructions be derived for other common factors (e.g., softmax, Gaussian mixture)? Is there a general recipe?
3. **Convergence diagnostics**: How can practitioners know when DMA has converged? Are there practical stopping criteria that match the theoretical guarantees?
4. **Batch vs. online learning**: The paper uses one forward/backward sweep per training example; how does performance degrade with minibatching, and can the algorithm be adapted for efficient minibatch training?
5. **Comparison to VI and sampling**: How does DMA compare to modern variational inference libraries (e.g., Pyro, Stan) and MCMC/sampling methods on benchmark problems?
6. **Posterior approximation quality**: Beyond marginal KL bounds, how close are the approximate marginals to the true posterior? Are there empirical measures of posterior concentration?

## Key Takeaway
Direct message approximation eliminates hyperparameters and numerical instabilities in Bayesian neural network inference by approximating factor messages instead of marginals.
