# Policy-Invariant Reward Shaping from LLM Feedback: A Framework for Hybrid RL Agents

**Authors:** Christophe D. Hounwanou, John Emeka Eze, Yaé U. Gaba
**Published:** 2026-08-18 | **arXiv:** [2608.18008v1](http://arxiv.org/abs/2608.18008v1)

## Summary
This paper addresses how to safely use language models to guide reinforcement learning agents by formalizing the hybrid LLM-RL architecture and proving that LLM-generated reward signals can be used for "reward shaping" (adjusting rewards to guide learning) without changing which policies are actually optimal—even when the LLM makes mistakes. This matters because combining LLMs with RL is becoming common in practice, but the theoretical guarantees for doing so safely have been unclear.

## Theoretical Background
The paper builds on two main traditions. First, reward shaping in RL—a technique where you modify the reward signal to help an agent learn faster without changing the underlying optimal solution (rooted in potential-based reward shaping). Second, the growing practice of using LLMs as reward models or evaluators in RL (seen in approaches like [[RLHF]] and recent work on LLM-as-judge systems). The authors formalize this combination using Goal-Augmented Markov Decision Processes (MDPs)—an extension of standard MDPs that explicitly model goal-directed behavior. The key theoretical tool is the potential function, a mathematical object that guarantees reward shaping preserves optimality.

## Core Contributions
1. **Formal architecture**: The paper explicitly models the hybrid LLM-planner and RL-controller setup as a Goal-Augmented MDP, making the feedback loop mathematically explicit rather than ad-hoc.
2. **Policy-invariance guarantee**: They prove that when the LLM's per-state progress score is bounded and used as a potential function in reward shaping, the optimal policy set is preserved—even under significant LLM errors (tested up to 20× reward magnitude deviation).
3. **Stronger guarantee than prior work**: Unlike general "LLM-as-reward" approaches, this result guarantees policy optimality preservation rather than just hoping the LLM feedback helps.
4. **Empirical validation**: Verification on small MDPs including adversarial configurations demonstrates the theoretical result holds in practice.

## Connections to Other Work
This work sits between [[Reward Shaping]] (classical RL technique) and recent LLM-in-the-loop learning systems. It formalizes intuitions behind [[RLHF]] but goes further by providing optimality guarantees. Related to [[Alignment]] research insofar as using LLM feedback for RL is a core alignment strategy. Differs from work treating LLMs purely as reward models (which assume perfect LLM feedback) by explicitly tolerating bounded imperfection. Also connects to [[Agent]] design literature where hybrid architectures combining symbolic planning (LLM) and learning (RL) are increasingly standard.

## Practical Applications
1. **Robotic task learning**: Use an LLM to evaluate progress toward natural language goals (e.g., "make the bed") while RL tunes low-level motor control—safe even if the LLM's intermediate judgments are imperfect.
2. **Dialogue systems**: LLM feedback on conversation quality (coherence, helpfulness) shapes RL agent learning without requiring perfect human labels.
3. **Code generation and synthesis**: LLM judges code correctness; RL agent optimizes for more efficient or readable solutions while preserving correctness guarantees.
4. **Autonomous navigation**: LLM evaluates whether the agent is "making progress toward the destination" even if local estimates are noisy; shaping ensures the destination-reaching policy isn't corrupted.
5. **Content moderation**: LLM provides soft feedback on policy violations; RL agent learns to avoid harmful content while the shaping guarantee ensures moderation quality is preserved.

## Product & Startup Ideas
1. **LLM-guided RL training platform**: A SaaS tool for teams to build RL agents from natural language task descriptions and LLM feedback, with built-in policy-invariance guarantees and safety auditing.
2. **Robust reward modeling service**: An API that takes task specifications and returns formally-verified reward shapers (combining LLM evaluation with shaping guarantees), sold to robotics and autonomous systems companies.
3. **Hybrid agent for customer support**: A chatbot that uses LLM for conversation quality evaluation and RL for response optimization, marketed with formal safety guarantees to enterprises.
4. **Autonomous task execution**: A software platform for personal/business automation (e.g., scheduling, research, writing) where LLMs specify goals and RL agents execute efficiently, with provable convergence to correct behavior.
5. **Research collaboration tool**: A researcher productivity assistant that uses LLM feedback on research direction quality and RL to learn personalized work patterns, with theoretical guarantees on research output quality preservation.

## Technical Limitations
1. **Scalability unclear**: All experiments on small MDPs; it's unknown whether the bounding and potential function approach scales to high-dimensional problems common in modern RL (vision, language generation).
2. **Bounded potential assumption**: The guarantee requires the LLM score to be bounded. In practice, defining and enforcing these bounds for complex tasks is non-trivial.
3. **Per-state evaluation cost**: Using LLM feedback on every state could be prohibitively expensive (LLM queries are slow and costly); the paper doesn't address sparse or batched feedback.
4. **What "progress" means**: The framework assumes the LLM can meaningfully score per-state progress toward a goal. For open-ended or ill-defined goals, this breaks down.
5. **No distributional guarantees**: The result preserves the optimal policy set but says nothing about convergence rate or sample complexity—shaping might not actually speed up learning.
6. **Assumes goal clarity**: The Goal-Augmented MDP framework requires explicit, stable goal definitions; it doesn't handle goal drift or changing objectives.

## Open Questions
1. **Scaling**: Can this framework be extended and verified experimentally on high-dimensional problems (e.g., vision-based robotics or language generation tasks)?
2. **Empirical learning speed**: Does policy-invariant reward shaping actually accelerate learning compared to no shaping or naive LLM feedback? By how much?
3. **Adaptive bounds**: Rather than fixing the LLM potential bounds in advance, can you learn tight bounds online without breaking the guarantee?
4. **Sparse feedback**: What happens if you can only afford LLM feedback on occasional states? Can the guarantee be weakened gracefully?
5. **Partial observability**: The paper assumes full state observability. How does the result change under partial observability, which is realistic?
6. **Competing goals**: Many real tasks have multiple objectives. Does the approach extend to multi-objective reward shaping with LLM feedback?
7. **Non-Markovian feedback**: What if the LLM's progress judgment depends on trajectory history, not just the current state?

## Key Takeaway
LLM feedback can safely guide RL agents without corrupting optimal policies if structured as bounded potential-based reward shaping.
