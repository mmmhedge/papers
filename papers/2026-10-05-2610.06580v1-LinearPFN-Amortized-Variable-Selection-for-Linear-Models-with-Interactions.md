# LinearPFN: Amortized Variable Selection for Linear Models with Interactions

**Authors:** Louis Schiekiera, Max Zimmer, Christophe Roux, Manuel Arnold, Sebastian Pokutta et al.
**Published:** 2026-10-05 | **arXiv:** [2610.06580v1](http://arxiv.org/abs/2610.06580v1)

## Summary
This paper presents LinearPFN, a neural network that solves variable selection for linear models by amortizing Bayesian spike-and-slab inference — instead of running expensive computations for each new dataset, the network is trained once on synthetic data and then performs inference in a single forward pass. This addresses a fundamental computational bottleneck: traditional methods require rerunning Markov chain Monte Carlo for every dataset, which doesn't scale; LinearPFN trades that per-dataset cost for upfront pretraining.

## Theoretical Background
Spike-and-slab regression is a classical Bayesian approach to variable selection that represents uncertainty as a posterior distribution over which predictors are "active" (have non-zero effects) rather than committing to a single subset. The posterior distribution assigns inclusion probabilities to each candidate effect — a natural way to quantify selection uncertainty. However, computing this posterior exactly requires enumerating all possible subsets of predictors, which scales as 2^p (where p is the number of candidate effects); for large p, this becomes infeasible. Practitioners typically resort to Markov chain Monte Carlo (a sampling method) to approximate the posterior, but this must be rerun from scratch for each new dataset and may not converge within a fixed computational budget.

The paper uses prior-data fitting, a concept where a neural network (a transformer, specifically) is pretrained on synthetic data sampled from an explicitly specified prior distribution. The conjugate prior design ensures that for any fixed set of active effects, the posterior has a closed-form solution, allowing exact verification of the network's outputs.

## Core Contributions
1. **Amortized inference architecture**: Demonstrates that a transformer can learn to approximate spike-and-slab posteriors for linear models with main effects and pairwise interactions, eliminating per-dataset fitting costs.
2. **Conjugate prior by design**: Uses a prior structure that allows exact posterior computation for each fixed active set, enabling principled validation against ground truth on synthetic data where the true model is known.
3. **Empirical validation and robustness**: Achieves higher variable selection AUC and F1 scores than five classical baselines on real predictor matrices from social-science datasets, and maintains performance when model assumptions (coefficients, interactions, noise) deviate from the prior.
4. **Open-source release**: Provides both code and a pretrained model, enabling immediate practical adoption.

## Practical Applications
1. **High-dimensional genomics**: Variable selection in genome-wide association studies (GWAS) with thousands of genetic markers; practitioners need fast posterior uncertainty quantification without rerunning MCMC.
2. **Rapid epidemiological modeling**: Public health agencies modeling disease risk from dozens of demographic and environmental predictors; amortized inference enables real-time model updates as new data arrives.
3. **Economic and social-science research**: Exploratory analysis of survey data with many candidate predictors and interactions (e.g., how income, education, region, and their interactions affect health outcomes); researchers can instantly obtain posterior summaries without computational delays.
4. **Clinical decision support**: Feature selection in electronic health record data for patient risk stratification, where clinicians need both point estimates and uncertainty quantification in milliseconds.

## Product & Startup Ideas
1. **AutoML variable-selection API**: A cloud service wrapping LinearPFN that accepts a dataset and prior specification, returning posterior inclusion probabilities and predictive distributions via REST; target: data science teams avoiding MCMC tuning.
2. **Bayesian A/B testing platform**: Precompute posterior inclusion probabilities for online experiments with factorial designs; let experimenters query interaction effects instantly without Bayesian network analysis expertise.
3. **Interactive data exploration tool**: Desktop or web app where analysts upload data, specify a prior (or use default), and instantly see a ranked, uncertainty-quantified list of candidate effects; integrate with BI platforms.
4. **Federated healthcare analytics**: Train LinearPFN on institutional priors; deploy at multiple hospitals so each can run inference locally without sharing raw data or waiting for centralized MCMC.
5. **Econometric consulting accelerator**: Offer economists a "variable selection as a service" reducing project cycles for policy impact assessment from weeks (MCMC) to seconds.

## Technical Limitations
1. **Scope restriction**: Current version handles only linear models with main effects and pairwise interactions; genuine nonlinearity, high-order interactions, or nonparametric effects are out of scope.
2. **Prior dependence**: Performance degrades when the data-generating process deviates significantly from the assumed prior; the model must be refit for substantially different problem classes.
3. **Training data size**: Quality depends on the synthetic pretraining dataset; generating representative prior samples for very high-dimensional spaces (p >> 1000) may require enormous computational resources or careful prior engineering.
4. **Scalability for p**: While faster than MCMC, scaling to extremely large predictor spaces (p ~ 10^5) is unexplored; transformer computational cost grows quadratically in sequence length.
5. **Interaction explosion**: Pairwise interactions scale as O(p^2); extending to higher-order interactions is computationally and informationally challenging.

## Open Questions
1. **Can the amortization framework extend to generalized linear models** (logistic, Poisson, etc.) while preserving the conjugate-prior advantage and closed-form posterior?
2. **How sensitive is performance to prior misspecification** when p is very large and the prior has many hyperparameters? Can the method self-tune or learn robust meta-priors?
3. **Can we extend this to graphical model structures or sparse high-dimensional regression** (e.g., elastic net style priors) and still maintain amortization gains?
4. **Does the same pretraining generalize across different predictor covariance structures**, or must we retrain for each new data regime?
5. **How does performance compare to modern differentiable approximate inference methods** (e.g., variational autoencoders for Bayesian inference) on the same problems?

## Key Takeaway
A pretrained neural network performs Bayesian variable selection instantly, replacing slow per-dataset Markov chain Monte Carlo with a single forward pass.
