# ActiveSaddler: Automated Curriculum Learning for Agent Harness Optimization

**Authors:** Sungho Park, Wonjoong Kim, Jue Zhang, Wook-Shin Han, Pengfei Gao et al.
**Published:** 2026-10-01 | **arXiv:** [2610.00906v1](http://arxiv.org/abs/2610.00906v1)

## Summary
This paper introduces ActiveSaddler, a system that automatically improves LLM agents by adapting which training scenarios to use during optimization. Rather than fixing training data upfront, the method treats curriculum design as a dynamic bandit problem—continuously discovering failure patterns in the agent's behavior and prioritizing which ones to target for improvement. On two benchmarks, it improves agent performance by 4–8 percentage points over methods that use a static training curriculum.

## Theoretical Background
The work builds on two established ideas: (1) harness optimization for LLM agents — the iterative refinement of prompts, tools, and control logic based on execution feedback — and (2) curriculum learning — the practice of structuring training examples from easy to hard to improve learning efficiency. The novelty is marrying these: treating the choice of *which failures to target* as a non-stationary multi-armed bandit problem, where arms represent recurring failure patterns and rewards reflect expected learning progress. This draws on bandit theory (exploration-exploitation tradeoffs) and online learning (adaptation in changing environments).

## Core Contributions
1. **Formulation**: Casts curriculum design for harness optimization as automated curriculum learning — a missing optimization dimension that prior work overlooked.
2. **Algorithm**: ActiveSaddler uses a bandit framework that (a) abstracts repeated failures into reusable patterns, (b) estimates the potential learning progress from targeting each pattern, and (c) balances revisiting known weaknesses with discovering new failure modes.
3. **Co-evolution**: The curriculum adapts dynamically as the harness improves; the set of discovered failure patterns and their priorities are continuously updated.
4. **Empirical validation**: Demonstrates 4.4–7.5 percentage-point improvements over static curriculum baselines on GAIA2 and Terminal-Bench 2.0.

## Connections to Other Work
This work extends the harness optimization paradigm (related to [[prompt optimization]] and [[in-context learning]] for LLMs) by introducing an adaptive dimension inspired by [[curriculum learning]] and online bandit algorithms. It complements existing work that optimizes *how* harnesses are updated but have left the *what* (training data selection) fixed. The failure-pattern abstraction resonates with error analysis and failure mode discovery in LLM debugging, though applied here in an automated, bandit-theoretic framework.

## Practical Applications
1. **Agent reliability in high-stakes domains** (medical diagnosis, finance): Automatically improve agents by targeting their most impactful failure modes without human annotation.
2. **Tool-use optimization**: As agents gain access to new APIs or tools, the curriculum can discover which tool-use failures are most critical to address first.
3. **Rapid deployment of specialized agents**: For domain-specific chatbots or reasoning systems, automated curriculum learning reduces manual tuning and iteration time.
4. **Continuous improvement pipelines**: In production systems, the method could periodically re-discover emerging failure patterns and adapt training accordingly.

## Product & Startup Ideas
1. **Agent Optimization-as-a-Service**: A cloud platform that takes an LLM agent definition and automatically improves it via curriculum learning, charging per optimization cycle.
2. **Failure-Pattern Analytics Dashboard**: Real-time visualization of recurring agent failures and their priorities, helping teams understand where to focus engineering effort.
3. **Enterprise Agent Tuning**: Embed ActiveSaddler into internal agent platforms so non-ML teams can improve their bots without retraining from scratch.
4. **Curriculum-Guided Fine-Tuning**: Extend beyond prompts to automated selection of training data for continued fine-tuning of base models on domain tasks.
5. **Multi-Agent Coordination Optimizer**: Use curriculum learning to improve coordination protocols in multi-agent systems by adaptively targeting inter-agent failure modes.

## Technical Limitations
1. **Failure pattern abstraction**: The paper doesn't deeply specify how failures are clustered into patterns; ad-hoc or coarse clustering may miss nuanced distinctions.
2. **Bandit assumptions**: The non-stationary bandit model assumes rewards (learning progress estimates) are reasonably observable; in practice, noisy or delayed feedback could degrade performance.
3. **Scalability**: The method requires repeated execution and failure collection; computational cost and wall-clock time for large-scale agents aren't thoroughly discussed.
4. **Generalization**: Experiments are on two benchmarks (GAIA2, Terminal-Bench 2.0); unclear how well the approach transfers to qualitatively different agent types or domains.
5. **Exploration-exploitation tradeoff tuning**: The balance between revisiting known weaknesses and discovering new failures likely requires problem-specific tuning, limiting off-the-shelf applicability.

## Open Questions
1. How does performance scale with agent complexity, harness size, and execution cost?
2. Can the method detect when a failure pattern becomes obsolete (should be retired from the curriculum)?
3. How sensitive is the algorithm to the choice of failure-pattern abstraction? Can it learn the abstraction automatically?
4. How does ActiveSaddler interact with other harness optimization techniques (e.g., in-context example selection, tool chains)? Is there a unified optimization framework?
5. Can the learned curriculum transfer across different agents or domains, or must it be re-learned for each new task?

## Key Takeaway
Adaptive curriculum design, not just fixed training data, is crucial for improving LLM agents—the curriculum itself should evolve as the agent improves.
