# Learning Latent Memory States from Longitudinal Athlete Monitoring Data

**Authors:** Dae-Jin Lee
**Published:** 2026-08-06 | **arXiv:** [2608.06290v1](http://arxiv.org/abs/2608.06290v1)

## Summary
We propose a new unit of analysis for longitudinal data: the Latent Memory Table. The scientific contribution is not the encoder. It is that table, treated as a reusable statistical object on the same footing as a matrix of principal-component scores, a table of estimated random effects, or a table of predicted probabilities.

## Theoretical Background
Neural networks learn distributed representations from data. Their practical value depends on how well those representations preserve task-relevant information, generalize to new inputs, and can be computed efficiently.

The paper is positioned against prior approaches described in its abstract and asks whether a more targeted representation, evaluation method, or optimization procedure can improve the relevant trade-off.

## Core Contributions
1. We propose a new unit of analysis for longitudinal data: the Latent Memory Table.
2. A simulation study with known memory mechanisms shows that \(Q\) and rotation-invariant recovery scores discriminate genuine multivariate or personalized memory from negative controls and from misspecified windows, whereas regime classification accuracy alone does not.
