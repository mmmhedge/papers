# Solving Multi-Agent Sokoban via LaCAM

**Authors:** Keisuke Okumura
**Published:** 2026-09-30 | **arXiv:** [2609.39889v1](http://arxiv.org/abs/2609.39889v1)

## Summary
This paper presents Sokoban-LaCAM, a planning algorithm for Multi-Agent Sokoban — a puzzle where multiple agents must cooperatively push boxes onto target locations. The key insight is that recent advances in multi-agent pathfinding (MAPF) can be adapted to handle the harder problem of coordinating both task assignment and collision-free movement, scaling to dozens of agents while guaranteeing solutions will eventually be found.

## Theoretical Background
Multi-Agent Sokoban builds on two foundational areas. First, single-agent Sokoban is a classic AI planning benchmark — a state-space search problem where an agent navigates a grid and pushes boxes. Second, Multi-Agent PathFinding (MAPF) is a well-studied problem: given multiple agents on a graph, find collision-free paths for all of them simultaneously. MAPF algorithms use techniques like conflict-based search (CBS) — exploring the space of possible paths and resolving conflicts when agents would collide. The paper leverages MAPF as a "primitive" — a reusable subroutine — by embedding it within a higher-level planner that also decides which agent should push which box.

## Core Contributions
1. **Problem formulation**: Formally defines Multi-Agent Sokoban as a combination of task assignment (which agent pushes which box) and collision-free pathfinding.
2. **Sokoban-LaCAM algorithm**: Extends LaCAM (a recent MAPF algorithm) to handle the additional constraint that agents must push boxes to specific goals, not just reach arbitrary positions.
3. **Scalability proof**: Empirically demonstrates completeness (always finds a solution if one exists) and eventual optimality (finds better solutions over time) on instances with tens of agents — a significant scaling achievement for this combined problem.

## Connections to Other Work
This work sits at the intersection of [[classical planning]], [[multi-agent pathfinding]], and [[collective automation]]. It differs from pure MAPF by adding the task assignment layer — similar in spirit to problems like multi-robot task allocation, but integrated seamlessly with pathfinding. The approach also relates to warehouse automation systems and the broader class of collective manipulation problems where multiple agents must coordinate.

## Technical Limitations
1. **State space explosion**: Works well for tens of agents and boxes, but scalability to hundreds remains unclear.
2. **Unlabeled targets assumption**: The paper assumes boxes are interchangeable (no specific box-to-target pairing required). Many real warehouses have labeled assignments.
3. **Grid world assumption**: The algorithm assumes discrete grid movement; continuous spaces require discretization, potentially losing optimality.
4. **Offline computation**: Appears to be a complete offline planner; real-time replanning when goals or agents change is not addressed.
5. **No dynamic obstacles**: The approach doesn't handle moving obstacles, crowds, or dynamic goal updates mid-execution.

## Open Questions
1. How does performance scale beyond tens of agents? Are there phase transitions in solvability?
2. Can the algorithm handle dynamic goal reassignment — i.e., goals added/removed while the plan executes?
3. Does integrating learned heuristics (e.g., from neural networks) speed up search while preserving completeness?
4. How do approximate or suboptimal variants trade off quality for speed in real-time settings?
5. Can this extend to heterogeneous agents with different speeds or capabilities?

## Key Takeaway
MAPF algorithms can scale Multi-Agent Sokoban to dozens of agents by combining pathfinding with task assignment while guaranteeing optimal solutions.
