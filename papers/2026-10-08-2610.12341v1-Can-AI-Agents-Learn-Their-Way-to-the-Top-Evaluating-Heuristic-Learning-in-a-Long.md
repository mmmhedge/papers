# Can AI Agents Learn Their Way to the Top? Evaluating Heuristic Learning in a Long-Running Game Agent Competition

**Authors:** Kaisen Yang, Qingle Liu, Kejin Wang, Yicheng Zhao, Jieming Li et al.
**Published:** 2026-10-08 | **arXiv:** [2610.12341v1](http://arxiv.org/abs/2610.12341v1)

## Summary
This paper introduces Adversarial Heuristic Learning (AHL), a framework where AI agents use code generation and self-refinement to improve game-playing policies without changing their underlying model weights. The authors test this on AAArena, a benchmark of 12 competitive games with 1,920 human player programs, and show that agents like Claude can win some competitions but struggle with complex rule interpretation and long-horizon strategy — revealing both promise and hard limits in how well language models can learn adversarial game play from experience alone.

## Theoretical Background
This work builds on a lineage connecting traditional heuristic search (like minimax algorithms), modern reinforcement learning (where agents learn policies through trial and error), and recent advances in language models as reasoning engines. The key insight is treating an AI agent as a "learning engine" that doesn't retrain its weights but instead iteratively revises *executable code* (the game-playing policy) based on match outcomes and rule understanding. This bridges the gap between black-box RL (which requires gradient updates) and interpretable program synthesis — the agent reads rules, writes code, plays matches, analyzes replays, and edits code in a loop. The evaluation protocol mimics real competitive ladders, where agents are ranked by win-loss records under a fixed budget of matches.

## Core Contributions
1. **Formalization of Adversarial Heuristic Learning (AHL)**: A paradigm where agents refine game strategies via code generation and self-editing, keeping model weights constant.
2. **AAArena benchmark**: 12 authentic competitive games + 1,920 archived human programs, with a realistic competition protocol (opponent selection, budget constraints, replay analysis).
3. **Empirical findings**: Opus 5.5 with Claude Code won 6/12 gold medals; opponent selection and dense feedback improve learning; agents learn from both own replays (on-policy) and others' replays (off-policy).
4. **Failure analysis**: Complex rule specifications and long-horizon planning remain hard; no model topped all 6 remaining human ladders.

## Connections to Other Work
This extends [[reinforcement-learning]] beyond gradient-based updates to policy synthesis via code. It relates to [[mechanistic-interpretability]] in that the learned policies are human-readable code rather than opaque weight matrices. The replay analysis and learning from self-play echoes classical RL (e.g., AlphaGo), but applied to symbolic, interpretable strategies. It also touches on [[multi-agent-systems]] — agents must predict and adapt to opponent behavior. The fixed-weight constraint is novel: most LLM adaptation work (like [[RLHF]]) involves retraining, whereas AHL keeps the model frozen and only evolves the *program*.

## Practical Applications
1. **Game AI and esports**: Automated coaching systems that analyze pro player replays and suggest strategy refinements for competitive gaming.
2. **Educational game engines**: Tutoring systems that dynamically adapt difficulty and strategy hints by interpreting student performance and revising puzzle-solving policies.
3. **Automated strategy in board/tabletop games**: Chess, Go, or custom strategy games where agents compete in online leagues and improve via self-play and peer-replay analysis.
4. **Real-time tactical planning**: Military or logistics simulations where agents refine operational strategies under resource and time budgets without retraining.
5. **Adversarial testing**: Security and game-balance auditing where agents autonomously discover exploits and suggest patch strategies.

## Technical Limitations
1. **Rule interpretation bottleneck**: Agents struggle with complex, ambiguous, or poorly-specified rules; no automated way to validate that the agent's *understanding* of a game matches reality.
2. **Code-only learning**: The agent can only modify executable logic, not explore fundamentally new heuristics or learning algorithms; it's constrained to the search space of reasonable code variants.
3. **Sample efficiency**: Adversarial games are non-stationary (opponents adapt); fixed match budgets mean agents can't learn long-horizon strategies requiring thousands of samples.
4. **Generalization across games**: A model trained well on one game doesn't transfer; each new game requires re-prompt-engineering and cold-start learning.
5. **Scalability**: Evaluating 1,920 human baselines is expensive; real competitive ladders with thousands of players would be prohibitive.
6. **Opponent modeling**: Agents don't learn explicit models of opponent strategies, so they can't plan meta-strategies (e.g., "my opponent counters X, so I should play Y").

## Open Questions
1. How much does rule clarity/complexity affect learning? Can agents learn to ask clarifying questions or test hypotheses about ambiguous rules?
2. Does agent performance scale with model size or reasoning budget? Do smaller models with more compute rival larger models?
3. Can agents learn *transferable* heuristics that generalize across games with similar structure (e.g., different turn-based tactics games)?
4. What's the theoretical lower bound on match budget needed to reach human-level play? Is there a phase transition?
5. Can agents learn to model opponents explicitly (e.g., "this opponent favors aggressive opening") and exploit that?
6. How does performance degrade if human baselines are also learning/adapting in real time?
7. Could a multi-agent version where agents co-learn (e.g., via peer replay exchange) outpace single-agent learning?

## Key Takeaway
Language models can iteratively refine game strategies by writing and editing code, but struggle with complex rules and long-term planning in competitive settings.
