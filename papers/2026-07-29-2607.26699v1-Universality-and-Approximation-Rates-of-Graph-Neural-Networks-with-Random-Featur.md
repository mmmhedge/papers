# Universality and Approximation Rates of Graph Neural Networks with Random Features

**Authors:** Lukas Gonon, Thilo Meyer-Brandis, Niklas Weber
**Published:** 2026-07-29 | **arXiv:** [2607.26699v1](http://arxiv.org/abs/2607.26699v1)

## Summary
This paper proves that graph neural networks with random node features can learn any permutation-invariant or permutation-equivariant function on graphs, and derives specific rates showing how network complexity translates to approximation accuracy. The result is important because it rigorously justifies why random features improve GNNs and provides practical guidance on network sizing for desired accuracy.

## Theoretical Background
Graph neural networks (GNNs) are neural networks designed to operate on graph-structured data by passing messages between connected nodes. Prior work established that standard GNNs have fundamental expressiveness limits — they cannot distinguish certain non-isomorphic graphs. Adding random features to nodes has been shown empirically and in some cases theoretically to overcome these limits.

Permutation-equivariant neural networks (PENNs) are architectures that respect the symmetry of graph data: relabeling nodes shouldn't change the learned function in arbitrary ways. This paper extends universality results — which prove a class of functions can approximate any target function — from Euclidean spaces to permutation-equivariant functions on graphs. The key mathematical tool is showing that feedforward neural network components can combine to approximate smooth functions with explicit rates.

## Core Contributions
1. **Novel universality theorem** for permutation-equivariant neural networks: establishes that PENNs with partially random node features can approximate any measurable permutation-invariant or permutation-equivariant function on fixed-size directed graphs with multidimensional node and edge features.

2. **Explicit approximation rate bounds** for smooth functions ($k$-times continuously differentiable, $k \geq 2$): relates network architecture parameters (depth, sparsity) directly to approximation error — providing constructive guidance on how large a network must be to achieve a target accuracy.

3. **Characterization of random feature benefits**: quantifies precisely how random features enhance expressiveness compared to deterministic initializations.

## Connections to Other Work
This work extends classical universality theorems (e.g., for feedforward networks on Euclidean spaces) to the geometric setting of graphs while respecting their symmetries. It relates to fundamental questions in [[Graph Isomorphism Networks]] and [[Weisfeiler-Leman Test]] literature about GNN expressiveness limits. The random feature mechanism connects to [[kernel methods]] and [[neural tangent kernel]] theory, which also use randomness for expressiveness.

The result is complementary to empirical work on message-passing GNNs (GraphSAGE, GCN variants) that use random features heuristically; this paper provides the theoretical foundation.

## Practical Applications
1. **Graph classification**: Guarantee that sufficiently large GNNs can learn to classify molecular graphs, social networks, or citation networks without architectural limitations.

2. **Node embedding**: Certify that learned node representations can capture arbitrary symmetric properties (e.g., community structure) up to desired accuracy.

3. **Dynamic graph analysis**: Apply to temporal or evolving graphs where permutation symmetry is crucial and random initialization helps break ties.

4. **Combinatorial optimization on graphs**: Use approximation rate bounds to design networks for graph-based constraint satisfaction or routing problems with known accuracy guarantees.

## Product & Startup Ideas
1. **GNN AutoML tool**: Use approximation rate bounds to automatically recommend network size and random feature configurations for a target dataset and accuracy requirement, eliminating trial-and-error tuning.

2. **Graph learning certification service**: Provide customers with formal guarantees on approximation accuracy before training — useful for safety-critical domains (supply chain, infrastructure networks).

3. **Synthetic graph generator**: Exploit universality result to synthesize training graphs that certifiably test whether a GNN has learned the target function class.

4. **GNN-as-a-service with SLAs**: Offer graph learning APIs with accuracy guarantees backed by theoretical bounds, charging premium for higher accuracy tiers.

5. **Robustness auditor for GNNs**: Use approximation rate analysis to identify adversarial perturbations that degrade network performance below theoretical guarantees.

## Technical Limitations
- **Fixed graph size assumption**: Theory applies only to graphs of a specified fixed size; real applications need variable-size graph handling (which breaks permutation structure).
- **Smoothness requirement**: Approximation rate bounds assume $k$-times continuously differentiable target functions; not all graph properties (e.g., graph diameter, exact counting) are smooth.
- **Practical constants hidden**: Bounds likely contain exponential or polynomial dependence on graph size and feature dimension that may be loose; actual network sizes needed in practice could be much smaller than worst-case bounds suggest.
- **Random feature overhead**: Requires genuinely random features, not learned ones; this adds sampling variance and memory cost.
- **Multidimensional edge features**: Analysis assumes edge features exist and are multidimensional; sparse or binary edge weights may require different treatment.

## Open Questions
1. How tight are the approximation rate bounds in practice? Can empirical studies show whether worst-case constants are pessimistic?

2. Can the fixed-size assumption be relaxed to handle graphs with variable numbers of nodes while preserving permutation-equivariance?

3. Do the results extend to other GNN variants beyond message-passing (e.g., spectral methods, attention-based GNNs)?

4. What is the role of network depth vs. width in the approximation rate trade-off? Can you trade off deeper networks with sparse weights against shallow wide networks?

5. Can analogous universality results with rates be proven for temporal or streaming graphs where nodes/edges arrive dynamically?

## Key Takeaway
Random features enable graph neural networks to provably learn any symmetric function with explicit accuracy guarantees tied to network size.
