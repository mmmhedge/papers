# Reinformed Dreamer: An Asymmetric World Model Efficiently Trained through Latent Guidance

**Authors:** Gaspard Lambrechts, Adrien Bolland, Daniel Ebi, Damien Ernst
**Published:** 2026-07-28 | **arXiv:** [2607.26040v1](http://arxiv.org/abs/2607.26040v1)

## Summary

This paper improves how reinforcement learning agents learn world models—internal representations of their environment—by using additional information during training. The key innovation is "latent guidance," a technique that helps the agent's internal representations learn more useful features by comparing them against privileged information (extra state details available only during training). The result is faster, more stable learning across multiple benchmark tasks.

## Theoretical Background

Model-based reinforcement learning trains agents by having them learn a world model—a neural network that predicts how the environment will change in response to actions. This differs from model-free approaches, which directly learn policies without understanding the world's dynamics.

Asymmetric reinforcement learning exploits an information asymmetry: during training, the agent has access to privileged information (extra state details, such as exact object positions in a partially observable game), but during deployment, it only sees the raw observations it must act upon. This extra information acts as supervision, much like a student learning with hints that won't be available during exams.

Prior work (notably "Informed Dreamer") used this asymmetry to improve representation learning in world models. However, the paper identifies a specific limitation: the way privileged information is represented in these models doesn't capture all the useful structure available.

## Core Contributions

1. **Identification of a representational limitation** in Informed Dreamer: the algorithm's approach to encoding privileged information fails to fully utilize its structure for improving the learned world model.

2. **Latent guidance objective**: a new training signal that explicitly guides the agent's learned representations toward structures that align with privileged information, using a direct comparison in the learned (latent) space rather than observation space.

3. **Reinformed Dreamer algorithm**: combines the latent guidance objective with the Dreamer world-model framework, showing more consistent empirical gains than previous asymmetric methods across multiple benchmarks.

## Connections to Other Work

This work builds on [[Dreamer]], a foundational model-based RL algorithm that learns world models from observations. It extends [[Informed Dreamer]], which first explored asymmetric learning in this setting. The paper relates to broader themes in representation learning and curriculum learning—the idea that well-structured training signals can accelerate and stabilize learning. It also connects to privileged information learning (sometimes called "learning with auxiliary information"), which has roots in distillation and semi-supervised learning.

## Practical Applications

- **Robotics with simulation**: Train robot controllers in simulation where perfect state is available (e.g., joint angles, object positions), then deploy on real robots with only camera input. Latent guidance can accelerate learning of policies that transfer to reality.
- **Autonomous driving**: Use high-fidelity simulator data with complete state information during training to learn representations that work with camera/lidar data at test time.
- **Game AI**: Train agents on games where engine state is observable during training but only rendered observations are available in deployment.
- **Partial observability problems**: Tasks where agents have incomplete information about the world; training with occasional full-state glimpses (e.g., from privileged sensors or communication) can improve policies.

## Product & Startup Ideas

1. **Simulation-to-reality transfer platform**: A toolkit that automatically extracts privileged information from physics simulators and uses latent guidance to train policies that transfer to real robots with minimal real-world data.

2. **Faster game AI development**: A game engine plugin that uses latent guidance to speed up NPC or opponent training, reducing real-world simulation hours needed per AI agent.

3. **Autonomous vehicle pre-training service**: Cloud platform that leverages CARLA or similar simulators with latent guidance to produce pre-trained driving models customers fine-tune with real data.

4. **Multi-sensor fusion learning**: Software that optimizes sensor configuration and training by treating high-cost sensors (e.g., LIDAR) as privileged information during training, then deploying with cheaper sensors.

5. **RL consulting for industrial control**: Advisory service helping manufacturers deploy model-based RL by setting up asymmetric training regimes that use lab/simulation data to train policies for noisy factory environments.

## Technical Limitations

- **Privileged information availability**: The method requires access to extra state information during training. In many real domains (e.g., robotics), obtaining this ground truth is expensive or impossible, limiting applicability.
- **Sim-to-real gap**: Even with latent guidance, a mismatch between simulator state and real-world observations can cause learned policies to fail; the paper doesn't address this explicitly.
- **Scalability unclear**: Most experiments are on relatively simple benchmarks (Atari, control tasks). Performance on high-dimensional, complex environments remains untested.
- **Computational cost**: The latent guidance objective adds training overhead; the paper doesn't thoroughly analyze computational efficiency gains or losses.
- **Generalization within training distribution**: No analysis of how well representations learned via latent guidance generalize to new privileged information patterns or domain shifts during training.

## Open Questions

- How does latent guidance perform when privileged information is noisy or partially incorrect?
- Can latent guidance be combined with other representation learning objectives (contrastive learning, world model diversity) for further gains?
- How sensitive is the method to the choice of which information is "privileged"? Could automated selection of privileged features improve results?
- Does latent guidance improve sample efficiency in low-data regimes (e.g., robotics with limited real-world interaction)?
- How does this approach scale to very high-dimensional privileged information (e.g., multiple camera views, LiDAR clouds)?

## Key Takeaway

Latent guidance helps RL agents learn better world models by aligning internal representations with privileged information available only during training.
