# Algorithmic Separation between Constant-Depth and Logarithmic-Depth Neural Networks

**Authors:** Yunwei Ren, Zihao Wang, Jason D. Lee
**Published:** 2026-07-28 | **arXiv:** [2607.25200v1](http://arxiv.org/abs/2607.25200v1)

## Summary
This paper proves that neural networks with logarithmic depth can efficiently learn certain Boolean functions that constant-depth networks fundamentally cannot learn well. The result matters because it's the first rigorous algorithmic separation between these two depth regimes — showing that depth isn't just theoretically useful for approximation, but actually changes what a network can learn *efficiently* during training.

## Theoretical Background
Prior work on neural network depth has mostly focused on approximation theory — proving that deep networks can represent more functions with fewer parameters than shallow ones. However, algorithmic separations (showing learning efficiency differs) have been rare and limited to shallow cases (comparing 2-layer vs 3-layer networks). This paper builds on Fourier analysis of Boolean functions — a framework where functions are decomposed into frequency components — and uses coordinate descent as the learning algorithm (a simple, well-understood optimization method where you iteratively update one variable at a time). The key insight is that some Boolean functions have hierarchical Fourier structure that logarithmic-depth networks can exploit layer-by-layer, but constant-depth networks cannot.

## Core Contributions
1. **First algorithmic separation at scale**: Proves logarithmic-depth networks learn a class of hierarchically-structured Boolean functions in polynomial time via layerwise coordinate descent, while constant-depth polynomial-width networks with regular activations incur constant $L^2$ error.
2. **Constructive learning algorithm**: Shows explicitly how depth enables hierarchical, adaptive reconstruction of Fourier spectra — deeper networks can "build up" solutions layer-by-layer.
3. **Hardness for shallow networks**: Establishes that constant-depth networks with controlled spectral norms fundamentally fail on these functions, not due to optimization difficulty but approximation limitations.

## Practical Applications
- **Architecture design**: Provides theoretical justification for using deeper networks in settings with hierarchical data structure (e.g., compositional/modular tasks).
- **Learning theory for practitioners**: Helps predict which problems benefit from depth, informing decisions about network design for new domains.
- **Curriculum learning**: Suggests layer-by-layer training strategies for hierarchically-structured problems may be fundamentally more efficient.
- **Boolean satisfiability & constraint solving**: Results apply to learning solutions to structured constraint problems.

## Technical Limitations
- **Restriction to Boolean functions**: Results don't directly apply to continuous/real-valued problems common in practice.
- **Uniform distribution assumption**: Hardness results assume uniform distribution over hypercube; real data may have different structure that helps shallow networks.
- **Coordinate descent only**: Algorithm uses simple coordinate descent; unclear if backpropagation or other modern optimizers have different behavior.
- **Regular activations required**: Hardness requires restrictions on activation functions and spectral norms — may not hold for ReLU networks in practice.
- **Polynomial width requirement**: The constant-depth networks must have polynomial width; the result doesn't constrain exponentially-wide shallow networks.
- **Implicit assumptions about hierarchy**: Theory assumes hierarchical Fourier structure exists; many real problems lack this structure.

## Open Questions
1. Do these separations hold beyond coordinate descent? What about stochastic gradient descent or backpropagation dynamics?
2. Can the hierarchical Fourier class be characterized more broadly — what properties of real datasets match this structure?
3. Can you extend to approximate learning of these functions by shallow networks? Is there a trade-off between depth and approximation error?
4. Do layerwise training methods (as suggested by the algorithm) actually converge faster in practice on these problems?
5. What happens with other activation functions (especially ReLU, Sigmoid) — does the hardness still hold?
6. Can this framework explain depth separations in practical vision or NLP domains?

## Key Takeaway
Deeper networks can efficiently learn some problems that shallow networks fundamentally cannot — a first algorithmic proof of why depth matters.
