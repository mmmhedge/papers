# On Learning Optimal Corners in Orthogonal Partially Observable Cooperative Guard Art Galleries

**Authors:** Yassin Ben Mansour, Edwin Meriaux
**Published:** 2026-10-05 | **arXiv:** [2610.06777v1](http://arxiv.org/abs/2610.06777v1)

## Summary
This paper combines formal verification with machine learning to solve the cooperative guard art gallery problem—a scenario where multiple agents must collectively monitor all visible areas in an environment. The authors show that using learned neural networks to decide where each agent should be positioned can dramatically speed up existing algorithms while preserving their formal guarantees about coverage and connectivity.

## Theoretical Background
The art gallery problem is a classical computational geometry challenge: given a polygon-shaped environment, find the minimum number of guards (points) needed so that every location in the space is visible from at least one guard. The "partially observable" and "cooperative" variants add constraints: agents can only see locally around themselves and must work together. Prior work (CADENCE algorithm) solved this with formal guarantees but didn't optimize which specific valid positions ("corners" in grid-based orthogonal environments) each agent should occupy. This paper leverages graph neural networks—neural networks designed to operate on interconnected data structures—and deep Q-learning (a reinforcement learning technique where agents learn optimal actions through trial and error) to make smarter placement decisions.

## Core Contributions
1. **Two learned heuristics** for corner selection that maintain formal coverage and connectivity guarantees from CADENCE (previously these choices were arbitrary or unspecified).
2. **CNN-based approach** that encodes the grid environment visually and scores candidate corner positions.
3. **GATv2 + DQN approach** that models the problem as a visibility graph (nodes = corners, edges = mutual visibility) and learns policies through deep reinforcement learning.
4. **Empirical validation** across 7,500 random orthogonal environments showing 2-3x improvements in steps to full coverage and peak agent count, with gains increasing at larger scales (50×50 up to 250×250 grids).
5. **Formal preservation** of guarantees—unlike baselines like Incremental Self-Deployment (ISDA), the learned methods don't sacrifice provable correctness.

## Connections to Other Work
This bridges **formal methods** (algorithm verification, guaranteed properties) with **learning-based optimization** (neural networks improving computational efficiency). It extends [[CADENCE]] by addressing its underspecified degrees of freedom. Related to multi-agent coordination problems solved via [[reinforcement-learning]] and graph neural networks for structured environments. Shares spirit with work on learned heuristics for NP-hard problems (e.g., learned solvers for combinatorial optimization), but grounds learning in a provably correct baseline rather than replacing it entirely.

## Practical Applications
- **Security surveillance**: Optimal placement of cameras/guards in buildings, warehouses, or perimeters where coverage and communication guarantees matter.
- **Robotic inspection**: Teams of robots monitoring large facilities (airports, factories, power plants) with partial sensing ranges.
- **Wildfire detection**: Drone networks strategically positioned on terrain to observe vulnerable areas.
- **Wireless sensor networks**: Optimizing node placement in ad-hoc networks where both sensing range and connectivity are constraints.
- **Museum/gallery security**: Actual art gallery guarding in complex floor plans.

## Technical Limitations
- **Orthogonal environments only**: Restricted to grid-aligned polygons; real buildings have curved walls and angled corridors.
- **Scalability bottleneck in training**: Deep Q-learning requires extensive simulation; unclear how learning time grows beyond 250×250 grids or with 50+ agents.
- **Visibility graph assumption**: Works for direct line-of-sight; doesn't account for realistic occlusion from dynamic obstacles or partial transparency.
- **Hyperparameter sensitivity**: CNN and GATv2 architectures likely require re-tuning per environment type; generalization across vastly different morphologies untested.
- **Formal guarantees decoupling**: While placement preserves CADENCE's guarantees, the *learning process itself* has no formal bounds; wrong heuristic could theoretically break guarantees if algorithm is misimplemented.
- **Limited baseline comparison**: Missing comparisons to other heuristics (e.g., reinforcement learning without graph structure, classical optimization like genetic algorithms).

## Open Questions
- Does the learned heuristic transfer to environments not seen during training (e.g., train on 100×100, test on 200×200 or non-orthogonal layouts)?
- How does performance scale with agent count beyond what was tested?
- Can formal verification be integrated *into* the learning process itself (e.g., constrained optimization) rather than applied post-hoc?
- Why does GATv2 outperform the CNN? Is it fundamentally the graph structure, or architectural choices?
- How sensitive are results to environment randomness? Would results hold in structured, adversarial, or human-designed layouts?
- Can the approach handle dynamic environments where obstacles move or agents fail mid-deployment?

## Key Takeaway
Learning which corner to place each robot in preserves guarantees while speeding up proven coverage algorithms by 2–3×.
