# Evolving Towards Better Codes: LLM-Guided Search for High-Distance Binary Linear Codes

**Authors:** Amal Seddas, Vladyslav Shashkov, Maryna Viazovska, Emmanuel Abbe
**Published:** 2026-09-29 | **arXiv:** [2609.37056v1](http://arxiv.org/abs/2609.37056v1)

## Summary
This paper shows how large language models (LLMs) can discover better binary linear codes — mathematical structures used in data transmission and storage — by searching over possible code-construction programs. The approach found seven new record-breaking codes that beat the current best-known constructions, suggesting LLMs can guide search in classical mathematics problems where exhaustive solutions are infeasible.

## Theoretical Background
Binary linear codes are structures in coding theory that add redundancy to digital messages so errors can be detected and corrected during transmission. The key measure of a code's quality is its minimum distance — roughly, how different two valid codewords must be, which determines error-correction capability. Finding codes with high distance relative to their length has been an open optimization problem for decades. The paper builds on evolutionary algorithm frameworks (EvoTune, ShinkaEvolve) that evolve programs rather than tune parameters directly. LLMs are used not as classifiers but as proposal generators — they suggest new program variants during the search loop, combining human expert knowledge with automated exploration.

## Core Contributions
- **LinCodeEvolve framework**: An evolutionary system that evolves code-construction programs, guided by LLM proposals and validated against exact minimum-distance evaluators.
- **Seven new record codes**: Discovery of codes that improve 22 entries in the standard code tables, with six admitting compact quasi-cyclic descriptions (making them theoretically interesting and practically compact).
- **Strategy loop mechanism**: A method for escaping search plateaus by having human experts and LLM collaboratively redirect the search when progress stalls.
- **Verification**: All codes verified by exhaustive enumeration, ensuring rigor in a space where heuristics dominate.

## Connections to Other Work
This work exemplifies the emerging pattern of [[large-language-models]] applied to [[optimization]] in pure mathematics, similar to recent breakthroughs in combinatorics (e.g., AlphaTensor for tensor decomposition). It differs from typical LLM uses (NLP, classification) by treating LLMs as proposal generators in a human-in-the-loop search. It complements classical algebraic methods in coding theory (which construct codes by hand using group-theoretic techniques) with automated search. The quasi-cyclic structure discovered suggests the approach doesn't merely brute-force but finds codes with elegant mathematical structure.

## Practical Applications
- **Telecommunications**: Improved codes directly improve error correction in satellite, cellular, and long-distance fiber-optic systems.
- **Data storage**: Better codes increase reliability of flash memory, SSDs, and archival systems with fixed physical space.
- **QR codes and 2D barcodes**: Smaller, denser barcodes with better error tolerance.
- **Deep-space missions**: NASA and ESA missions critically depend on efficient codes for communication with rovers and probes.
- **5G/6G standards**: Coding schemes in wireless standards could be optimized using this method.

## Product & Startup Ideas
1. **Code optimization-as-a-service**: Cloud API where telecom engineers input code requirements (length, dimension, error-correction capability) and receive optimized constructions, with verification.
2. **Hardware verification tool**: Automated co-design tool for VLSI engineers that evolves optimal systematic codes for memory systems and generates optimized hardware decoders.
3. **Standards consulting**: Advise standards bodies (3GPP, IEEE) on improved coding schemes for next-gen wireless and optical protocols.
4. **Bespoke code search platform**: SaaS for companies needing custom codes for niche applications (aerospace, medical devices), combining domain expertise with LLM-guided search.
5. **Code library optimization**: Automated discovery and cataloging of codes for specific constraint sets, published as open libraries replacing static handcrafted tables.

## Technical Limitations
- **Scalability**: The approach requires exhaustive enumeration to verify candidate codes, which becomes computationally prohibitive for very long codes.
- **LLM dependency**: The quality and diversity of proposals depend on the LLM's ability to understand code theory — smaller or less-trained models may fail. No ablation of which LLM properties matter most.
- **Search space**: The space of possible programs is vast and ill-characterized; no theoretical guarantee the method finds globally optimal codes, only improvements over existing tables.
- **Generalization**: Codes are highly specialized; a system trained for binary linear codes may not transfer to other code families (LDPC, polar codes, algebraic codes).
- **Reproducibility**: LLM outputs are stochastic; reproducibility and sensitivity to random seeds not discussed in detail.

## Open Questions
- How does performance scale to longer codes (length > 500)? Do the gains persist or does search become intractable?
- Which properties of the LLM (model size, training data on math/CS) most influence code discovery quality? Can smaller, cheaper models work?
- Can the quasi-cyclic structure found by the search be explained post-hoc, or does the method find structure by accident?
- Can the approach transfer to other code families (LDPC, algebraic, convolutional) or is the method fundamentally tied to linear codes?
- How much human expert supervision was actually needed versus automated search? Could the method work without human feedback loops?
- Can the discovered codes themselves teach the LLM, creating a bootstrapping loop that improves future searches?

## Key Takeaway
LLMs guided by exhaustive search can discover record-breaking binary linear codes, suggesting automated discovery complements classical coding theory for practical optimization.
