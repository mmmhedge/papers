# ClawGym II: Exploring Black-Box RL on Agent Harness

**Authors:** Huatong Song, Fei Bai, Ming Yang, Renyuan Li, Jia Deng et al.
**Published:** 2026-08-17 | **arXiv:** [2608.16798v1](http://arxiv.org/abs/2608.16798v1)

## Summary
This paper presents ClawGym II, a framework for training language model agents using reinforcement learning (RL) through complex external tools and harnesses (like code execution environments) without needing to modify their internals. The key innovation is treating these harnesses as black boxes — the RL system doesn't need to understand their implementation — and using sandbox infrastructure to run many parallel training rollouts stably and efficiently, demonstrating 10–15 point improvements on code generation benchmarks.

## Theoretical Background
The work builds on agent frameworks that coordinate language models with external tools (agent harnesses) to solve multi-step tasks. Prior work on [[RLHF]] and policy optimization methods like [[PPO]] (Proximal Policy Optimization) and GRPO have shown promise for fine-tuning language models, but scaling these to long-horizon agentic tasks — where a model makes many sequential decisions via tool calls — remains challenging because the harness logic is opaque and hard to integrate into standard RL pipelines. This paper adapts two complementary RL paradigms: critic-based (PPO, which learns a value function) and critic-free (GRPO, which doesn't) to work with reconstructed trajectory data from captured model calls.

## Core Contributions
1. **Sandbox-based execution infrastructure** — Isolated, concurrent execution of task environments and harnesses to enable large-scale parallel rollouts without resource contention or cross-contamination.
2. **Black-box RL decoupling** — A serving proxy at the model boundary captures all model-to-harness interactions without modifying either, then reconstructs multi-turn trajectories as prefix trees for efficient policy optimization.
3. **Adapted policy optimization** — Both PPO and GRPO are modified to optimize over the recovered tree structure while maintaining training-inference consistency.
4. **Mix-harness training** — A single model can be jointly optimized by multiple heterogeneous harnesses (e.g., different code execution environments) in one training run.
5. **Empirical validation** — Demonstrates stable, consistent gains on code generation (ClawGym-Bench, JobBench) and real-world task benchmarks (OfficeQA) without catastrophic forgetting over 200–400 optimization steps.

## Connections to Other Work
This extends the agent harness paradigm (e.g., ReAct, function-calling frameworks) by making RL practical for black-box tool integration. It relates to [[Reward Modeling]] and [[RLHF]] but focuses on the harder setting where the harness itself is not differentiable. The prefix tree reconstruction approach resembles trajectory stitching in offline RL, adapted here for online agent-harness interaction. The mix-harness concept connects to [[multi-task learning]] and domain adaptation; training on heterogeneous systems is analogous to robust policy learning across environment variations.

## Practical Applications
1. **Code generation and software engineering** — Fine-tuning LLMs to write, test, and debug code more reliably by optimizing on real execution feedback (compiler, test suite results).
2. **Autonomous task completion** — Language models orchestrating APIs, databases, and web services to execute workflows (e.g., scheduling, data entry, report generation).
3. **Multi-tool reasoning** — Models that reason across spreadsheets, calculators, search engines, and document retrieval to solve knowledge-intensive tasks.
4. **Robustness across deployment environments** — Training once with mix-harness to ensure the same model works stably across different execution backends (cloud providers, on-premise systems).
5. **Interactive retrieval and QA** — Systems that refine answers by querying external knowledge bases, fact-checking, and iterating based on feedback signals.

## Technical Limitations
1. **Scalability of tree reconstruction** — Prefix trees grow exponentially with episode length and branching factor; managing millions of partial trajectories may hit memory or traversal speed limits.
2. **Reward signal dependency** — The framework requires a clear, interpretable reward signal from the harness (e.g., test pass/fail); tasks with sparse or noisy rewards may see high variance.
3. **Training-inference consistency** — Maintaining consistency across different model checkpoint versions and harness updates requires careful bookkeeping; this breaks if harness APIs change mid-training.
4. **Limited to deterministic harnesses** — Environments with significant stochasticity (e.g., network delays, random backend behavior) may produce noisy gradients.
5. **Generalization** — Models trained on specific harnesses may not transfer well to unseen tools or deployment environments outside the mix-harness training set.
6. **Sample efficiency** — Black-box RL often requires more rollouts than white-box (differentiable) methods; the overhead vs. standard supervised fine-tuning is not quantified.

## Open Questions
1. **How does the tree reconstruction complexity scale with real-world episode lengths (100+ steps)?** Do memory or pruning strategies become essential?
2. **Can the framework handle temporally continuous harness feedback** (reward per step) rather than only episodic rewards?
3. **What is the minimal harness diversity needed for zero-shot transfer?** How much mix-harness training is required before the model generalizes to new unseen tools?
4. **How does the method compare to white-box fine-tuning on the same tasks in terms of sample efficiency and wall-clock time?**
5. **Can critic-free GRPO be scaled to ultra-long-horizon tasks (500+ steps) without divergence, and how does it compare to actor-critic methods empirically?**
6. **Does the framework support online curriculum learning — e.g., starting with easy harnesses and progressively increasing complexity?**

## Key Takeaway
Black-box RL through sandboxed harnesses enables stable, scalable fine-tuning of language models on complex tools without modifying their internals.
