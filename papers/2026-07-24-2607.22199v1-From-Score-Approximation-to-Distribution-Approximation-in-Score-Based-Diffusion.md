# From Score Approximation to Distribution Approximation in Score-Based Diffusion Models

**Authors:** Lan V. Truong
**Published:** 2026-07-24 | **arXiv:** [2607.22199v1](http://arxiv.org/abs/2607.22199v1)

## Summary
This paper proves that when a neural network approximates the score function (the gradient of log probability) accurately enough, the probability distribution generated by a score-based diffusion model will be close to the target data distribution. It bridges a gap in diffusion model theory by showing that good score approximation actually translates to good distribution approximation, with explicit error bounds.

## Theoretical Background
Score-based diffusion models (also called diffusion probabilistic models) work by gradually adding noise to data via a forward process, then learning to reverse this process by predicting the score function at each step. Prior work showed that neural networks can universally approximate any smooth function, including score functions. However, the paper addresses a missing piece: no one had rigorously proved that approximating the score function well enough guarantees the final generated distribution is close to the true data distribution. The analysis draws on three mathematical tools: Hornik's universal approximation theorem (showing neural networks can approximate continuous functions arbitrarily well), Girsanov's theorem (relating probability measures along continuous paths in probability space), and the data processing inequality (bounding how information changes under transformations).

## Core Contributions
1. **First rigorous quantitative link**: Establishes an explicit upper bound connecting score approximation error directly to distribution approximation error in KL divergence, filling a theoretical gap.
2. **Explicit error decomposition**: Identifies and quantifies three sources of error — score approximation error, the diffusion noise schedule's influence, and mismatch between the true terminal prior and the reverse process initialization.
3. **Self-contained approximation-theoretic analysis**: Develops the argument from first principles using classical neural network approximation theory, independent of finite-sample statistical or data structure assumptions that other works rely on.

## Connections to Other Work
This work complements recent papers that study score approximation under statistical (finite-sample) settings and structural assumptions on the data distribution. It provides a complementary "worst-case" approximation-theoretic perspective, similar in spirit to classical function approximation results. The result validates the empirical success of diffusion models observed in papers like [[Score-Based Generative Modeling Through Stochastic Differential Equations]] by providing theoretical justification. It also relates to broader efforts to understand generative model approximation guarantees, positioning diffusion models alongside [[VAEs]] and [[GANs]] in terms of theoretical grounding.

## Practical Applications
1. **Model validation**: Practitioners can use the error bound to estimate how accurately they need to train their score networks to guarantee a certain quality of generated samples.
2. **Architecture and hyperparameter selection**: The explicit dependence on noise schedule and approximation error guides choices about diffusion timesteps, network capacity, and training objectives.
3. **Reliability in high-stakes generation**: For applications like drug molecule or protein design, the quantitative guarantee helps determine whether a diffusion model is theoretically sound for the required precision.
4. **Debugging convergence**: If generated samples are poor, the bound helps diagnose whether the issue is score network capacity, noise schedule mismatch, or training.

## Product & Startup Ideas
1. **Diffusion Model Validator Tool**: SaaS that checks whether a trained diffusion model's score approximation error meets requirements for a target application, certifying sample quality.
2. **Automated Diffusion Architecture Search**: Platform that combines this theory with architecture search to auto-select network depth, width, and noise schedule for a given generation task and error tolerance.
3. **Certified Generative AI for Pharma**: Specialized service that uses this quantitative guarantee to certify diffusion models for molecule design, where regulators require approximation error bounds.
4. **Distribution Quality Monitoring**: Real-time monitoring system for production diffusion models that continuously estimates KL divergence from target distribution based on score error.
5. **Diffusion Model Distillation Service**: Use the error bounds to build provably-correct lightweight diffusion models via distillation, with certificates of approximation quality.

## Technical Limitations
1. **Terminal prior mismatch**: The bound includes an irreducible error term from mismatch between where the forward process ends and where the reverse process begins; this cannot be eliminated by better score approximation alone.
2. **Curse of dimensionality**: The universal approximation theorem guarantees existence but is silent on how network size must scale with dimension; the bound may be loose in high dimensions.
3. **Smooth score assumption**: The analysis assumes the true score function is sufficiently smooth and bounded; it does not handle multimodal or discontinuous data distributions.
4. **KL divergence metric**: The bound is in KL divergence, which can be insensitive to mode collapse or other sample quality issues that matter in practice.
5. **Finite discretization gap**: Real implementations discretize the continuous reverse process; the paper does not address approximation error from discretization.

## Open Questions
1. **Dimension dependence**: Can the bound be tightened to show explicit dimension dependence, and how does it compare to worst-case lower bounds?
2. **Discretization error**: How do discretization errors in numerical ODE solvers interact with score approximation errors in the bound?
3. **Finite-sample extension**: Can this approximation-theoretic result be combined with statistical learning theory to give finite-sample guarantees?
4. **Structured data**: Do the bounds improve under assumptions that the data lies on a low-dimensional manifold or has other structure?
5. **Practical tightness**: Are the constants in the bound sharp, or are they artifacts of the proof technique? Empirical studies would clarify.

## Key Takeaway
Good score function approximation provably yields good sample quality in diffusion models, with explicit error bounds linking both.
