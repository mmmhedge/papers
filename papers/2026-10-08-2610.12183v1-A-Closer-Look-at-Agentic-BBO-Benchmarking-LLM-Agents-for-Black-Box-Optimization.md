# A Closer Look at Agentic BBO: Benchmarking LLM Agents for Black-Box Optimization

**Authors:** Ming Chen, Rong-Xi Tan, Ke Xue, Yu-Jie Zhou, Taiye Lu et al.
**Published:** 2026-10-08 | **arXiv:** [2610.12183v1](http://arxiv.org/abs/2610.12183v1)

## Summary
This paper creates AgenticBBO-Bench, a benchmark for testing how well LLM-powered agents solve black-box optimization problems (where you can only evaluate objective functions, not see their internals). The authors compare agentic approaches across five real domains — synthetic functions, hyperparameter tuning, database optimization, chip design, and molecular design — and find that agents often outperform both pure LLM methods and classical numerical optimizers, though the gains depend heavily on task semantics and tool design.

## Theoretical Background
Black-box optimization (BBO) is a classical problem in computer science and engineering: find the best input to an objective function when you cannot access its gradients or structure, only observe outputs for expensive evaluations. Traditionally solved by Bayesian optimization, genetic algorithms, and evolutionary strategies. Recent work explores using large language models (LLMs) — neural networks trained on vast text corpora to generate coherent sequences — as optimization agents. These agents combine natural language reasoning, access to mathematical tools, and feedback loops to iteratively improve solutions. The key insight is that LLMs can encode domain knowledge and use tools (like solvers or simulators) in ways pure optimization algorithms cannot.

## Core Contributions
1. **AgenticBBO-Bench**: A unified, cross-domain benchmark with standardized finite-budget protocols, eliminating confounds from prior work that used different tasks and configs.
2. **Systematic ablation studies** isolating three design factors: which optimization tools help (finding that additional tools don't always improve performance), how task semantics and priors affect agents (task semantics are broadly useful; specific priors less reliable), and how agents and numerical optimizers interact (optimizers can effectively exploit search trajectories established by agents).
3. **Empirical findings**: Agents beat direct LLM methods in all five domains and outperform best numerical baselines in four; frontier analysis identifies GPT-6 Astra and DeepSeek-V4.1-Flash as cost-efficient leaders.
4. **Open-source benchmark and reproducible methodology** enabling future comparative studies.

## Practical Applications
- **Hyperparameter optimization**: AutoML systems that tune machine learning models without manual search.
- **Molecular design**: Discovering new drug candidates or materials by navigating vast chemical spaces with limited lab experiments.
- **Chip design**: Optimizing circuit layouts and parameters when simulation is expensive.
- **Database tuning**: Automatically configuring indices, memory allocation, and query parameters for production systems.
- **Scientific discovery**: Tuning experimental parameters in physics or chemistry when each trial is costly.

## Technical Limitations
- **Evaluation cost and reproducibility**: Agents require many function evaluations; real-world BBO problems (e.g., wet labs, chip fabrication) may be too expensive to validate improvements at scale.
- **Task semantic dependence**: Performance heavily depends on whether the agent can parse task semantics; domains with ambiguous or implicit objectives may not benefit.
- **LLM brittleness**: Agents are sensitive to prompt design, model version, and randomness; no principled guidelines for tuning agent behavior across domains.
- **Scalability to high-dim**: Most benchmarks likely have moderate dimensionality; scaling to 100+ dimensional spaces is unclear.
- **Tool generalization**: Results assume access to domain-specific tools (solvers, simulators); in truly novel domains, agents must discover tools or lack them entirely.
- **Comparison fairness**: Numerical baselines may not be given equal compute budgets or access to agent-like trajectory information; this could inflate agentic claims.

## Open Questions
- **How do agents leverage trajectory history?** When do they memorize vs. generalize across related tasks?
- **Can agents discover new optimization algorithms or tools on-the-fly**, or are they limited to using pre-provided ones?
- **What is the theoretical complexity** of agentic BBO (sample complexity, convergence rates) compared to classical optimizers?
- **How robust are agents to task distribution shift?** If train on synthetic + HPO tasks, do they transfer to chip design?
- **Do larger or instruction-tuned LLMs scale agent performance**, or do returns plateau?
- **How does prompt engineering or in-context learning** affect results; should this be treated as a hyperparameter or source of unfairness?

## Key Takeaway
LLM agents beat traditional optimizers on real problems, but gains depend on task structure and tool design — no silver bullet.
