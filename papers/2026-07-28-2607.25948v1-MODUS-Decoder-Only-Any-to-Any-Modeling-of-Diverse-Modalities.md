# MODUS: Decoder-Only Any-to-Any Modeling of Diverse Modalities

**Authors:** Mingqiao Ye, Zhaochong An, Zhitong Gao, Xian Liu, François Fleuret et al.
**Published:** 2026-07-28 | **arXiv:** [2607.25948v1](http://arxiv.org/abs/2607.25948v1)

## Summary
This paper presents MODUS, a decoder-only neural network that can accept any combination of modalities (images, text, audio, etc.) as input and generate any modality as output using a single unified model. Unlike existing any-to-any systems that require separate encoders and decoders or diffusion models, MODUS leverages pre-trained decoder-only models and treats all modalities symmetrically, achieving competitive performance across multiple benchmarks without task-specific components.

## Theoretical Background
Multimodal learning has traditionally relied on encoder-decoder architectures (e.g., vision transformers paired with language models) or diffusion models that gradually denoise outputs. Decoder-only architectures—popularized by large language models like GPT—process sequences autoregressively, predicting one token at a time. The key insight here is that decoder-only models can be extended beyond text by tokenizing all modalities (images, audio, sensor data) into discrete sequences, allowing a single model to handle cross-modal translation. Prior any-to-any work (common in vision-language and scientific domains) typically required separate task pipelines or modality-specific prediction heads, limiting scalability and preventing leverage of strong pre-trained priors.

## Core Contributions
1. **Decoder-only any-to-any framework**: Demonstrates that a single decoder-only model can seamlessly handle arbitrary input-output modality pairs without modality-specific components, heads, or losses.
2. **Symmetric treatment of modalities**: All modalities are both inputs and outputs of the same model, enabling novel capabilities like chained generation (audio → text → image) and cross-modal self-verification (generate image, then score it by generating text description).
3. **Competitive out-of-the-box performance**: Shows that a single MODUS model matches or exceeds specialist and multi-task baselines across diverse benchmarks, suggesting strong transfer from pre-trained decoders.
4. **Practical unification**: Eliminates the need for separate task pipelines, specialist models, or domain-specific losses—a single trained model handles all modality combinations.

## Connections to Other Work
This work builds on the success of decoder-only architectures in [[large-language-models]] and extends them to multimodal settings. It contrasts with encoder-decoder approaches (e.g., CLIP, DALL-E 2) and [[diffusion models]] for generation. The any-to-any formulation relates to work in vision-language modeling and scientific multimodal domains. The cross-modal self-verification idea echoes [[RLHF]] and reward-based verification in language models, adapted to visual and other domains. The symmetric input-output treatment is philosophically similar to masked language modeling but applied across modalities.

## Practical Applications
1. **Cross-modal search & retrieval**: Query with any modality (sketch, audio clip, text description) to retrieve matching content in other modalities.
2. **Scientific data analysis**: In ecology or astronomy, generate missing observational data (e.g., missing spectral bands) from available measurements; in medical imaging, predict missing scan modalities from available ones.
3. **Content accessibility**: Automatically generate captions for images, transcripts for audio, and audio descriptions for text—all from a single model.
4. **Data augmentation for training**: Generate synthetic training data by chaining intermediate modalities (text description → generated image → synthetic caption).
5. **Multimodal chatbots**: Accept images, audio, or sketches as input alongside text; respond with text, images, or audio without switching models.

## Product & Startup Ideas
1. **Universal Accessibility Platform**: A web app where users upload any media type and get AI-generated descriptions, transcripts, or translations in any other modality—powered by MODUS—targeting accessibility-first markets (media, education).
2. **Scientific Data Reconstruction SaaS**: For researchers in climate, astronomy, and biology, a service that reconstructs missing sensor data or observational modalities from partial measurements using MODUS, reducing costly data collection.
3. **AI-Powered Asset Management for Creative Studios**: A tool that ingests unstructured creative assets (sketches, storyboards, audio drafts) and auto-generates matching visuals, soundtracks, and scripts in any style—enabling small studios to compete at scale.
4. **Multimodal Legal/Compliance Automation**: Ingest contracts, audio recordings of agreements, and video depositions; output standardized summaries, redacted versions, and risk assessments—all from one model, reducing legal overhead.
5. **Interactive Education Content Generator**: Teachers upload lecture videos or textbooks; the system generates interactive quizzes, visual summaries, audio narrations, and personalized learning paths automatically.

## Technical Limitations
1. **Tokenization bottleneck**: Performance depends heavily on effective discrete tokenization of each modality. Poor tokenizers for new modalities (e.g., 3D point clouds, time-series sensor data) will degrade quality.
2. **Modality imbalance**: Training data across modalities is rarely balanced; domains like audio or medical imaging may be underrepresented, limiting generalization.
3. **Sequence length constraints**: Decoder-only models struggle with very long contexts (e.g., hour-long videos, high-resolution images). Computational cost scales with total token count across all modalities.
4. **Latency in production**: Autoregressive decoding (predicting one token at a time) is slower than parallel methods for image or video generation, limiting real-time applications.
5. **Generalization to truly novel modalities**: While symmetric, the model still needs enough data to learn a new modality's tokenization and semantics; truly zero-shot modality transfer is likely weak.
6. **Alignment across modalities**: No explicit mechanism to enforce semantic consistency (e.g., generated image and caption must depict the same scene); relies on implicit learning from training data.

## Open Questions
1. **How does performance scale with the number of modalities?** Does adding a 10th or 20th modality degrade all existing ones, or does the model gracefully adapt?
2. **What is the optimal tokenization strategy for modalities at vastly different information densities** (text ≈ 1–10 tokens per second; video ≈ 1000s of visual tokens)? Does the paper's approach balance them fairly?
3. **Can MODUS learn useful cross-modal supervision** (e.g., use generated text descriptions to improve image generation quality through a scoring mechanism), and at what computational cost?
4. **How does it perform on truly out-of-distribution input combinations** (e.g., modality pairs never seen together during training)? Is the learned representation truly compositional?
5. **Can decoder-only architecture match or beat specialized models** when fine-tuned on a single downstream task, or is there an inherent trade-off between universality and task-specific optimization?

## Key Takeaway
A single decoder-only model can generate any modality from any input combination, matching specialist systems without task-specific components.
