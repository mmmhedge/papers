# Information fusion and machine learning for sensitivity analysis using physics knowledge and experimental data

**Authors:** Berkcan Kapusuzoglu, Sankaran Mahadevan
**Published:** 2026-08-18 | **arXiv:** [2608.17248v1](http://arxiv.org/abs/2608.17248v1)

## Summary
This paper combines physics-based computational models with experimental data using machine learning to improve sensitivity analysis — understanding how input changes affect system outputs. The key innovation is using physics-informed machine learning (enforcing physical laws as constraints, or pre-training with simulation data) to get better and more reliable sensitivity estimates when both simulations and real measurements are available.

## Theoretical Background
Global sensitivity analysis (GSA) measures how much each input variable influences model outputs, typically using Sobol indices — a metric from variance-based sensitivity analysis. The paper builds on two classical ML approaches: deep neural networks (DNNs — flexible models with many parameters) and Gaussian processes (GPs — probabilistic models that quantify uncertainty naturally). Physics-informed machine learning is an emerging paradigm that embeds domain knowledge (physics equations, conservation laws) into ML models, either through loss functions (penalty terms that enforce physical constraints during training) or through strategic use of simulation data. The challenge addressed here is model uncertainty: when your ML model is imperfect, how does that error propagate into your sensitivity estimates?

## Core Contributions
1. Systematic comparison of two physics-informed strategies for combining simulation and experimental data: (i) constraint-based (adding physics to loss functions) and (ii) sequential training (pre-training on simulations, then updating with experiments).
2. Quantification of how model uncertainty from both DNNs and GPs affects Sobol indices bounds — showing that DNNs produce tighter confidence intervals than GPs.
3. Demonstration on two real problems: additive manufacturing (3D printing) and lake temperature modeling, showing practical applicability.
4. Framework for selecting which ML architecture to use when both data sources are available.

## Connections to Other Work
This work sits at the intersection of [[uncertainty quantification]], surrogate modeling, and [[physics-informed neural networks]] (PINNs). It extends classical sensitivity analysis (traditionally done on expensive physics simulators) by leveraging experimental data to refine estimates. Related to [[Bayesian optimization]] and active learning in that it combines heterogeneous data sources; differs by focusing on *sensitivity* rather than model training per se. Connects to broader work on data assimilation (combining models and observations) in geophysics and climate science.

## Practical Applications
1. **Additive manufacturing process control**: Determine which printing parameters (temperature, speed, material) most affect final part quality, then focus quality control on those knobs.
2. **Environmental monitoring**: In lake temperature modeling, identify which meteorological inputs (wind, solar radiation, inflow) are most critical for prediction, informing what sensors to deploy.
3. **Clinical device design**: For medical devices, understand which design parameters most affect patient safety outcomes when both simulation and trial data exist.
4. **Aerospace structural analysis**: Determine which material properties most influence wing flutter risk, reducing expensive physical testing.

## Product & Startup Ideas
1. **Sensitivity-as-a-Service platform**: Cloud tool for engineers to upload computational models + experimental datasets, automatically choose best physics-informed ML strategy, return sensitivity rankings with uncertainty bounds — democratizing GSA for SMEs.
2. **Digital twin calibration engine**: SaaS that continuously fuses new sensor data with physics simulations to refine sensitivity estimates in real-time, enabling adaptive control systems.
3. **Manufacturing parameter optimization suite**: Specialized tool for additive manufacturing and injection molding plants to auto-identify which process parameters matter most, reducing trial-and-error.
4. **Regulatory compliance analytics**: Help pharmaceutical and automotive companies quantify sensitivity of product performance to manufacturing variation for FDA/regulatory submissions.
5. **Research software package**: Open-source Python library competing with UQLab; integrated Sobol computation with DNN/GP physics-informed backends for academic/industry use.

## Technical Limitations
1. **Scalability**: Both DNNs and GPs become computationally expensive in high-dimensional input spaces (>20 inputs); paper doesn't address this curse of dimensionality.
2. **Physics specification**: Requires explicit knowledge of which physics constraints to encode — unclear how to handle systems where physics is partially unknown or multi-physics interactions are complex.
3. **Data heterogeneity**: Assumes experimental data and simulations are comparable; doesn't address cases where they measure different quantities or have incompatible scales.
4. **Limited sample sizes**: Real experiments are expensive; paper doesn't clarify minimum experimental sample sizes needed to reliably update models or bound sensitivities.
5. **Model class bias**: Results compare DNNs vs. GPs but don't explore other modern approaches (ensemble methods, neural process models) that might trade uncertainty quantification differently.
6. **Transferability**: Examples are application-specific; unclear how method generalizes to entirely new domains.

## Open Questions
1. How does the method perform in truly high-dimensional settings (50+ inputs)? Can dimension reduction be integrated?
2. Can the framework handle sparse or irregularly-sampled experimental data, or does it require dense, well-curated datasets?
3. How sensitive are the Sobol bounds to mis-specification of physics constraints (i.e., when your assumed physics is partially wrong)?
4. Could active learning strategies be embedded to suggest which experiments to run next to most efficiently refine sensitivity estimates?
5. Can this framework extend to time-varying systems or those with hidden/latent variables not directly observable?
6. How do results change if you have *multiple competing* physics models rather than one canonical simulation?

## Key Takeaway
Combining physics-informed ML with experimental data yields tighter, more trustworthy sensitivity estimates for engineering models than using either source alone.
