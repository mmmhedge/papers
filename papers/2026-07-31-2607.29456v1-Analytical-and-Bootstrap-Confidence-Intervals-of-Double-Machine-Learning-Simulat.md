# Analytical and Bootstrap Confidence Intervals of Double Machine Learning: Simulation studies and an application to rural-urban difference in obesity prevalence

**Authors:** Haozheng Xu, Siyuan Ma, Qingyan Xiang
**Published:** 2026-07-31 | **arXiv:** [2607.29456v1](http://arxiv.org/abs/2607.29456v1)

## Summary

This paper investigates how the choice of machine learning algorithm affects the reliability of confidence intervals in Double Machine Learning (DML), a method for estimating treatment effects. The authors compare analytical and bootstrap confidence intervals across five different learners (linear regression, LASSO, Random Forest, LightGBM, neural networks) through simulations and a real-world case study on obesity prevalence, finding that algorithm choice dramatically impacts coverage probability—and surprisingly, that coverage often *worsens* as sample size increases.

## Theoretical Background

Double Machine Learning is a framework designed to combine the flexibility of modern machine learning methods with valid statistical inference for causal effects. Traditional causal inference assumes parametric models, but DML allows researchers to use any flexible learner (random forests, neural networks, etc.) for estimating "nuisance parameters"—auxiliary model components that aren't the main object of interest—while still preserving asymptotic validity of confidence intervals. The method works by using sample splitting and orthogonalization to decouple estimation error in the nuisance model from the final treatment effect estimate. Prior work (Chernozhukov et al.) established that under certain conditions, DML confidence intervals should have correct coverage. However, these theoretical guarantees depend on how well the nuisance models are estimated, which varies across different algorithms.

## Core Contributions

1. **Systematic empirical comparison**: First comprehensive simulation study directly comparing coverage probability of DML confidence intervals across five modern learners under controlled conditions, something prior theory papers did not thoroughly investigate.

2. **Bootstrap vs. analytical intervals**: Quantifies the performance gap between theoretically-derived analytical confidence intervals and bootstrap-based alternatives, revealing both have reliability issues depending on learner choice.

3. **Paradoxical sample-size finding**: Documents a counterintuitive phenomenon—coverage probability *decreases* with sample size in many settings—which contradicts standard asymptotics and suggests finite-sample breakdowns in DML theory under certain algorithm-data combinations.

4. **Real-world validation**: Applies findings to U.S. county-level obesity data, demonstrating that algorithm choice affects substantive conclusions (e.g., the significance of rural-urban differences).

## Connections to Other Work

This work sits at the intersection of causal inference and machine learning. DML builds on classical treatment effect estimation but extends it to high-dimensional settings. The paper implicitly tests the robustness of [[Chernozhukov]] et al.'s theoretical guarantees in practice. It relates to broader questions about when machine learning methods preserve statistical validity—similar to concerns in [[RLHF]] and other ML systems that must combine predictive performance with reliable uncertainty quantification. The coverage problem parallels issues in [[uncertainty-quantification]] and [[calibration]] of neural networks.

## Practical Applications

1. **Policy evaluation**: Policymakers using DML to estimate causal effects of interventions (e.g., rural development programs, health policy) need to know whether their confidence intervals are trustworthy; this paper provides guidance on learner selection.

2. **Epidemiological research**: Public health researchers estimating effects of exposures on disease outcomes can use these findings to choose algorithms that yield reliable inference.

3. **Economics**: Labor economists, development economists estimating program effects can benchmark their machine learning choices against this framework.

4. **Personalized medicine**: Clinical trials using machine learning to estimate treatment heterogeneity require valid confidence intervals; this work flags risks in current practice.

## Product & Startup Ideas

1. **DML Algorithm Advisor**: A software tool that automatically evaluates coverage properties of different learners for a user's dataset and recommends the most reliable algorithm for causal inference tasks—useful for consulting firms, academic researchers, and industry data science teams.

2. **Causal Inference SaaS**: A cloud platform that wraps DML with built-in diagnostics, showing users not just point estimates but also coverage reliability metrics across candidate learners.

3. **Policy Impact Auditor**: Software for government agencies to validate treatment effect estimates from grants/programs, automatically flagging when algorithm choice could invalidate conclusions.

4. **Enterprise ML Governance**: A system for large organizations (pharma, finance, insurance) to audit internal causal analyses for statistical validity—ensuring regulatory and legal compliance.

5. **Academic Benchmarking Service**: A repository + compute service where researchers can submit their DML analyses, automatically run coverage diagnostics, and publish results with confidence-interval quality badges.

## Technical Limitations

1. **Limited scope of learners**: Study covers five algorithms; newer methods (transformers, other deep learning variants) not evaluated.

2. **Simulation design dependency**: Results depend on how data-generating processes (DGPs) were chosen; coverage issues may not generalize to all real-world settings.

3. **No solution offered**: Paper identifies the problem (coverage variability with learner choice) but doesn't propose a fix—practitioners still face the original dilemma.

4. **Finite-sample paradox unexplained**: The counterintuitive sample-size effect is documented but not theoretically explained; unclear when or why this occurs.

5. **Nuisance model specification**: DML still requires correct specification of *which* variables are nuisance parameters vs. the treatment; this choice is not explored.

6. **Computational constraints**: No discussion of computational cost trade-offs when comparing learners in real applications.

## Open Questions

1. **Why does coverage degrade with sample size?** Needs theoretical analysis of the breakdown in asymptotic approximations for specific learner-DGP pairs.

2. **Can we predict in advance which learner will work?** Is there a data-driven diagnostic (cross-validation, information criterion) that flags problematic algorithms before analysis?

3. **Do hybrid ensembles help?** Could averaging predictions across learners or using stacking improve coverage robustness?

4. **How do hyperparameters matter?** The paper doesn't vary hyperparameter choices (regularization, tree depth, etc.)—does tuning fix coverage issues?

5. **Real-world validation**: Larger suite of real datasets with known ground truth (via randomized experiments) to validate simulation findings.

6. **Deep learning specifics**: Why do neural networks behave differently? Can architecture choices or training procedures improve DML reliability?

## Key Takeaway

Machine learning algorithm choice dramatically affects whether DML confidence intervals are statistically reliable in practice, and increasing sample size sometimes makes coverage worse.
