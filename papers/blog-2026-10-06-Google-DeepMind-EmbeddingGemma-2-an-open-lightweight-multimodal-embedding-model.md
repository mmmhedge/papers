# EmbeddingGemma 2: an open, lightweight multimodal embedding model

**Source:** Google DeepMind
**Published:** 2026-10-06 | **Link:** [https://deepmind.google/blog/embeddinggemma-2-an-open-lightweight-multimodal-embedding-model/](https://deepmind.google/blog/embeddinggemma-2-an-open-lightweight-multimodal-embedding-model/)

## Summary
Google DeepMind released EmbeddingGemma 2, an open-source lightweight multimodal embedding model designed to encode both text and images into unified vector representations. The model prioritizes efficiency and accessibility while maintaining competitive performance, making it suitable for resource-constrained deployments and retrieval applications.

## Key Points
- EmbeddingGemma 2 is a multimodal embedding model capable of processing both text and image inputs
- Emphasis on lightweight architecture—smaller model size than predecessors for reduced computational overhead
- Open-source release enables broad adoption and community contributions
- Designed for embedding tasks: converting inputs into dense vector spaces for similarity search and retrieval
- Achieves competitive performance metrics while maintaining efficiency

## Why It Matters
Multimodal embeddings are foundational for modern retrieval systems, semantic search, and cross-modal applications. Open, lightweight models democratize access to these capabilities for organizations without massive compute budgets. This addresses the gap between state-of-the-art performance and practical deployment constraints.
