# Towards End-to-End Multilingual Metaphor Processing: Integrating Detection, Translation, and Evaluation

**Authors:** Jiahui Liang, Lifeng Han
**Published:** 2026-08-04 | **arXiv:** [2608.04260v1](http://arxiv.org/abs/2608.04260v1)

## Summary
Metaphorical language remains a major challenge for multilingual natural language processing because successful interpretation and translation require reasoning beyond literal lexical meaning. Existing research has largely investigated metaphor detection, machine translation, and translation evaluation as separate tasks, while little work has explored how these components can be integrated into a unified computational framework. This PhD proposal aims to develop an end-to-end framework for multilingual metaphor processing consisting of three complementary research directions: (1) robust metaphor detection across languages, (2) metaphor-oriented translation evaluation for both human assessment and automatic quality estimation, and (3) joint modelling that connects metaphor detection with translation evaluation.

## Theoretical Background
Language systems must represent meaning, retrieve evidence, and follow task constraints. Evaluation should separate these capabilities rather than relying on one aggregate score.

The paper addresses the trade-off identified in its abstract through a targeted method, representation, or evaluation framework.
