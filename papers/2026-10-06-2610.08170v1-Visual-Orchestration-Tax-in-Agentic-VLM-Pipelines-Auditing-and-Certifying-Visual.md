# Visual Orchestration Tax in Agentic VLM Pipelines: Auditing and Certifying Visual Evidence Reuse

**Authors:** Lingteng Zeng
**Published:** 2026-10-06 | **arXiv:** [2610.08170v1](http://arxiv.org/abs/2610.08170v1)

## Summary
This paper identifies and measures "visual orchestration tax"—the wasteful reprocessing of identical images across multiple specialist agents in multi-agent VLM (vision-language model) pipelines. The authors develop an auditing framework that reveals 67–76% redundant image processing, then propose SharedVisCache, a caching system that eliminates this waste while preserving output correctness and reducing computational cost by 75–90%.

## Theoretical Background
The work builds on two established concepts: multi-agent orchestration (systems where independent agents collaborate on complex tasks) and vision-language models (neural networks that process both images and text, like CLIP or GPT-4V). Modern agentic pipelines decompose tasks by routing the same image to different specialist agents (e.g., one for chart understanding, another for document OCR). The paper assumes images flow through a shared VLM API boundary where each agent makes independent requests. Prior work on agent systems focuses on task decomposition and coordination; this paper identifies a previously unexamined efficiency problem at the visual encoding layer—the repeated conversion of the same static image into different API calls.

## Core Contributions
1. **Visual Orchestration Tax** — Defines and quantifies the phenomenon of semantically identical images being reconstructed multiple times across agentic pipelines. Introduces two metrics: M1_trace (raw visual-evidence touches) and M2 (structural touch redundancy).

2. **Measurement Framework** — Develops an auditing methodology using query-level distributions, bootstrap confidence intervals, and paired quality tests; applies it to SeeingEye and MAMMQA benchmarks showing 66.8–75.6% redundancy.

3. **SharedVisCache** — A contract-aware caching layer that keys reuse by image content, preprocessing fingerprint, and encoder assumptions; validates correctness via contract checks and achieves 75.0–75.5% certified hit rates.

4. **Physical-layer validation** — Demonstrates end-to-end gains: reduces vision function calls from 800 to 200 (ChartQA) and 200 to 50 (live SeeingEye) while preserving all outputs (Δ M5 = 0).

## Connections to Other Work
This work sits at the intersection of [[multi-agent systems]] and [[computer-vision]] optimization. It relates to caching strategies in [[transformers]] (prefix caching, KV-cache reuse) but applies the principle at a higher level—across agent boundaries rather than within a single model. The contract-aware reuse pattern echoes formal verification approaches in agent safety and [[alignment]], ensuring cached outputs are semantically safe. The measurement methodology draws from performance profiling in distributed systems; the certification layer resembles determinism testing in ML pipelines.

## Practical Applications
1. **Multi-agent VLM applications** — Reduce API costs for document processing, medical imaging analysis, or chart interpretation systems that route images to multiple specialist agents.
2. **Enterprise document workflows** — Accelerate HR/legal document review where the same contract or form is analyzed by compliance, financial, and risk agents in sequence.
3. **Autonomous visual reasoning** — Speed up embodied AI systems or robotics that repeatedly reason about the same observed scene across motion planning, object detection, and semantic understanding modules.
4. **Real-time analytics dashboards** — Optimize systems that feed the same visualization (chart, screenshot) to multiple analytical agents (trend detection, anomaly detection, summarization).

## Technical Limitations
1. **Image fingerprinting brittleness** — Reuse depends on exact content/preprocessing match; even minor preprocessing variations (JPEG quality, resizing algorithm) can break cache hits. Real-world pipelines may have heterogeneous preprocessing.

2. **Encoder assumption coupling** — The cache is keyed to specific encoder assumptions; if agents use different VLM versions or encoders, certification becomes fragile.

3. **Limited scope** — Evaluated only on chart/document QA tasks (SeeingEye, MAMMQA). Unclear how well the approach generalizes to video, real-time streams, or highly dynamic visual content.

4. **Contract overhead** — SharedVisCache adds validation logic; the paper doesn't isolate the computational cost of contract checking itself, which could be non-negligible for high-frequency pipelines.

5. **Sequential vs. parallel orchestration** — Gains assume images flow sequentially through agents; true parallel agent execution may reduce the window for reuse.

6. **No theoretical guarantees** — The framework is empirical; no formal proof that contract validation always preserves semantic equivalence.

## Open Questions
1. How does visual orchestration tax scale with pipeline depth (number of agents)? Is it sublinear, linear, or worse?

2. Can the framework extend to **dynamic content** (e.g., images that change between agent calls but remain "semantically similar")? How should M2 be redefined?

3. What is the minimal contract specification needed for safe reuse? Can you learn contracts from execution traces rather than manually specifying them?

4. How does this interact with [[reinforcement-learning]]-based agent coordination, where agents might learn to exploit cached images in unintended ways?

5. Could this inform the design of VLM APIs themselves (e.g., native image deduplication at the model server level)?

6. Does SharedVisCache provide any privacy benefits by reducing image transmission, or does the caching layer itself become a privacy liability?

## Key Takeaway
Multi-agent vision pipelines waste 67–76% of image processing—a caching layer with correctness contracts recovers this loss without changing outputs.
