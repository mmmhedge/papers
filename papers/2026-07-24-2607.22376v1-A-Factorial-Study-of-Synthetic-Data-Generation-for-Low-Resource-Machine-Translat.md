# A Factorial Study of Synthetic Data Generation for Low-Resource Machine Translation using Grammar Books

**Authors:** Varun Ghat Ravikumar, Sina Ahmadi, Lena Jäger, Rico Sennrich
**Published:** 2026-07-24 | **arXiv:** [2607.22376v1](http://arxiv.org/abs/2607.22376v1)

## Summary
This paper shows how to build machine translation systems for endangered languages by extracting grammatical rules and examples from existing grammar books using large language models, then generating synthetic training data for fine-tuning. The work demonstrates practical improvements on three typologically diverse low-resource languages, opening a path toward translation tools where parallel data doesn't exist but linguistic documentation does.

## Theoretical Background
Machine translation typically requires large parallel corpora (paired sentences in source and target languages) to train effective models. Low-resource languages—especially endangered ones—lack this data. Prior work has used grammar books at inference time by prompting language models with grammatical constraints. This paper builds on two foundations: (1) the ability of large language models to extract and understand structured linguistic information from text, and (2) the practice of fine-tuning pre-trained translation models on domain-specific or synthetic data to improve performance on target tasks. The paper also engages with linguistic typology—the classification of languages by structural features (e.g., word order, case systems)—to understand whether synthetic data strategies generalize across different language families.

## Core Contributions
1. **Extraction pipeline**: A systematic method to use LLMs to extract grammatical rules, example sentences, and lexicons directly from grammar books (rather than using them as prompts at inference).
2. **Synthetic data generation**: Demonstrates that LLM-generated synthetic parallel sentences, derived from extracted grammar, can improve translation quality when used for fine-tuning.
3. **Factorial study design**: Tests 96 configurations across three dimensions (target part-of-speech, retrieval granularity, sample volume) to identify which factor combinations drive gains and where they fail—moving beyond binary "does it work?" to systematic understanding.
4. **Empirical validation on endangered languages**: Shows concrete ChrF++ improvements (+3.3 to +8.8) on three typologically unrelated languages (Papuan, Romance, Siouan), validating generalizability.

## Connections to Other Work
This work sits at the intersection of [[low-resource machine translation]], [[synthetic data generation]], and [[prompt engineering]]. It differs from prior work that feeds grammar into prompts at inference time—instead, it treats grammar books as a data source for offline synthetic generation. The approach relates to broader trends in using [[large language models]] for data augmentation and the growing recognition that linguistic structure can be systematically exploited for NLP tasks. The factorial study methodology echoes experimental design practices in linguistics and human-computer interaction, bringing rigor to the question of "which design choices matter?"

## Practical Applications
1. **Community translation tools**: Endangered language communities can now leverage existing grammar documentation (often created by linguists over decades) to build functional MT systems for preservation, education, and communication.
2. **Language revitalization programs**: Schools teaching endangered languages can use synthetic data to create translation aids for teaching materials.
3. **Cultural heritage digitization**: Organizations documenting endangered languages can create basic MT systems to make archives more accessible.
4. **Linguistic research**: Researchers can rapidly prototype MT systems to test typological hypotheses or validate grammatical descriptions.

## Product & Startup Ideas
1. **Grammar-to-MT SaaS**: A platform where linguists upload grammar books (or sketches), the system extracts rules and generates synthetic data, and outputs a fine-tuned MT model—no parallel corpus required. Market: academic linguists, NGOs, indigenous language organizations.
2. **Language revitalization toolkit**: An end-to-end suite combining grammar extraction, synthetic data generation, and a simple web/mobile translation interface for schools and communities. Freemium model targeting educational institutions.
3. **Endangered language translation API**: A cloud service specializing in low-resource and endangered language pairs, trained on synthetic data from grammar documentation. Pitch to NGOs and UN agencies working on cultural preservation.
4. **Grammar book digitization service**: Help institutions scan, OCR, and convert existing paper grammar books into structured formats that can feed LLM extraction pipelines—creating a data supply chain for MT.
5. **Linguist-in-the-loop annotation tool**: A GUI where linguists iteratively refine extracted grammar and generated sentences, with real-time MT quality feedback, turning grammar book work into collaborative MT development.

## Technical Limitations
1. **Grammar book quality and specificity**: The pipeline depends on the quality and completeness of the source grammar. Many endangered languages have only sketchy or incomplete documentation; results may degrade significantly.
2. **Morphological complexity**: The factorial study hints that performance breaks down for certain part-of-speech combinations—likely morphologically rich languages where synthetic examples may not capture inflectional paradigms fully.
3. **LLM hallucination**: LLMs extracting rules and generating sentences can hallucinate plausible-sounding but incorrect linguistic data, especially for unfamiliar language structures.
4. **Limited scale and baseline models**: The work uses relatively small seed datasets and standard pre-trained models; results may not hold when scaling to larger base models or when starting from very poor initial MT baselines.
5. **Generalization**: Tested on only three languages and a specific LLM (likely GPT or similar). Generalization to other language families, writing systems, or LLM architectures is unclear.
6. **Semantic accuracy**: Synthetic sentences generated from grammar rules may be grammatically correct but semantically implausible or not natural for actual use cases.

## Open Questions
1. **Scaling laws**: How do results change with larger seed datasets, stronger base MT models, or different LLM architectures? Is there a diminishing return as synthetic data increases?
2. **Morphological limits**: Why do certain part-of-speech categories fail? Can the extraction pipeline be enhanced to handle inflectional morphology better?
3. **Grammar coverage**: Which linguistic phenomena from grammar books actually transfer to improvement in translation? Can we identify which rules matter most?
4. **Cross-lingual transfer**: Can synthetic data from a closely related language's grammar help a less-documented language?
5. **Human evaluation**: The paper uses ChrF++ (a metric); human evaluation from native speakers would strengthen claims about practical utility.
6. **Iterative refinement**: Can linguists efficiently correct and improve the synthetic data in a feedback loop, and how much human effort is needed?

## Key Takeaway
Grammar books can be mined to generate synthetic training data that improves translation for endangered languages without parallel corpora.
