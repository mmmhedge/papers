# 4DCodeBench: Benchmarking Agents on Inverse Graphics of Dynamic Scenes

**Authors:** Ruihong Shen, Žiga Kovačič, Peter Kulits, Xingrui Wang, Zizhang Li et al.
**Published:** 2026-10-02 | **arXiv:** [2610.03715v1](http://arxiv.org/abs/2610.03715v1)

## Summary
This paper introduces 4DCodeBench, a benchmark where AI agents reconstruct dynamic 3D scenes from videos by generating executable graphics code. Instead of predicting pixels, agents must understand scene structure and physics well enough to write programs that reproduce complex real-world behavior like deformation, fluids, and fracture. This matters because it tests whether models can truly understand dynamics rather than merely memorizing visual patterns.

## Theoretical Background
The work builds on inverse graphics — the classical computer vision problem of inferring 3D scene properties (geometry, materials, lighting) from 2D images. Traditionally, this has focused on static scenes; this paper extends it to dynamics. It also draws from neural rendering (synthesizing images from learned scene representations) and program synthesis (training models to generate executable code rather than continuous outputs). The core insight is that code is a more interpretable and compositional representation of scene dynamics than pixel predictions or latent vectors — code explicitly encodes physical rules and structure that can be debugged and verified.

## Core Contributions
1. **4DCodeBench itself** — a curated benchmark with real and synthetic videos spanning diverse physical phenomena, designed to measure dynamic scene reconstruction via code generation (not just static geometry).
2. **Systematic evaluation** showing that strong vision models (those good at static 3D reconstruction) fail on dynamics, revealing a genuine gap in current agent capabilities.
3. **Framing of the problem** as code generation for inverse graphics — making the output space executable and verifiable, which enables clearer evaluation of whether agents truly understand physics.

## Connections to Other Work
This relates to broader efforts in [[neuro-symbolic reasoning]] and program synthesis applied to vision. It complements work on [[3D scene understanding]] and neural radiance fields (NeRFs), which focus on rendering rather than interpretability. It sits at the intersection of code generation (similar to [[Code as Policies]] in robotics) and visual reasoning. The benchmark philosophy mirrors other agent-evaluation frameworks that test compositional reasoning rather than end-to-end black-box performance.

## Practical Applications
1. **Robotics & simulation** — agents that can reconstruct scene dynamics could improve sim-to-real transfer by automatically building simulators from real videos.
2. **Scientific discovery** — generating physics-based models from observational video could accelerate system identification in engineering and materials science.
3. **Video editing & effects** — understanding dynamics enables intelligent re-rendering of scenes under counterfactual conditions (e.g., changing material properties).
4. **Virtual production** — reconstructing lighting, geometry, and physics from live-action footage to populate 3D environments.

## Product & Startup Ideas
1. **AI-powered physics engine builder** — SaaS tool where users upload video, an agent generates a simulator, enabling instant physics-based VFX or product prototyping.
2. **Scientific video-to-model platform** — service targeting materials scientists and chemists; upload lab video, receive fitted differential equations and simulation code.
3. **Interactive video understanding** — consumer app where users ask "what would happen if I changed X?" about videos, using agents to answer via re-simulation.
4. **Robotics dataset annotation** — tool for automatically generating ground-truth dynamics models from robot manipulation videos at scale.
5. **Digital twin generation** — enterprise service: record physical machinery, auto-generate executable simulator for predictive maintenance and what-if analysis.

## Technical Limitations
- **Evaluation ambiguity** — matching rendered output to ground truth video is still pixel-level comparison; many physically plausible codes may produce visually similar but different dynamics.
- **Scalability of code generation** — as scene complexity grows, generated code becomes longer and harder for models to synthesize correctly; no analysis of how performance degrades with scene complexity.
- **Sim-to-real gap** — synthetic benchmark may not capture unmodeled physics (contact, friction uncertainty, wear) present in real videos.
- **Limited physical phenomena** — deformation, fluid, and fracture are covered, but other phenomena (e.g., electromagnetic, chemical reactions) are not explicitly evaluated.
- **Agent capability ceiling** — results only test "frontier models"; unclear if the benchmark is solvable with current architectures or if fundamental new methods are needed.

## Open Questions
1. What architectural changes (e.g., neuro-symbolic integration, differentiable physics layers) would help models generate correct dynamics code?
2. Can agents learn shared physical priors across scenes, or do they reconstruct each scene in isolation?
3. How much does code verifiability (e.g., simulation run-time checking) help agents improve during training?
4. Can multi-modal agents (combining vision + language descriptions of physics) outperform vision-only approaches?
5. What is the minimal video length / frame rate needed for reliable reconstruction?

## Key Takeaway
Agents struggle to convert video into physics code even when they excel at static 3D reconstruction, revealing a gap in understanding dynamics.
