# Mitigating Representation Gaps in Amortized Bayesian Inference with Auxiliary Supervision

**Authors:** Hans Olischläger, Svenja Jedhoff, Šimon Kucharský, Aayush Mishra, Stefan T. Radev et al.
**Published:** 2026-09-30 | **arXiv:** [2609.39525v1](http://arxiv.org/abs/2609.39525v1)

## Summary
This paper addresses a practical problem in amortized Bayesian inference — a technique where neural networks learn to approximate posterior distributions directly, enabling fast inference on new data. The authors show that these networks often get stuck in "representation gaps" (local optima) that hurt accuracy, and propose using auxiliary supervision losses on internal network representations to fix this. The work matters because it makes amortized inference more reliable without requiring problem-specific tuning.

## Theoretical Background
Bayesian inference aims to compute posterior distributions — updated beliefs about unknown parameters given observed data. Traditional methods (like MCMC) are computationally expensive. Amortized inference treats this as a neural network learning problem: train a network once to map datasets to posterior distributions, then reuse it for instant inference on new data. The catch is that neural networks are nonconvex optimization problems, so in practice they don't always converge to good solutions. The paper frames this failure through the lens of the information bottleneck — a theoretical concept suggesting that networks compress information into a narrow layer, and poor feature learning can create a bottleneck that sabotages downstream conditional distribution learning.

## Core Contributions
1. **Formalization of representation gaps**: The authors explicitly connect practical amortized inference failures to the information bottleneck problem, showing that networks can get stuck when feature extraction (learning a useful summary of the data) and posterior learning decouple.

2. **Auxiliary supervision framework**: They propose a generic method using auxiliary guidance losses applied to hidden layers during training. These losses push intermediate representations toward better summaries, without requiring problem-specific redesign.

3. **Diagnostic tool**: They provide a diagnostic procedure to distinguish summary failures (bad feature learning) from inference failures (bad posterior mapping), helping practitioners identify which problem they're facing.

4. **Empirical validation**: The approach is tested on challenging real-world inference problems, showing consistent improvements in both convergence speed (with abundant data) and final accuracy (with scarce data).

## Connections to Other Work
This work sits at the intersection of [[neural networks for Bayesian inference]], [[amortized variational inference]], and general deep learning optimization. It relates to broader concerns about [[neural network bottlenecks]] and representation learning quality. The auxiliary loss idea echoes multi-task learning and auxiliary task frameworks in deep learning, though applied here to fix a specific inference pathology. It also complements recent work on improving neural posterior estimation (NPE) and other simulation-based inference (SBI) methods that suffer similar convergence issues in practice.

## Practical Applications
- **Scientific computing**: Speeding up Bayesian inference for expensive simulators (e.g., climate models, particle physics) where retraining is amortized over many posterior queries.
- **Medical diagnostics**: Fast posterior inference over disease model parameters when processing patient data requires millisecond-scale turnaround.
- **Pharmacokinetics**: Inferring drug concentration in patients; amortized models could enable real-time dose adjustment.
- **Structural engineering**: Inferring material properties from sensor data in real time, where each measurement requires instant posterior updates.

## Product & Startup Ideas
1. **SBI-as-a-service platform**: Cloud service offering pre-trained amortized inference networks for common scientific domains (epidemiology, materials science, economics), with automatic auxiliary supervision built in to ensure quality.

2. **Bayesian AutoML tool**: Software that wraps simulator-based models and automatically configures amortized inference with auxiliary supervision, targeting practitioners without deep learning expertise.

3. **Fast posterior database**: Precomputed amortized posteriors for standard statistical models (Bayesian GLMs, mixture models, state-space models) with built-in diagnostics to certify representation quality.

4. **Real-time clinical decision support**: System that trains amortized inference models on hospital data and uses them to provide instant posterior estimates of patient-specific parameters for personalized medicine.

5. **Simulator debugging service**: Tool that ingests user simulators and automatically detects representation gaps using the diagnostic procedure, then suggests architectural/loss modifications to improve inference fidelity.

## Technical Limitations
- **Scalability unclear**: Testing is on "challenging real-world problems," but absolute scale (dimensionality, dataset size) is not transparent; unclear how auxiliary supervision scales to high-dimensional posteriors.
- **Limited theoretical guarantees**: The paper acknowledges that theory guarantees faithfulness "under ideal convergence"; the auxiliary loss framework appears heuristic, lacking convergence proofs.
- **Architecture dependence**: The method still requires choosing which layers to supervise and how to weight auxiliary losses, potentially reintroducing problem-specific tuning.
- **Simulation budget assumption**: The method assumes access to abundant training data (simulations); it doesn't address regimes where simulator calls are the bottleneck.
- **Diagnostic overhead**: The proposed diagnostic for separating summary from inference failures requires additional computation and may not be foolproof in high dimensions.

## Open Questions
- How should practitioners choose which layers to add auxiliary supervision to, and how sensitive is performance to these choices?
- Does auxiliary supervision help when the prior or simulator is misspecified?
- Can the approach be combined with other recent amortized inference improvements (e.g., normalizing flows, attention-based architectures)?
- How does performance degrade as posterior dimensionality increases beyond the tested cases?
- Can the information bottleneck framing be made rigorous for this setting, or is it primarily a useful intuition?

## Key Takeaway
Auxiliary supervision losses on intermediate network layers reliably fixes poor amortized Bayesian inference without problem-specific tuning.
