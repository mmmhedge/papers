# TokenCast: Forecasting Token Consumption During LLM Agent Execution

**Authors:** Chaoqian Ouyang, Ling Yue, Libin Zheng, Huanghui Guo, Shengxiang Xu et al.
**Published:** 2026-09-28 | **arXiv:** [2609.35760v1](http://arxiv.org/abs/2609.35760v1)

## Summary
This paper presents TokenCast, a system that predicts how many tokens an LLM agent will consume during task execution. Token consumption is highly unpredictable because agents take different paths based on tool feedback, and context grows with each step—making costs vary by 10× or more across runs. TokenCast learns lightweight "cost representations" for each execution segment and composes them to forecast total consumption, updating predictions as the run unfolds without needing extra LLM calls.

## Theoretical Background
LLM agents (systems that call language models repeatedly to solve tasks) operate iteratively: they observe feedback, decide next steps, and accumulate context. Each call reads the full conversation history plus new information, so the input size grows predictably but the number of steps does not. Prior work on LLM cost modeling typically estimates from static task descriptions alone, missing the dynamic branching that causes 10× variance in practice. This paper treats token consumption as a composition problem: each segment (one agent step) has local cost plus "context inflation"—the fact that all future steps must re-read it.

## Core Contributions
1. **Composable cost representation**: A formal framework where each execution segment records its own token consumption and the context growth it introduces to downstream calls. Adjacent segments compose to yield cumulative predictions that account for repeated context reading.
2. **Online forecasting with evidence refresh**: As execution unfolds, observed segment costs update predictions without requiring new LLM calls (mean latency 32.8 ms per run).
3. **Strong empirical validation**: 14.5% mean absolute error improvement over baselines across 4 task suites and 6 agent models (96 combinations tested). In budget-control replay, TokenCast uses 21.3% fewer tokens than fixed-budget policies at matched completion rates.

## Connections to Other Work
This work complements research on [[agent planning]] and [[tool use]] by solving the cost-control problem that arises when agents explore variable-length execution paths. It relates to [[reinforcement-learning]] cost optimization but operates in a predictive rather than policy-learning paradigm. The composition of local costs mirrors techniques in [[hierarchical reinforcement learning]] and flow networks. Budget-aware execution connects to work on efficient inference and resource-constrained LLM serving.

## Practical Applications
- **Cost forecasting for LLM agent platforms**: Companies running agents at scale (e.g., autonomous software engineers, research assistants) need per-task cost budgets; TokenCast enables accurate billing and resource allocation.
- **Budget-aware agent routing**: Dynamically decide whether to escalate a task to a more capable (expensive) agent model, or retry with a cheaper one, based on predicted consumption.
- **SLA compliance**: Guarantee token budgets for SLA contracts without over-provisioning.
- **Real-time cost governance**: Monitor live agent execution and pause/redirect tasks that exceed predicted budgets.
- **Cost-conscious benchmark evaluation**: Fairly compare agent systems by normalizing for variable-path execution rather than assuming fixed costs.

## Product & Startup Ideas
1. **LLM Agent Cost Analytics Platform**: A SaaS dashboard integrating TokenCast to monitor, predict, and optimize token spend across teams running diverse agent workloads. Upsell: cost anomaly detection, per-team quotas, and cost attribution.
2. **Autonomous Software Engineer Billing Layer**: Transparent, per-task token cost forecasting for code-generation agents (SWE-bench style); enables competitive per-issue or per-sprint pricing models for enterprise software engineering automation.
3. **Agent Simulator & Cost Validator**: Pre-execution environment that runs TokenCast offline to validate agent configurations and predict failure modes before deploying to production (reduces failed/expensive runs).
4. **Multi-Agent Orchestration Controller**: Middleware that selects which agent model to route tasks to based on TokenCast forecasts, optimizing for cost-quality tradeoff in real time.
5. **LLM Agent Insurance / Escrow Service**: Underwrite cost uncertainty for agent-driven workflows; use TokenCast predictions to price risk and set performance bonds.

## Technical Limitations
- **Generalization to unseen task types**: TokenCast learns from execution traces; performance on entirely new domains or task distributions is not thoroughly validated.
- **Long-horizon tasks and context explosion**: The model assumes composability of local costs, which may break if segment interactions are complex or nonlinear (e.g., early decisions dramatically reshape later paths).
- **Agent-model dependency**: Predictions are trained per-agent-model; transferability across model families is limited.
- **Off-policy replay assumptions**: Budget-control evaluation uses *offline* replay traces, not live agent control; online performance and feedback loops are not tested.
- **No exploration of adaptive stopping**: The paper does not address early termination or dynamic budget reallocation mid-execution beyond simple prediction updates.

## Open Questions
1. **Can TokenCast transfer across agent models or architectures** without retraining? What is the generalization gap?
2. **How does performance scale to multi-hour, multi-stage workflows** where segment interactions and context dependencies become nonlinear?
3. **Can TokenCast inform agent *policy* learning** (e.g., training agents to take cheaper paths)? Is there a feedback loop?
4. **What happens with hierarchical or recursive agent calls**, where one agent spawns sub-agents? Does composition still hold?
5. **Can TokenCast integrate with real-time LLM provider APIs** to predict actual billable cost, including batch discounts or dynamic pricing?

## Key Takeaway
TokenCast predicts LLM agent token consumption mid-execution by composing local segment costs, improving budget forecasts by 14.5% over baselines without extra inference.
