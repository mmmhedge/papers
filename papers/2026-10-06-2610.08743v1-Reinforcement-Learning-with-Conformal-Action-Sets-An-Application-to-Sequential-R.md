# Reinforcement Learning with Conformal Action Sets: An Application to Sequential Recommendation

**Authors:** Wenwen Si, Honghao Wei
**Published:** 2026-10-06 | **arXiv:** [2610.08743v1](http://arxiv.org/abs/2610.08743v1)

## Summary
This paper proposes RLCP (Reinforcement Learning with Calibrated Pruning), a method that dynamically adjusts which items a recommender system considers at each step in a user session, rather than always using a fixed set. The key insight is that the number of genuinely good options changes as users browse, so adapting the action set improves both recommendation diversity and efficiency. The authors prove theoretical bounds on performance and show their approach outperforms fixed-slate baselines by 1–5× on diversity metrics.

## Theoretical Background
Sequential recommendation treats the problem as a [[Reinforcement Learning]] task where an agent (the recommender) learns a policy to select items that maximize cumulative user satisfaction over a session. Prior work typically uses a fixed slate size — returning the same number of items regardless of context. This paper builds on three foundational ideas: (1) **critic-based pruning** — using a value function (critic) to score which actions are worth keeping, (2) **conformal inference** — a statistical framework for constructing sets with coverage guarantees, and (3) **value decomposition** — breaking down total reward loss into interpretable components (filtering and selection). The method also relies on binary feedback (e.g., "was the recommended item in this session useful?") to calibrate an online threshold that decides which items survive pruning.

## Core Contributions
1. **RLCP algorithm**: A concrete approach combining critic scores with online threshold calibration to dynamically prune action sets, avoiding hand-tuned fixed slates.
2. **Deterministic proxy miss-rate bound**: Proves that the probability of filtering out a desirable item is bounded even along adaptive (non-stationary) trajectories.
3. **Value loss decomposition**: Derives an exact formula decomposing reward loss into filtering loss (missing good items) and selection loss (picking bad items), which clarifies the trade-off between pruning aggressiveness and recommendation quality.
4. **Finite-session reward bound**: Provides a performance guarantee that holds without convergence assumptions and accounts for both critic approximation error and set truncation effects.
5. **Empirical validation**: Demonstrates up to 5.21× improvement in catalog diversity on real datasets (KuaiRand-Pure, MovieLens 1M) while maintaining competitive session depth.

## Connections to Other Work
This work sits at the intersection of [[Reinforcement Learning]] for recommendations, [[optimization]] under uncertainty, and conformal prediction:
- **RL for recommendations**: Related to Q-learning and actor-critic methods applied to slate recommendation (e.g., learning to rank systems), but novel in treating action set cardinality as a learnable variable.
- **Action space reduction**: Connects to curriculum learning and exploration–exploitation trade-offs by dynamically narrowing the decision space.
- **Conformal prediction**: Uses coverage guarantees (a hallmark of conformal inference) to ensure key items aren't filtered, addressing a classical reliability challenge in pruning heuristics.
- **Value decomposition**: Related to reward shaping and multi-objective RL, but here the decomposition is provably exact and interpretable.

## Practical Applications
1. **E-commerce search & personalization**: Reduce computational cost and latency by only scoring a curated subset of inventory per user session, while maintaining diversity.
2. **Video streaming platforms** (Netflix, YouTube): Adapt recommendation set sizes based on session context—fewer options during peak engagement, richer exploration during browsing phases.
3. **Music/podcast apps**: Dynamically grow or shrink candidate playlists to match user behavior, reducing decision fatigue early in sessions and expanding options for power users.
4. **Job boards & dating apps**: Tailor the number of matches or listings shown based on implicit user engagement signals, improving click-through rates and session length.
5. **Real-time ad serving**: Prune low-relevance ads before expensive ranking models, reducing serving latency in millisecond-critical auction environments.

## Product & Startup Ideas
1. **"SmartSlate" — RL recommendation middleware**: A plug-and-play service for B2B e-commerce and SaaS platforms that learns per-user session dynamics to auto-tune slate sizes, sold as a recommendation-as-a-service (RaaS) product with measurable diversity/CTR lift.
2. **"CatalogOptimizer" — inventory diversification platform**: Helps retailers discover and promote underexposed SKUs by using RLCP to adaptively expand action sets for cold-start or low-engagement users, funded on performance (% revenue from promoted items).
3. **"AdaptiveRank" — streaming personalization engine**: A specialized recommender for video/music platforms that learns when to show more/fewer options based on watch-time patterns, reducing churn through optimal choice architecture.
4. **"DynamicExploration" — A/B testing & bandit platform**: Wraps RLCP's conformal coverage guarantees into an MLOps tool so product teams can safely prune low-performing variants without risking coverage losses.
5. **"SessionInsight" — analytics + optimization dashboard**: Visualizes how different users benefit from different slate sizes and filters in real time, then auto-configures per-segment thresholds, targeting mid-market SaaS.

## Technical Limitations
1. **Binary feedback requirement**: The method assumes access to binary proxy labels (e.g., "item was useful") on held-out sets, which may not always be available or accurate in sparse-feedback environments (e.g., implicit-only interactions).
2. **Critic approximation**: Theoretical bounds assume a well-behaved critic; in practice, value-function approximation error can be large, potentially invalidating guarantees.
3. **Threshold calibration lag**: The online threshold update relies on recent feedback; in cold-start or highly non-stationary sessions, the threshold may lag behind true underlying item utilities.
4. **Computational assumptions**: The paper assumes critic scores are cheaply computable; if scoring is expensive (e.g., deep neural nets), pruning overhead may not be negligible.
5. **Session independence**: The approach treats sessions as independent; longer user journeys with strong carryover effects may violate model assumptions.
6. **Catalog size**: Scalability to very large catalogs (billions of items) is unclear, as pruning still requires scoring many candidates before thresholding.

## Open Questions
1. **What is the optimal threshold update frequency?** Should it adapt per-session, per-user, or globally? How sensitive are results to this choice?
2. **Can the method handle implicit feedback only?** Many real systems lack explicit binary labels; can proxy signals be learned end-to-end?
3. **How does RLCP compare to learned slate-size prediction (e.g., a separate RL agent choosing cardinality)?** Is conformal pruning strictly better?
4. **Does the approach generalize across domains?** Results are shown on movies and video; do benefits persist for product search, ads, or other domains with different session dynamics?
5. **Can you extend RLCP to multi-objective settings** (e.g., simultaneous optimization of diversity, relevance, and revenue) without losing the decomposition and bounds?
6. **What happens with non-stationary critic models?** If the critic is continuously retrained, do the theoretical guarantees still hold?

## Key Takeaway
Dynamically pruning recommendation candidates using critic scores and conformal thresholds improves diversity by 5× while reducing computational cost per session.
