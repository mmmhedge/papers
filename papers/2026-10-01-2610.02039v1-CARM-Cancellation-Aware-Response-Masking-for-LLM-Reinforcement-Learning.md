# CARM: Cancellation-Aware Response Masking for LLM Reinforcement Learning

**Authors:** Yafei Zhang, Songshuo Lu, Sicong Liao, Zhi Chen, Yaohua Tang
**Published:** 2026-10-01 | **arXiv:** [2610.02039v1](http://arxiv.org/abs/2610.02039v1)

## Summary
This paper addresses a critical problem in LLM reinforcement learning: when policy updates happen during training, some sampled responses become "off-policy" (generated under an older policy) and shouldn't fully guide learning. The authors show that standard masking approaches can mask problematic policy drift because positive and negative probability changes cancel each other out. They propose CARM, a better masking rule that prevents this cancellation and improves performance on math reasoning and code generation tasks by 2–3 percentage points.

## Theoretical Background
Large language models are increasingly trained using reinforcement learning rather than supervised learning alone. In RL, a policy (the model's decision-making function) is optimized by sampling responses, scoring them (e.g., correct answer vs. incorrect), and updating weights. A key challenge: if the policy changes during training, responses sampled early under an old policy shouldn't be weighted equally to responses sampled under the current policy — this is the "off-policy problem."

Prior work uses sequence-level masking: compute a single score for each full response that determines whether it contributes to the gradient. A common approach uses length-normalized geometric mean of token probability ratios (the ratio of probability under new policy vs. old policy for each token). The paper identifies a subtle but important flaw: if one token's probability ratio rises and another falls, their log-ratios can cancel in the geometric mean, hiding the fact that the policy has drifted substantially in opposing directions.

## Core Contributions
1. **Identifies a real failure mode**: Shows that geometric-mean masking can mask significant bidirectional policy drift because opposite log-ratio changes cancel.
2. **Proposes CARM**: Uses absolute value of each token's log-ratio before averaging, ensuring all drift is "visible" to the masking rule.
3. **Theoretical justification**: Proves that responses accepted by CARM satisfy a joint bound: a bounded fraction of token ratios fall outside a prescribed band, and those that do have bounded mean log-distance beyond it.
4. **Empirical validation**: Demonstrates consistent improvements on two practically important domains (math reasoning via AIME, code generation via multiple benchmarks).

## Connections to Other Work
This work sits at the intersection of [[off-policy learning]] (a classical RL problem) and modern [[LLM post-training]] via techniques like [[RLHF]] (Reinforcement Learning from Human Feedback). It's related to broader work on trustworthy policy optimization and importance weighting — fields that have grappled with distributional mismatch for decades in traditional RL. The paper improves on prior [[response-level masking]] approaches by fixing a subtle but consequential bug in how policy divergence is measured.

## Practical Applications
1. **Math reasoning systems**: Directly improves performance on competition-level math problems (AIME), relevant for tutoring, research assistants, and mathematical software.
2. **Code generation**: Boosts pass rates on code benchmarks, enabling more reliable code synthesis tools for software engineering.
3. **Faster LLM training**: Better off-policy control means fewer wasted gradient updates, reducing compute cost for LLM fine-tuning.
4. **Real-time LLM adaptation**: In deployed systems where the policy is continuously updated, CARM ensures new training data doesn't destabilize the system via off-policy drift.

## Product & Startup Ideas

## Technical Limitations
1. **Bounded to sequence-level masking**: Doesn't address finer-grained (e.g., token-level) off-policy control; assumes binary accept/reject per response.
2. **Policy divergence assumptions**: The theoretical bounds assume token log-ratios follow certain distributional properties; heavy-tailed or multimodal divergence may violate assumptions in practice.
3. **Computational overhead unclear**: No reported cost of computing absolute-value log-ratios vs. geometric mean; likely negligible but not explicitly measured.
4. **Limited domain scope**: Only tested on math and code; unclear how well CARM generalizes to dialogue, summarization, or other RL-trained LLM tasks.
5. **Hyperparameter sensitivity**: The "band" width in the theoretical bound is a design choice; paper doesn't explore sensitivity to this threshold.
6. **Comparison baseline**: Only compares to geometric-mean masking and one baseline; missing comparisons to other off-policy RL techniques (e.g., behavior cloning warm-starts, KL regularization variants).

## Open Questions
1. **Can CARM be extended to token-level masking?** Would finer-grained control (masking individual bad tokens rather than whole responses) yield further gains?
2. **Why does CARM work so well empirically?** The theoretical bound is necessary but is it tight? Do experiments reveal how much drift typical responses exhibit?
3. **How does CARM interact with KL penalties?** Many LLM RL systems also include a KL divergence penalty; do CARM and KL penalties work redundantly or synergistically?
4. **Generalization to other RL algorithms**: Does CARM help with PPO, DPO, or other policy optimization methods beyond the one tested?
5. **Scaling behavior**: Do improvements hold as model and dataset size grow? Is CARM's benefit consistent or does it saturate?
6. **Off-policy threshold tuning**: How sensitive are results to the band width hyperparameter? Is there a principled way to set it?

## Key Takeaway
CARM prevents policy drift from hiding in RL-trained LLMs by unmasking canceling probability changes, boosting math and code performance by 2–3 percentage points.
