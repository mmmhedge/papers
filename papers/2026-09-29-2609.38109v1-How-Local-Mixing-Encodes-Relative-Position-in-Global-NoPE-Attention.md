# How Local Mixing Encodes Relative Position in Global NoPE Attention

**Authors:** Cutter Dawes, Nick Alonso, Tom Figliolia, Beren Millidge
**Published:** 2026-09-29 | **arXiv:** [2609.38109v1](http://arxiv.org/abs/2609.38109v1)

## Summary
This paper explains how transformer models can work without explicit position encodings (like RoPE) when they combine local attention layers (like sliding window attention) with global attention layers. The key finding: local mixing layers create a "recency bias" in the model's internal representations that carries position information forward, allowing global attention to implicitly track sequence positions. This matters because it challenges the assumption that explicit position encodings are necessary and suggests a path toward position representations that could generalize to longer sequences.

## Theoretical Background
Transformers use attention mechanisms — neural networks that compute weighted combinations of input elements based on learned similarities. A core problem: attention is position-invariant on its own, so transformers need position encodings to know where in a sequence each token appears. Traditional approaches use explicit encodings like RoPE (rotary position encoding), which directly encode absolute or relative positions into token representations.

Recent hybrid architectures interleave local mixing layers (e.g., sliding window attention — attention computed only over a fixed local context window) with global NoPE (no position encoding) attention layers. These models work surprisingly well at scale despite lacking explicit position signals in global layers. This paper investigates the mechanism behind this empirical success through mechanistic interpretability — analyzing how neural networks actually process information internally.

## Core Contributions
1. **Identifies the mechanism**: Local mixing layers (SWA, gated linear attention) induce recency bias in the residual stream — the accumulated information flowing through the network — that persists and is selectively accessed by global attention logits.

2. **Proves persistence across long sequences**: Unlike purely global NoPE models (where position info only comes from causal masking), hybrid models maintain recency bias over arbitrarily long sequences, solving a key limitation.

3. **Provides dual evidence**: Supports findings with both theoretical analysis and empirical validation, moving beyond pure speculation about why these architectures work.

4. **Implications for extrapolation**: Suggests that implicit position encodings via local-global mixing may naturally extrapolate to longer sequences than explicitly encoded positions.

## Practical Applications
1. **Longer-context language models**: Hybrid architectures with implicit position encoding may scale to substantially longer sequences (documents, code files, conversations) with better generalization than models requiring fixed position embeddings.

2. **Efficient inference**: Hybrid models using local attention windows require less computation; understanding why they work enables better optimization without sacrificing capability.

3. **Multi-document retrieval and reasoning**: Systems processing very long documents or multiple documents sequentially could benefit from position encodings that naturally extrapolate beyond training length.

4. **Domain transfer**: Models trained on one sequence length could adapt to longer sequences in new domains without retraining position encodings.

## Technical Limitations
1. **Limited scope of analysis**: Paper focuses on SWA and gated linear attention; generalization to other local mixing strategies (e.g., block-wise attention, sparse patterns) unclear.

2. **Scaling questions**: Empirical validation likely on standard benchmarks; unclear how implicit position encoding scales to truly extreme lengths (millions of tokens) or how it degrades gracefully at distribution shift.

3. **Training dynamics not addressed**: Paper analyzes inference-time behavior; how recency bias emerges *during training* and whether it's stable across optimization trajectories is unclear.

4. **Causal mask dependency**: Findings may depend on causal masking in global layers; applicability to bidirectional attention (encoder layers) or non-sequential tasks is unexplored.

5. **Interaction with other inductive biases**: Real models have layer normalization, skip connections, and other components; whether recency bias interacts cleanly with these is not fully characterized.

## Open Questions
1. **Theoretical bounds**: Can you formally prove that recency bias induced by local mixing propagates reliably across all sequence lengths, or are there regimes where it breaks down?

2. **Comparison to explicit encodings**: How does implicit position encoding via local mixing *compare quantitatively* to RoPE or other explicit methods on length extrapolation? Which is fundamentally stronger?

3. **Architectural ablations**: What properties of local mixing layers are *necessary* for recency bias? Can you induce it with simpler mechanisms (e.g., learned mixing without SWA)?

4. **Bidirectional models**: Do these findings apply to encoder-only or encoder-decoder models without causal masking? Can implicit position encoding work there?

5. **Mechanistic details**: Can you trace *exactly* which attention heads and residual components carry positional signal, and do they align with interpretable linguistic or structural roles?

6. **Generalization to 2D/3D**: Do hybrid local-global architectures work for vision transformers or other non-sequential domains, and does the recency bias analogue exist?

## Key Takeaway
Local attention layers create a recency signal that global attention naturally uses, removing the need for explicit position encodings and enabling better length generalization.
