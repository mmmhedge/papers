# Optimal Control with Expectation Constraint in a Smooth Boundary Case

**Authors:** Bruno Bouchard, Lucas Gnecco Heredia, Ludovic Moreau, Kim-Anh Pham
**Published:** 2026-07-27 | **arXiv:** [2607.24114v1](http://arxiv.org/abs/2607.24114v1)

## Summary
This paper solves a utility maximization problem with an expectation constraint — a classic problem in portfolio optimization — by proving the boundary of the feasible region is smooth and deriving the correct boundary conditions for the value function. The authors develop new PDE approximation methods that work in both regular and degenerate cases, and demonstrate that neural networks can solve these problems numerically, opening the door to practical computational methods for constrained portfolio optimization.

## Theoretical Background
The paper builds on classical stochastic control theory and the utility maximization framework in mathematical finance. Utility maximization asks: given uncertain returns, how should an investor allocate capital to maximize expected satisfaction (utility) while respecting constraints? An expectation constraint (e.g., "ending wealth must be at least some target in expectation") makes the problem harder because the constraint couples decisions across time and states.

Prior work (Bouchard et al. 2010, 2014) formulated these problems as constrained optimal control, but lacked tools to actually solve them. The key mathematical objects are:
- **Value function** — the maximum utility achievable from any starting state
- **HJB equation** — a nonlinear partial differential equation (PDE) characterizing the value function
- **Ellipticity** — a technical condition ensuring the PDE is well-behaved (uniformly elliptic = "nice"; degenerate = "harder")

The paper's core insight is that when you impose an expectation constraint, it implicitly defines a boundary in state space. The authors prove this boundary is smooth (no corners, cusps), which lets them impose proper **Dirichlet boundary conditions** (specifying the value function's value on the boundary) — a crucial step for turning the problem into something you can actually compute.

## Core Contributions

1. **Smoothness of constraint boundary**: First rigorous proof that the endogenous boundary defined by the expectation constraint is smooth in the uniformly elliptic case — this is non-trivial and enables boundary condition derivation.

2. **New martingale truncation argument**: A novel approximation technique that truncates the martingale representation of the constraint, yielding a sequence of auxiliary PDE systems where comparison principles hold (comparison principles guarantee stability and uniqueness).

3. **Degenerate case handling**: A second approximation by adding small noise to recover uniform ellipticity, with convergence guarantees — extends applicability beyond the ideal case.

4. **First complete PDE analysis**: As the authors note, this is the first full theoretical analysis enabling numerical schemes for these problems.

5. **Neural network implementation with error bounds**: Demonstrates numerically that neural networks can solve these constrained control problems and provides error estimates using a neural network approach.

## Connections to Other Work
This work extends [[stochastic control theory]] to a previously intractable class: constrained utility maximization. It relates to:

- **RLHF and constraint satisfaction**: While in a different domain, the problem of optimizing an objective (like a language model's reward) while respecting an expectation constraint parallels constraint handling in [[reinforcement-learning]] — both need to balance primary and secondary goals.
- **Value function approximation**: Neural network approaches for solving PDEs (e.g., DeepONet, PINNs) have shown promise; this paper contributes a concrete application with error analysis.
- **Martingale methods in finance**: Classical duality theory in portfolio optimization; this work brings rigorous PDE machinery to expectation-constrained variants.

## Practical Applications

1. **Portfolio optimization with minimum guarantee**: Investors want maximum returns subject to "portfolio value stays above $X in expectation" — directly this problem.

2. **Pension fund management**: Scheme trustees must ensure expected future obligations are met while maximizing returns on contributions.

3. **Constrained wealth management**: High-net-worth clients often require floor constraints (e.g., "don't let my wealth drop below this level in expectation") alongside upside participation.

4. **Insurance reserve optimization**: Insurers manage premium investments under regulatory constraints on solvency (expectation of reserves ≥ claims).

5. **Risk-constrained algorithmic trading**: Hedge funds using [[algorithmic-trading]] frameworks may want to maximize expected returns while constraining expected drawdown or volatility.

## Product & Startup Ideas

1. **Constrained portfolio optimizer SaaS**: Cloud-based tool for advisors to compute optimal allocations under client-specified expectation constraints, with real-time rebalancing and reporting.

2. **Pension liability matching engine**: Automate portfolio construction for pension funds to simultaneously match liabilities in expectation and maximize returns, replacing spreadsheet-based heuristics.

3. **Risk-bounded robo-advisor platform**: Retail investment app that learns user risk aversion and computes portfolios respecting both return targets and expected loss constraints (e.g., "95% chance of reaching goal").

4. **Enterprise compliance optimization**: Software for institutional asset managers to manage regulatory capital requirements and expectation constraints through automated portfolio optimization.

5. **Decentralized finance (DeFi) yield optimizer**: Smart contract that allocates capital across DeFi protocols subject to expectation-based loss constraints, using neural network solvers on-chain or off-chain.

## Technical Limitations

1. **Smoothness assumption fragility**: The proof relies on uniform ellipticity; real market volatility can be stochastic and degenerate. The degenerate approximation adds noise — a practical workaround but artificial.

2. **Scalar state space in toy example**: Numerical demonstration uses a simple 1D example; scaling to realistic portfolios (10–100+ assets) and solving the implied high-dimensional PDEs is non-trivial.

3. **Neural network error control**: While error bounds are provided, they depend on network architecture and training. Practical guarantees in high dimensions remain unclear.

4. **Constraint definition**: The paper assumes the expectation constraint is known and fixed; real clients often have implicit or evolving constraints.

5. **Computational cost**: Solving high-dimensional PDEs with neural networks is expensive; real-time rebalancing for large portfolios may be infeasible.

6. **Model risk**: The approach assumes known asset dynamics; misspecification of volatility or drift will propagate through the solution.

## Open Questions

1. **High-dimensional scalability**: Can the neural network approach scale to 20+ assets with certified error bounds?

2. **Stochastic coefficients**: What happens if volatility or drift themselves follow stochastic processes?

3. **Multiple constraints**: How does the method extend to multiple expectation constraints (e.g., floor on wealth AND capped downside)?

4. **Adaptive noise in degenerate case**: Can you optimize the noise level added in the degenerate approximation, or prove convergence rates as noise → 0?

5. **Numerical scheme comparison**: How do these neural network solutions compare to standard PDE schemes (finite difference, finite element) in accuracy and speed?

6. **Path-dependent constraints**: Can you handle constraints on the path of the portfolio (e.g., "maximum drawdown in expectation") rather than just terminal values?

## Key Takeaway
Neural networks can now solve utility maximization with expectation constraints by leveraging smooth boundary theory and approximation schemes.
