# Planning to Learn

**Authors:** Ian Osband
**Published:** 2026-10-02 | **arXiv:** [2610.03667v1](http://arxiv.org/abs/2610.03667v1)

## Summary
This paper shows that standard cross-entropy loss implicitly optimizes for a long-horizon objective — it's patient about accuracy, considering how each update affects future learning. The authors propose "horizon loss," which interpolates between cross-entropy and exact policy gradients by accounting for remaining training time. On image classification tasks (MNIST, ImageNet with ResNets and ViTs), this one-line change improves accuracy, especially under label noise.

## Theoretical Background
Policy-gradient methods (algorithms that learn by differentiating expected reward with respect to actions) are the backbone of modern reinforcement learning and LLM fine-tuning. In classification, the "policy" is a classifier and the "reward" is accuracy — the model gets the label right. Normally, the exact policy gradient would be perfect for this problem: the label is known, so the gradient is unbiased and smooth. Yet in practice, cross-entropy loss outperforms the exact gradient. The paper explains this puzzle by treating training as a sequential decision problem: each parameter update chooses where the next update starts, so an update's true value includes not just immediate accuracy gains but how it positions the learner for future improvements. This is a *planning* perspective on supervised learning — the model should learn in a way that sets itself up for continued progress.

## Core Contributions
1. **Conceptual reframing**: Shows cross-entropy loss as "patient accuracy" — optimizing total error reduction over an infinite training horizon — rather than a heuristic choice. This connects supervised learning to planning and long-horizon optimization.
2. **Horizon loss**: A practical modification that truncates the infinite-horizon objective at the actual remaining training time. It's provably superior to both cross-entropy and exact policy gradient in a toy allocation model.
3. **Empirical validation**: Demonstrates consistent gains on realistic vision benchmarks (MNIST, ImageNet with modern architectures), with larger improvements under label noise where forward-looking updates matter more.

## Connections to Other Work
This work bridges [[reinforcement-learning]] (policy gradients, long-horizon planning) and supervised learning (classification, cross-entropy). It relates to:
- **Policy-gradient theory**: Exact gradients vs. biased approximations; the paper shows exact gradients can be myopic.
- **Curriculum learning and sample weighting**: Both adjust training emphasis over time; horizon loss does this implicitly via the learning curve.
- **LLM post-training**: The motivation mentions policy-gradient methods in LLM fine-tuning (e.g., [[RLHF]]), suggesting the insights may apply beyond classification.
- **Optimization theory**: Connects to second-order effects and trajectory-dependent learning dynamics.

## Practical Applications
1. **Image classification under noisy labels**: Real-world annotation is imperfect (medical imaging, crowdsourced data). Horizon loss's gains scale with label noise, making it directly applicable.
2. **LLM fine-tuning and RLHF**: If supervised classification improves under horizon loss, policy-gradient methods for language models may benefit from similar long-horizon framing.
3. **Active learning and curriculum design**: Systems that decide which examples to train on next could use horizon loss insights to balance immediate accuracy with future learning potential.
4. **Resource-constrained training**: When compute budgets or epoch limits are known in advance, the horizon-aware objective can adapt the learning strategy accordingly.

## Product & Startup Ideas
1. **Noise-robust learning platform**: A training library that auto-detects label noise and switches to horizon loss (or tunes the horizon parameter), targeting medical imaging, manufacturing QA, and crowdsourced data.
2. **Adaptive LLM fine-tuning service**: An API wrapper around RLHF and supervised fine-tuning that uses horizon-aware objectives, reducing training time and improving sample efficiency for enterprise customers.
3. **Curriculum learning optimizer**: A tool that learns when to introduce hard examples and when to switch objectives, using horizon loss as a principled objective for scheduling.
4. **Data quality auditor**: A system that measures implicit label noise in real datasets and recommends horizon loss configurations to maximize accuracy given the noise level.
5. **Efficient vision model training**: A framework that compresses training time for vision models by using horizon loss with adaptive learning rates, targeting mobile and edge ML practitioners.

## Technical Limitations
1. **Theory-practice gap**: The theoretical analysis relies on a simple allocation model. It's unclear how tight the guarantees are on real networks with complex loss landscapes.
2. **Horizon specification**: The method requires knowing (or estimating) remaining training time. In practice, early stopping, learning-rate schedules, and dynamic compute budgets make this ambiguous.
3. **Limited architectural scope**: Experiments are on vision models (ResNets, ViTs). Generalization to transformers, recurrent models, and other domains is untested.
4. **Noise assumption**: Gains are largest under label noise; on clean data the improvement over cross-entropy is modest, limiting general applicability.
5. **Computational overhead**: The paper doesn't discuss whether computing or storing the horizon-weighted objective adds memory or wall-clock cost.
6. **Interaction with other techniques**: Modern training uses batch normalization, label smoothing, mixup, and other regularizers. How horizon loss interacts with these is unexplored.

## Open Questions
1. **What is the optimal horizon schedule?** The paper truncates at remaining time; could a learned or adaptive schedule outperform a fixed formula?
2. **Does this scale to language models?** Early results in LLM post-training are crucial for adoption. Does the insight hold for decoder-only transformers and RLHF?
3. **Can we derive tight sample-complexity bounds?** The allocation model is idealized. What guarantees hold in the overparameterized regime?
4. **How does horizon loss interact with other losses and regularizers?** Combined with label smoothing, focal loss, or contrastive objectives, what happens?
5. **Is there a meta-learning angle?** Could the horizon parameter be learned as a hyperparameter, or adapted per-task or per-layer?
6. **Why does cross-entropy empirically encode a long-horizon objective?** A more mechanistic explanation (e.g., via implicit regularization or loss landscape structure) would strengthen the theory.

## Key Takeaway
Cross-entropy is secretly long-horizon; accounting for remaining training time improves classification accuracy.
