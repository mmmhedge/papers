# Typological Alignment of Stack-Based Language Models on Mildly Context-Sensitive Artificial Languages

**Authors:** Nadine El-Naggar, Tatsuki Kuribayashi, Ted Briscoe
**Published:** 2026-10-01 | **arXiv:** [2610.02040v1](http://arxiv.org/abs/2610.02040v1)

## Summary
This paper investigates why certain grammatical structures (like word order patterns) appear more frequently across human languages by testing how stack-based language models learn artificial languages with varying complexity. The authors find that models with limited working memory struggle less with cross-serial dependencies—nested grammatical patterns that represent the upper limit of human language complexity—suggesting this constraint might explain why natural languages tend to avoid such patterns.

## Theoretical Background
The paper builds on typological linguistics, which documents patterns across thousands of natural languages (e.g., some word orders like SOV are far more common than others). It draws on computational learning bias theory: the idea that artificial constraints in how neural networks learn can explain these universal patterns. Previous work has used language models to simulate language learning and explore whether neural inductive biases predict typological commonalities. This work extends that line by examining stack-based language models—architectures that explicitly maintain a bounded stack (memory structure) to process hierarchical information—rather than standard transformer models.

## Core Contributions
1. Systematic evaluation of stack-based language models (SLMs) on cross-serial dependencies across diverse artificial languages, confirming they struggle with this pattern.
2. A novel finding: SLMs with *limited* working memory actually generalize *better* on these constructions, suggesting the working memory constraint itself creates a useful inductive bias.
3. A mechanistic explanation linking this computational bottleneck to typological commonality—the observation that natural languages avoid cross-serial dependencies correlates with the difficulty these models face.

## Connections to Other Work
This extends computational approaches to [[typological universals]] by moving beyond standard transformers to architecturally constrained models. It relates to [[mechanistic interpretability]] work by examining how architectural constraints (stack size, memory limits) shape what patterns models can learn. The focus on artificial grammars connects to [[context-free]] and [[mildly context-sensitive]] language hierarchies in formal linguistics, and to prior work using LMs to model language evolution and acquisition.

## Practical Applications
- **Linguistic typology databases**: Improve prediction of which grammatical constructions should be rare or absent in natural languages by simulating learning curves with constrained models.
- **Language documentation**: Help linguists prioritize which constructions to elicit in endangered language fieldwork, based on predicted rarity.
- **Neural architecture design**: Inform the design of language models for low-resource languages by understanding which inductive biases aid learning.
- **Language pedagogy**: Predict which L2 grammatical structures will be harder to teach, based on learning simulations.

## Product & Startup Ideas
1. **Typological prediction engine**: A web tool that predicts grammatical complexity and likelihood of attestation for constructed languages or linguistic hypotheses, powered by constrained LM simulations.
2. **Endangered language learning optimizer**: Adapt curriculum design for endangered language documentation by using constrained LMs to identify which structures to prioritize.
3. **Linguistic research SaaS**: Offer researchers interactive notebooks to test hypotheses about typological patterns by training SLMs on custom artificial grammars.

## Technical Limitations
- **Artificial language simplicity**: Findings on synthetic cross-serial dependencies may not generalize to the richer, messier syntax of natural languages with morphology, pragmatics, and real-world ambiguity.
- **Stack-based architecture constraints**: SLMs are not widely used; unclear how findings transfer to dominant transformer architectures deployed in production.
- **Limited memory scope**: The paper tests limited working memory, but does not systematically vary memory size or explore the precise threshold at which the bias emerges.
- **Evaluation scope**: Tests only grammatical generalization; does not measure performance on meaning or downstream tasks, so unclear if the inductive bias helps or hurts real-world language understanding.
- **Causality direction**: Shows correlation between memory limits and typological commonality, but does not definitively prove that natural languages evolved to respect memory constraints rather than that memory-respecting languages are simply easier to learn *for other reasons*.

## Open Questions
- How do results change with continuous or soft (attention-based) memory instead of hard stacks?
- Do these findings extend to transformer models with explicit bottlenecks (e.g., sparse attention, compressed embeddings)?
- Can the model predict which specific word orders are attested in natural languages, not just which constructions are rare?
- How does the inductive bias change with training data size, curriculum, or feedback signals (similar to RLHF)?
- Do stack-based models show the same bias when trained on natural language data with mixed typologies?

## Key Takeaway
Working memory constraints in neural networks may explain why human languages avoid complex nested patterns.
