# DoctorAgents: an agentic framework to iteratively refine AutoML pipeline for small clinical temporal data

**Authors:** Ruilin Wang, Bo-Hong Wang, Elizabeth Kourbatski, Jun Bai, Hegang Chen et al.
**Published:** 2026-08-05 | **arXiv:** [2608.05375v1](http://arxiv.org/abs/2608.05375v1)

## Summary
Clinical machine learning (ML) has the potential to support high-stakes medical decision-making, but reliable deployment is often constrained by scarce, heterogeneous, and temporal complexity. Developing effective ML pipelines for such data remains time-consuming and error-prone, while existing automated machine learning (AutoML) systems only partially address this challenge because they largely rely on brute-force search over predefined spaces and lack explicit reasoning and memory. We therefore reformulate AutoML for small clinical data from exhaustive search to reasoning-driven refinement.

## Theoretical Background
High-stakes predictive systems require traceable inputs, calibrated uncertainty, and evidence that results generalize beyond development data.

## Core Contributions
1. Developing effective ML pipelines for such data remains time-consuming and error-prone, while existing automated machine learning (AutoML) systems only partially address this challenge because they largely rely on brute-force search over predefined spaces and lack explicit reasoning and memory.
2. We therefore reformulate AutoML for small clinical data from exhaustive search to reasoning-driven refinement.
3. We propose DoctorAgents, an agentic AI framework that autonomously constructs and optimizes end-to-end ML pipelines through specialized large language model (LLM) agents for generation, validation, and refinement.
