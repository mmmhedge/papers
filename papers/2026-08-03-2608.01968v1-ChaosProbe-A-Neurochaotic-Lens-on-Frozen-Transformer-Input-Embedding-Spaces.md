# ChaosProbe: A Neurochaotic Lens on Frozen Transformer Input-Embedding Spaces

**Authors:** Kunal Kumar Pant, Nithin Nagaraj
**Published:** 2026-08-03 | **arXiv:** [2608.01968v1](http://arxiv.org/abs/2608.01968v1)

## Summary
This paper introduces ChaosProbe, a method for analyzing frozen transformer input-embedding spaces using deterministic chaotic dynamics. Rather than studying what transformers do (their outputs), the authors examine how embedding spaces respond to controlled deterministic probes, creating "fingerprints" that distinguish models. Testing on four pretrained models (GPT-2, BERT, RoBERTa), they show that these signatures reliably recover model family relationships, suggesting chaos-based analysis can reveal structural patterns in neural representations.

## Theoretical Background
Transformers process sequences through learned embeddings that map tokens to high-dimensional vectors, followed by attention mechanisms and contextual layers. Most transformer analysis focuses on downstream task performance or attention patterns; this work takes a different angle — examining the static structure of pre-trained embedding spaces before any contextual computation happens. Neurochaos theory uses tools from dynamical systems (trajectories, Lyapunov exponents, entropy measures) to study neural systems. The key insight here is treating an embedding matrix as input to a chaotic transformation, then measuring emergent properties like firing rates and Shannon entropy to create a model signature. This is inspired by how chaotic systems expose structure through their sensitivity to initial conditions and strange attractors.

## Core Contributions
1. **ChaosProbe framework**: A novel deterministic method combining chaotic trajectory-based transformations with response summaries (Firing Rate, Entropy) to generate fixed-length fingerprints of frozen embedding spaces — not learned via training, but derived from the static embedding matrix itself.
2. **Empirical validation on model families**: Demonstrates that Pearson/Spearman correlations of these signatures perfectly recover same-family nearest neighbors and mutual family relationships across four diverse pretrained models, with bootstrap resampling supporting stability.
3. **Response-based interpretability**: Shifts the interpretability lens from task behavior to intrinsic embedding space geometry, treating embeddings as "probes" that reveal latent structural properties.

## Connections to Other Work
This connects to [[mechanistic-interpretability]] efforts (e.g., work on understanding attention heads, probing tasks) but from an unconventional angle — using dynamical systems tools rather than causal intervention or linear probes. It aligns with the broader theme of analyzing [[transformers]] without fine-tuning, similar to studies of learned representations in deep networks. The neurochaos motivation borrows from neural dynamics literature but applies it to static embeddings in a novel way. Unlike [[RLHF]] or [[Attention Is All You Need]], this work does not improve model performance but rather diagnoses intrinsic structure — complementary to probing-based and representational similarity analysis work.

## Practical Applications
1. **Model quality assessment**: Quickly fingerprint pretrained models to detect whether they are genuine or corrupted copies without running full benchmarks.
2. **Transfer learning matching**: Automatically select which pretrained embedding space is best for a new task based on signature similarity rather than exhaustive fine-tuning.
3. **Model family clustering**: Organize growing model zoos by embedding space structure, helping practitioners find related models for ensemble or distillation work.
4. **Embedding space anomaly detection**: Monitor whether a model's embedding space drifts during continual training or deployment, flagging unexpected changes.
5. **Generalization diagnostics**: Use fingerprints as a lightweight proxy for downstream generalization or robustness without running full evaluation suites.

## Product & Startup Ideas
1. **Model Registry & Search**: A SaaS tool (like Hugging Face Model Hub enhancement) that pre-computes ChaosProbe signatures for all public models, letting users query "find models with embedding spaces similar to GPT-2" for faster transfer learning.
2. **Embedding Quality Dashboard**: B2B software for ML teams to continuously monitor their production transformer models' embedding spaces, alerting when signatures deviate (potential model corruption or drift).
3. **Automated Model Auditing**: A compliance/security service that uses ChaosProbe fingerprints to verify model authenticity and detect whether released checkpoints match claimed architectures/training.
4. **Transfer Learning Advisor**: A tool that recommends which pretrained model embedding space to use for a downstream task, based on signature similarity analysis and historical performance data.
5. **Embedding Space Visualization Platform**: Interactive web tool letting researchers explore embedding space structure via ChaosProbe signatures, enabling discovery of hidden model relationships and debugging representation collapse.

## Technical Limitations
1. **Proof-of-concept scope**: Only 80 neutral prompts and 4 models tested; no demonstration on larger model families, cross-lingual models, or models with very different architectures (e.g., MoE transformers).
2. **Prompt dependency**: Signatures depend on the specific prompts chosen; unclear how robust signatures are to diverse, naturalistic input distributions or adversarial prompts.
3. **Chaotic transformation design**: The choice of specific chaotic dynamics (e.g., which map, parameters) appears somewhat arbitrary; no systematic exploration of sensitivity to these hyperparameters.
4. **Comparison baseline missing**: No direct comparison to simpler alternatives (e.g., PCA, spectral clustering, or standard representational similarity metrics) — claims of advantage over existing methods are implicit.
5. **Scalability unstudied**: Computational cost and memory overhead of ChaosProbe on very large embedding dimensions (e.g., 100k+ token vocabularies) not addressed.
6. **Causality unestablished**: Correlating signatures with downstream task performance is not demonstrated; unclear whether fingerprints correlate with generalization, robustness, or other practically important properties.

## Open Questions
1. **Why does this work?** What property of embedding geometry does the chaotic transformation actually expose? Is it related to isotropy, spectral properties, or something else?
2. **Prompt invariance**: How do signatures change across different prompt types (code, math, instruction-following)? Are there universal signatures independent of prompt?
3. **Downstream correlation**: Do ChaosProbe signatures predict downstream task performance, transfer learning success, or adversarial robustness?
4. **Scaling behavior**: How do signatures change as model size grows? Can this detect model scaling laws or training dynamics?
5. **Architectural insights**: Can different chaotic transformations selectively highlight different embedding space properties (e.g., anisotropy vs. representation collapse)?
6. **Fine-tuned vs. frozen**: Do signatures of fine-tuned embeddings differ systematically from pretrained ones in interpretable ways?

## Key Takeaway
Chaotic dynamics reveal structural fingerprints in transformer embeddings that distinguish model families without training or task evaluation.
