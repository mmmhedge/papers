# RoMeRL: Balancing Feedback Coverage and the Memory-Reward Trap in Self-Evolving Agent Memory via Reduced-Order Utility States

**Authors:** Yi Yang, Zhennan Chen, Yihong Zhuang, Tiehan Fan, Yinan Chen et al.
**Published:** 2026-08-03 | **arXiv:** [2608.02508v1](http://arxiv.org/abs/2608.02508v1)

## Summary
This paper addresses a critical problem in self-evolving LLM agents: as agents interact with their environment, they accumulate memories, but feedback becomes increasingly sparse across an expanding state space, and irrelevant memories get corrupted by misdirected reward signals. RoMeRL solves this by representing memory utility using a fixed-dimensional space that gets updated over time rather than growing indefinitely, concentrating feedback and preventing bad memories from persisting. The approach yields substantial practical gains—6× denser feedback, 84% smaller memory, 21% fewer LLM calls—while improving task performance.

## Theoretical Background
This work builds on two foundations: reinforcement learning (RL) for agents, where agents learn policies by receiving rewards for actions, and LLM-based agents, which use large language models as decision-makers. A core challenge in RL is the sparse feedback problem—when rewards are rare, learning becomes inefficient. For memory-augmented LLM agents, this manifests as trajectory-indexed utilities: each interaction sequence accumulates a separate reward signal, but as history grows, each memory gets less feedback relative to the utility space's size. The paper also addresses "reward contamination," where multiple memories retrieved together receive a joint reward signal, causing irrelevant ones to learn spurious value estimates. Prior work on memory-augmented RL agents and curriculum learning inform the approach, though this paper's reduced-order framing is novel.

## Core Contributions
1. **Reduced-order parameterization**: Instead of maintaining utility estimates for every trajectory, RoMeRL represents agent memory using a fixed set of semantic coordinates (slots) that capture task-level memory patterns, factorized by outcome polarity (success vs. failure) and memory dynamics (how memory evolves).

2. **Theoretical analysis**: Proof that reduced-order states increase average feedback per coordinate and characterization of steady-state error rates under generic coordinate-transition models, bounding how long erroneous coordinates persist.

3. **Empirical validation across benchmarks**: Demonstrates 80% reduction in "Cold-Q ratio" (stale utility estimates), 6× feedback density increase, and 84% memory reduction on ALFWorld and LifelongAgentBench without sacrificing task performance.

## Connections to Other Work
RoMeRL relates to [[experience replay]] in RL (which also manages growing memory) but solves the distinctly harder problem of assigning credit correctly when multiple memories are co-retrieved. It shares conceptual roots with [[curriculum learning]] and [[memory-augmented neural networks]], but approaches memory compression differently—via semantic factorization rather than forgetting or prioritization. The reward contamination problem connects to multi-task RL's challenge of disentangling task-specific credit, and the fixed-dimensional reduction echoes techniques in [[representation learning]] that map high-dimensional spaces to lower-dimensional manifolds. The work implicitly addresses [[alignment]] concerns: reducing reward corruption helps prevent agents from learning misaligned behaviors rooted in contaminated memory.

## Practical Applications
1. **Long-horizon task automation**: Robotic process automation (RPA) systems that must learn from thousands of interaction episodes without memory bloat or corrupted experience.
2. **Web-agent assistance**: Browser-based AI agents (e.g., automated form-filling, data extraction) that must remember what worked across hundreds of prior tasks without polluting their memory.
3. **Interactive dialogue systems**: Conversational agents that improve over time but must distinguish useful prior conversations from misleading ones.
4. **Autonomous planning for embodied AI**: Household robots or warehouse automation that learns generalizable task strategies from repeated interactions without memory growing unbounded.

## Technical Limitations
1. **Assumption of outcome polarity**: The factorization assumes binary outcome categorization (success/failure), which may not capture nuanced task performance or partial credit scenarios.
2. **Fixed-dimensional bottleneck**: Choosing the right dimensionality for semantic coordinates requires tuning; too small and you lose expressiveness, too large and you lose compression.
3. **Generalization across domains**: The reduced-order parameterization is trained per task or task type; unclear how well semantic coordinates transfer across radically different domains.
4. **LLM as a black box**: The approach assumes the LLM's behavior is stable; it doesn't address drift in the underlying model or how to handle model updates/retraining.
5. **Evaluation scope**: Tested on ALFWorld (simulated household tasks) and LifelongAgentBench (multiple mini-tasks); real-world deployment on open-ended, non-episodic environments remains unvalidated.

## Open Questions
1. **How does the approach scale to truly long-horizon tasks (millions of interactions)?** Do semantic coordinates remain interpretable and stable, or does drift accumulate?
2. **Can the method extend to continuous or multi-valued reward signals** rather than binary success/failure?
3. **What is the relationship between coordinate dimensionality and task diversity?** Is there a principled way to choose it beyond empirical tuning?
4. **How does RoMeRL interact with other memory compression techniques** (e.g., summarization, semantic hashing) used in deployed LLM agents?
5. **Can we detect and correct coordinate drift online**, without retraining from scratch?
6. **Does the reduced-order factorization generalize to multi-agent settings** where agents share or learn from each other's memories?

## Key Takeaway
Fixed-size memory slots replace growing trajectories, concentrating feedback and eliminating corrupted memories from LLM agent learning.
