# Eliciting Intrinsic Hallucinations in LLMs via Semantically Equivalent Adversarial Attacks

**Authors:** Atri Vivek Sharma, Brian Formento, Alessio Lomuscio
**Published:** 2026-08-04 | **arXiv:** [2608.04286v1](http://arxiv.org/abs/2608.04286v1)

## Summary
Large language models (LLMs) are often used in conjunction with external knowledge sources to improve their factual accuracy and decrease hallucinations, through methods such as Retrieval-Augmented Generation (RAG). However, these systems remain susceptible to intrinsic hallucinations, where the model generates unfaithful or fabricated information that is not supported by the retrieved evidence. We propose a novel framework to assess model robustness against this phenomenon by stress-testing using natural, semantically equivalent variations of a user query found via adversarial optimization methods.

## Theoretical Background
Language systems must represent meaning, retrieve evidence, and follow task constraints. Evaluation should separate these capabilities rather than relying on one aggregate score.

The paper addresses the trade-off identified in its abstract through a targeted method, representation, or evaluation framework.

## Core Contributions
1. We propose a novel framework to assess model robustness against this phenomenon by stress-testing using natural, semantically equivalent variations of a user query found via adversarial optimization methods.
2. Evaluating these attacks on 5 open-source and 5 closed-source generator models across 3 datasets, we demonstrate that even state-of-the-art models are highly susceptible to meaning-preserving perturbations, which significantly degrade contextual faithfulness (by up to 50% for GPT-5-mini).
