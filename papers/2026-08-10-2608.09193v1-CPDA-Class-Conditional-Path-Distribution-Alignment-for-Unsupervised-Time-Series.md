# CPDA: Class-Conditional Path Distribution Alignment for Unsupervised Time-Series Domain Adaptation

**Authors:** Felix Ott, Christopher Mutschler
**Published:** 2026-08-10 | **arXiv:** [2608.09193v1](http://arxiv.org/abs/2608.09193v1)

## Summary
This paper proposes CPDA, a method for adapting time-series classifiers trained on labeled data from one source (e.g., one sensor) to work on unlabeled data from a different source (e.g., a different sensor or user). The key insight is to align not just overall feature distributions but class-specific temporal patterns between domains, using a specialized kernel that captures time structure and frequency information alongside semantic features.

## Theoretical Background
Domain adaptation addresses a fundamental machine learning problem: a classifier trained on labeled "source" data performs poorly on "target" data that comes from a different distribution. Existing unsupervised approaches (no target labels available) typically use adversarial training or optimal transport to match global feature distributions. Time-series domain adaptation is especially hard because shifts occur not just in data statistics but in temporal dynamics—the actual sequence patterns evolve differently across domains. This paper builds on kernel discrepancy methods (measures of distribution mismatch using kernel functions) and pseudo-labeling (using the model's own predictions to guide learning on unlabeled data). The signature-spectral kernel it proposes combines path signatures (a mathematical tool capturing temporal ordering and structure in sequences) with spectral methods (frequency-domain analysis) to create a richer representation of time-series dynamics.

## Core Contributions
1. **Class-conditional path distribution alignment**: Rather than matching all data together, CPDA aligns each class separately—ensuring that, say, "anomaly" sequences look similar between domains while "normal" sequences also align within their class.
2. **Composite signature-spectral kernel**: A novel kernel combining pooled semantic features, temporal path structure (via path signatures), frequency-domain information, and low-rank dynamics—capturing multiple views of time-series data simultaneously.
3. **Theoretical guarantees**: Formal proof that CPDA is a valid kernel discrepancy, encompasses existing moment-matching methods as special cases, and provides a class-conditional target risk bound (upper bound on future error on target domain).
4. **Comprehensive benchmark**: Extensive experiments across 13 time-series DA benchmarks with multiple neural architectures (CNN, ResNet18, temporal convolutional networks) against 30 baselines.

## Connections to Other Work
CPDA sits in the intersection of [[domain adaptation]] and time-series modeling. It moves beyond simple marginal distribution matching (used in adversarial methods like DANN) by adopting a class-conditional view similar to work in conditional domain adaptation. The use of pseudo-labels connects to self-training and co-training paradigms in semi-supervised learning. Path signatures are borrowed from mathematical finance and topological data analysis—relatively novel in deep learning for domain adaptation. The kernel discrepancy framework is classical in optimal transport and MMD (maximum mean discrepancy) literature but is less common in recent adversarial-dominated domain adaptation research, representing a partial return to principled discrepancy-based methods.

## Practical Applications
1. **Medical device sensors**: Transfer ECG or EEG classifiers across different sensor manufacturers or patient populations without retraining.
2. **Industrial IoT monitoring**: Adapt fault-detection models from one production line (labeled) to another (unlabeled) with different machinery or wear patterns.
3. **Mobile health apps**: Adapt activity recognition (walking, running, sitting) from training on one smartphone accelerometer to different devices without collecting new labels.
4. **Network intrusion detection**: Shift a traffic-classification model from one network segment (labeled normal/attack) to a new segment with different traffic patterns.
5. **Supply-chain anomaly detection**: Adapt time-series anomaly detectors across different warehouses or logistics networks without re-labeling.

## Product & Startup Ideas
1. **"SensorShift"**: A SaaS platform that automatically adapts machine-learning models trained on one IoT sensor fleet to work across different manufacturers/models in industrial predictive maintenance, eliminating per-device retraining.
2. **"MedicalDataTransfer"**: Software for hospitals/clinics to adapt diagnostic models (e.g., arrhythmia detection) across different ECG machines and patient demographics using unlabeled new-domain data.
3. **"WearableSync"**: A mobile-health analytics platform that adapts activity/sleep/heart-rate models across different wearables (Apple Watch, Fitbit, Garmin) without user re-calibration.
4. **"FinTS-Adapt"**: Financial time-series trading signal adapters that transfer models across different instruments, exchanges, or market regimes without retraining on new labeled data.
5. **"EdgeLearn"**: Consulting/software service helping manufacturers transfer ML models to new production lines or equipment with minimal labeled data collection, reducing deployment time from weeks to days.

## Technical Limitations
1. **Pseudo-label reliability**: The method depends on confident target pseudo-labels; poor initial predictions can compound errors during training, especially for imbalanced or complex classes.
2. **Kernel computation cost**: Signature-spectral kernels are computationally expensive for very long sequences (thousands of timesteps), potentially limiting real-time or streaming applications.
3. **Class-balance assumption**: Works best when class distributions are balanced between source and target; severe imbalance may break the class-conditional alignment.
4. **Domain-shift scope**: Designed for shifts in temporal dynamics and sensor characteristics, but may struggle if the underlying problem fundamentally changes (e.g., predicting a new outcome not present in source domain).
5. **Hyperparameter sensitivity**: The composite kernel mixes multiple components (semantic, spectral, signature, low-rank); tuning their relative weights may be data-dependent and non-trivial.
6. **Theory-practice gap**: The class-conditional risk bound is likely loose in practice and doesn't directly guide algorithm design; it is more of a post-hoc guarantee.

## Open Questions
1. **How does CPDA scale to very long sequences?** Can the signature-spectral kernel be approximated efficiently, or should a different path representation be used for streaming/real-time scenarios?
2. **Can class-conditional alignment harm minority classes?** If one class has fewer target samples, does aligning its distribution separately degrade performance due to noisy class-specific statistics?
3. **How to choose the balance between source labels and target pseudo-labels?** Is there an optimal weighting scheme, or does it require problem-specific tuning?
4. **Does CPDA work for partial domain adaptation** (source classes ⊉ target classes)? Current setup assumes same classes in both domains.
5. **How sensitive is the method to the choice of neural backbone?** Do different architectures (RNN, Transformer, TCN) benefit equally from the signature-spectral kernel?
6. **Can the method handle online/continual domain adaptation** where the target domain itself drifts over time?

## Key Takeaway
Aligning time-series classifiers across domains works better when matching class-specific temporal patterns, not just overall feature distributions.
