# On-Policy and Off-Policy Learning for Large Action Spaces

**Authors:** Imad Aouali
**Published:** 2026-07-30 | **arXiv:** [2607.28408v1](http://arxiv.org/abs/2607.28408v1)

## Summary
This thesis tackles policy learning when agents must choose from enormous action spaces—think recommendation systems or large-scale decision problems. It develops new methods for both on-policy learning (where an agent explores and learns by trial) and off-policy learning (where it learns from past logged interactions), addressing core challenges like inefficient exploration and high estimation variance that make large action spaces computationally and statistically hard.

## Theoretical Background
The work builds on **contextual bandits**, a foundational framework in sequential decision-making where an agent observes context, picks an action, and gets partial reward feedback. Traditional bandit algorithms assume small action spaces; this thesis extends theory to massive ones. Key prior concepts include:

- **Thompson sampling** — a Bayesian approach that samples action probabilities from posterior distributions to balance exploration and exploitation
- **Regret bounds** — guarantees on cumulative suboptimality compared to an oracle (the standard metric for on-policy learning)
- **Off-policy learning** — inferring optimal policies from historical logged data (common in recommendation systems and medical trials where exploration is costly)
- **Importance weighting** — reweighting logged data to estimate counterfactual outcomes under a new policy; high-variance in sparse settings
- **Extrapolation bias** — when a learned policy assigns high probability to actions rarely seen in historical logs, leading to unreliable estimates

## Core Contributions

1. **meTS (mixed-effect Thompson sampling)** — A structured Bayesian method that shares information across actions via hierarchical priors, enabling better exploration with regret that scales with an *effective* action space size rather than literal cardinality.

2. **dTS (diffusion-based Thompson sampling)** — Uses diffusion-inspired priors to model dependencies between actions, capturing structure (e.g., similarity between items in recommendations) to further reduce effective complexity.

3. **sDM (structured direct method)** — An off-policy approach using latent variable models to compress and denoise action representations, reducing both estimation and optimization error.

4. **Pessimistic importance-sampling estimators** — Theoretically grounded regularization schemes (via exponential smoothing and PAC-Bayesian bounds) that control the bias-variance tradeoff when re-weighting sparse logged feedback.

5. **Optimization-error analysis** — Novel insight that in large action spaces, the difficulty of optimizing the policy landscape can dominate statistical estimation error—pointing to where methods must focus.

## Connections to Other Work
This thesis sits in the intersection of bandit theory (which focuses on exploration-exploitation) and offline reinforcement learning ([[Off-Policy Reinforcement Learning]]). It extends classical results like [[Regret Bounds for Bandits]] to structured, high-dimensional settings. The pessimistic methods echo recent progress in uncertainty quantification for offline RL (e.g., [[Pessimism]] in contextual bandits). The use of latent representations connects to [[Dimensionality Reduction]] and **representation learning** in RL—the idea that rich structure (dependencies between actions) can be exploited to reduce complexity.

## Practical Applications

1. **Recommendation systems** — E-commerce platforms (e.g., Amazon, Netflix) must rank from millions of items; meTS and dTS enable efficient learning from user interactions.

2. **Ad targeting** — Digital advertising platforms (Google Ads, Meta) select from vast ad inventories; off-policy methods allow learning from logged campaign data without re-running expensive experiments.

3. **Clinical trial optimization** — Hospitals adapt treatments across large drug/dosage spaces; pessimistic off-policy methods safely infer best treatments from historical patient records.

4. **Search ranking** — Search engines optimize relevance scores across billions of documents; structured methods exploit similarity structure between queries/results.

5. **Content moderation** — Platforms must choose from many intervention actions (remove, flag, reduce reach, etc.) for each piece of content; on-policy contextual bandits enable fast adaptation.

## Product & Startup Ideas

1. **Bandit-as-a-Service platform** — SaaS offering plug-and-play Thompson sampling and structured bandit algorithms for e-commerce and SaaS companies optimizing conversion on large choice sets (e.g., pricing, product selection).

2. **Offline learning optimization tool** — Enterprise software that teaches data teams how to safely extract value from logged interaction data using pessimistic methods—reducing exploration cost for B2B SaaS feature recommendations.

3. **Clinical trial design consultant** — AI consulting firm helping biotech and pharma firms design and analyze adaptive trials with large treatment spaces (drug combinations, dosages) using principled off-policy methods.

4. **Recommendation engine for niche marketplaces** — Startup building a real-time recommendation API for mid-market e-commerce and content platforms; uses structured Bayesian methods to compete with large tech stacks despite smaller data.

5. **Ad exchange optimization** — Proprietary trading/arbitrage system for digital advertising that learns optimal bid/placement strategies from auction logs using off-policy learning with exponential-smoothing regularization.

## Technical Limitations

- **Assumption of action structure** — meTS and dTS assume meaningful dependencies or groupings exist; they degrade gracefully if actions are truly independent, but may waste modeling capacity.
- **Latent variable learning (sDM)** — Requires sufficient data to learn good latent representations; can fail in ultra-sparse regimes or when structure is subtle.
- **Optimization landscape** — The thesis identifies that optimization is hard but doesn't fully characterize *when* and *why* (e.g., which problem instances have benign vs. pathological landscapes).
- **Contextual bandit scope** — Only addresses partial feedback (one action per round); doesn't handle full-information settings or multiple simultaneous actions (common in real systems).
- **Scaling** — Theoretical guarantees and algorithmic complexity (sampling, inference) may not hold for action spaces of billions+ (e.g., full web scale).
- **Logged data quality** — Off-policy methods assume the logging policy is known and the data is unbiased; real logs often have selection bias, missing data, and unknown policies.

## Open Questions

1. **Tight optimization-error characterization** — Can we fully characterize which problem structures admit polynomial-time optimization and which don't? Does structure (e.g., low-rank action similarities) make optimization tractable?

2. **Hybrid on/off-policy learning** — Can we combine logged data with selective exploration to improve sample efficiency beyond pure off-policy or pure on-policy?

3. **Adaptive structure discovery** — In meTS/dTS, can the algorithm *learn* which action groupings or dependencies matter, rather than assuming structure is given?

4. **Nonstationary environments** — Real systems have drifting user preferences and action distributions; how do these methods degrade and how can we adapt them?

5. **Empirical benchmarking** — How do these methods compare on large-scale industrial datasets (e.g., real recommendation logs) against simpler baselines and practitioners' current methods?

6. **High-dimensional context** — The thesis focuses on large action spaces; what happens when both context and action spaces are high-dimensional?

## Key Takeaway
Large action spaces demand new learning algorithms that exploit structure and control variance; this thesis develops Bayesian and pessimistic methods for both exploration and offline learning.
