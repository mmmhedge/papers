# Efficient Online LLM Watermark Detection via Rao-Blackwellized E-Processes

**Authors:** Lu Luo, Dandan Mo, Chengdong Xu, Ting Li, Jinhan Xie et al.
**Published:** 2026-07-24 | **arXiv:** [2607.21958v1](http://arxiv.org/abs/2607.21958v1)

## Summary
This paper presents a method to detect whether text was generated by an LLM or written by humans, using a statistical technique called watermarking. The key innovation is enabling this detection to work *online* — meaning you can make a decision as soon as enough evidence accumulates, rather than waiting until text generation is complete. This matters because it's faster, uses less memory, and provides mathematically guaranteed accuracy.

## Theoretical Background
The paper builds on **statistical watermarking** for LLMs — the idea of subtly altering how an LLM generates text so that AI-generated output has a detectable statistical signature. Prior work used fixed-horizon testing (you decide upfront how much text to check), which is inefficient for streaming generation.

This paper applies **Rao-Blackwellized e-processes**, a statistical tool from sequential testing theory. E-processes generalize hypothesis testing to allow *anytime-valid inference* — you can stop and make a decision at any time while maintaining statistical guarantees (like Type I error control — the probability of falsely claiming text is AI-generated). The authors instantiate this for the **Gumbel-max watermark**, a specific watermarking scheme that modulates token probabilities in a detectable way.

The core mathematical problem reduces to **sequential hypothesis testing with a known null distribution**, which e-processes handle elegantly.

## Core Contributions
1. **Anytime-valid online detection framework**: Unlike prior work, the method allows early stopping with rigorous statistical guarantees — you don't need to wait for the full text or pre-specify a sample size.

2. **Rao-Blackwellized implementation**: Uses variance reduction to make token-level evidence updates efficient without storing full history, reducing memory overhead.

3. **Explicit reduction for Gumbel-max**: Converts token-level dependence testing into a pivot-induced sequential testing problem with a closed-form null distribution.

4. **Theoretical guarantees**: Proves Type I error control under *arbitrary optional stopping* (not just pre-planned stopping times) and establishes asymptotic consistency.

5. **Empirical validation**: Demonstrates the method works on real LLM-generated text with efficiency gains.

## Practical Applications
1. **Content moderation platforms**: Automatically flag AI-generated text submissions in real-time (e.g., on forums, comment sections, academic integrity systems) with early stopping to save computation.

2. **Search engines & news aggregators**: Tag or down-rank AI-generated content in search results or feeds while maintaining user trust through rigorous false-positive guarantees.

3. **Journalism & publishing**: Help editorial teams quickly identify AI-assisted or auto-generated articles before publication.

4. **Social media**: Stream-based detection of bot-generated posts or responses at scale.

5. **Educational assessment**: Monitor student submissions for AI assistance without slowing down grading pipelines.

## Technical Limitations
1. **Requires watermarking at generation time**: The method only detects text if the LLM was *specifically designed* to watermark. It cannot retroactively detect non-watermarked AI text.

2. **Watermark robustness not addressed**: The paper assumes watermarks survive transmission; truncation, paraphrasing, or adversarial attacks could degrade detection. No formal analysis of watermark robustness is provided.

3. **Language & model generalization**: Experiments focus on specific LLMs and English text. Effectiveness across languages, fine-tuned models, or multi-modal LLMs is unclear.

4. **Human-written text baseline**: The paper doesn't deeply explore false-positive rates when testing legitimate human text that statistically resembles the watermark signature by chance.

5. **Computational cost of online updates**: While memory-efficient, the per-token computational overhead of Rao-Blackwellized updates in production systems isn't fully characterized.

6. **Assumption of independence**: The pivot-based reduction assumes certain statistical independence properties that may not hold in highly correlated or adversarially manipulated text.

## Open Questions
1. How robust is the watermark and detection scheme to **adversarial perturbations** (e.g., synonym substitution, paraphrasing) or obfuscation attacks?

2. Can the framework be extended to **multilingual** or **code-generation** domains? Do error guarantees degrade?

3. What is the **computational overhead** in deployed systems, and how does it scale with vocabulary size or model dimension?

4. How does the method perform when the LLM's watermarking parameters are **partially compromised** or slightly misspecified at detection time?

5. Can the e-process framework be combined with **other detection signals** (entropy, n-gram patterns, semantic inconsistencies) to improve accuracy and robustness?

6. Does the anytime-valid stopping rule provide **practical speedups** (fewer tokens needed) compared to fixed-horizon methods in real streaming scenarios?

## Key Takeaway
Real-time detection of AI text is now possible with mathematical guarantees and zero memory overhead.
