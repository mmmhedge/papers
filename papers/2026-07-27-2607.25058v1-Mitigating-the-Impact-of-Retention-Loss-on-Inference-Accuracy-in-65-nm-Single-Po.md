# Mitigating the Impact of Retention Loss on Inference Accuracy in 65 nm Single-Poly Floating-Gate Analog In-Memory Computing

**Authors:** Mirko Brazzini, Giulio Filippeschi, Alessandro Catania, Sebastiano Strangio, Giuseppe Iannaccone
**Published:** 2026-07-27 | **arXiv:** [2607.25058v1](http://arxiv.org/abs/2607.25058v1)

## Summary
This paper addresses a critical hardware challenge in analog in-memory computing: floating-gate memory cells gradually lose charge over time (retention loss), degrading neural network inference accuracy. The authors demonstrate that combining circuit-level compensation techniques with algorithmic recalibration (batch normalization) can recover baseline accuracy even 60 days after programming, making analog memory viable for practical AI inference at the edge.

## Theoretical Background
Analog in-memory computing processes neural network operations directly in memory arrays, avoiding expensive data movement between compute and storage — a major power bottleneck in digital systems. This approach uses floating-gate (FG) transistors — non-volatile memory cells that store charge to represent analog weights. However, FG cells suffer from retention loss: stored charge leaks over time, causing weight drift and inference errors. Prior work has shown that batch normalization — a technique that rescales neural network activations to have unit mean and variance — can adapt to small distribution shifts. The paper extends this idea to hardware-induced weight drift.

## Core Contributions
1. **Experimental validation** of a hybrid mitigation strategy combining circuit-level compensation (likely refresh or offset techniques) with algorithmic recalibration on real 65 nm CMOS silicon.
2. **Retention-loss characterization model** calibrated from silicon experiments and used to predict system-level impact on real networks (VGG-10, WideResNet-28-10).
3. **Quantitative recovery benchmark**: demonstrates 2-4% accuracy loss recovery after 60 days using combined techniques — a concrete timeline for practical deployment.
4. First demonstration that this dual approach is sufficient to make single-poly floating-gate analog memory competitive for long-term inference workloads.

## Connections to Other Work
This relates to broader efforts in [[analog computing]], [[in-memory computing]], and hardware-software codesign for neural networks. It builds on prior work in weight quantization and [[batch normalization]] as an error-correction mechanism. Similar retention challenges appear in other non-volatile memory technologies (RRAM, PCM, flash), making this a template for mitigation across analog AI accelerators.

## Practical Applications
- **Edge AI inference on IoT devices**: long-lived sensors that perform on-device ML without frequent reprogramming.
- **Autonomous vehicles**: analog memory arrays in automotive edge processors that maintain accuracy over vehicle lifetime without retraining.
- **Medical implants**: closed-loop neural network inference (e.g., seizure detection) in implanted devices that cannot be easily updated.
- **Satellite and space systems**: radiation-hardened analog memory for inference in environments where frequent power cycles or updates are impractical.

## Technical Limitations
- **Limited to specific architectures**: only validated on CNNs (VGG, ResNet); unclear if the approach generalizes to transformers or vision transformers commonly used in modern inference.
- **Retention model calibration required**: the mitigation depends on an accurate statistical model of charge leakage, which varies with process variation and temperature — needs re-characterization per chip/fab.
- **Batch norm dependency**: assumes networks use batch normalization; older or custom architectures without it may require additional algorithmic changes.
- **Temperature sensitivity not explored**: retention loss rate is highly temperature-dependent; the 60-day benchmark may not hold across all operating conditions.
- **Single technology node**: tested only on 65 nm CMOS; scaling to 28 nm or 5 nm, where leakage mechanisms differ, is unvalidated.
- **Refresh overhead not quantified**: circuit-level compensation likely consumes additional power or latency; energy/throughput trade-offs not discussed.

## Open Questions
1. Does this approach work on modern architectures like ResNets-50+, Vision Transformers, or other non-CNN models?
2. What is the power and latency cost of circuit-level compensation, and how does it scale with memory array size?
3. Can you predict and preemptively recalibrate batch norm statistics without degrading inference, or must you collect new calibration data offline?
4. How does retention loss interact with process variations, temperature gradients, and analog noise in real deployments?
5. What happens beyond 60 days — does accuracy continue to degrade linearly, or does it plateau?

## Key Takeaway
Combining hardware compensation and batch norm retraining recovers neural network accuracy on leaky analog memory for months—enabling practical edge AI.
