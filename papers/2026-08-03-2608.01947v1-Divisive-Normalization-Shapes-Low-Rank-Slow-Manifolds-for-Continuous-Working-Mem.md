# Divisive Normalization Shapes Low-Rank Slow Manifolds for Continuous Working Memory

**Authors:** Zhaotian Gu, Jie Su, Weiwei Wang, Chang Liu, Tianyi Qian et al.
**Published:** 2026-08-03 | **arXiv:** [2608.01947v1](http://arxiv.org/abs/2608.01947v1)

## Summary
This paper shows that divisive normalization — a computation found in biological brains — helps recurrent neural networks learn stable, continuous memories that can change over time. Standard RNNs fail at this task, either becoming too fragile or collapsing into discrete states; the authors prove mathematically and empirically that divisive normalization prevents this failure and naturally keeps the network's effective complexity low.

## Theoretical Background
Working memory tasks require neural networks to robustly maintain and update continuous variables (e.g., position, angle) over time. Classical continuous attractor networks — systems that settle into smooth, connected solution spaces — suffer from extreme sensitivity to parameter changes; tiny weight adjustments break the solution entirely. Standard RNNs like GRUs and LSTMs, despite their empirical success, typically fail to learn true continuous manifolds (smooth, low-dimensional surfaces in high-dimensional state spaces) and instead discretize the state space into isolated point attractors. Divisive normalization is a biological neural computation where one neuron's activity is divided by a pooled measure of background activity; it is ubiquitous in cortical circuits but its computational function remains poorly understood. Backpropagation Through Time (BPTT) is the standard training algorithm for RNNs, unfolding the recurrent computation across time steps.

## Core Contributions
1. **RDNN architecture**: A minimal recurrent model incorporating divisive normalization as a core dynamical constraint, designed to probe its computational role in isolation.

2. **Dynamical systems proof**: Rigorous analysis showing that divisive normalization enables RNNs to converge to robust, high-fidelity slow manifolds on canonical working memory tasks (tasks where the network must track continuous values over time).

3. **Gradient dynamics insight**: Demonstration that divisive normalization during BPTT induces activity-dependent local gradient scaling that naturally dampens parameter updates when neurons are highly active, avoiding explicit low-rank regularization yet achieving emergent low-rank structure.

4. **Mechanistic necessity**: Ablation evidence that subtractive inhibition (subtraction of a baseline) alone maintains static memories, but divisive normalization is mathematically essential to prevent manifold shattering under time-varying inputs.

5. **Self-compression phenomenon**: Empirical observation that the network's effective rank compresses significantly, confining recurrent dynamics to a tight, low-dimensional subspace without the optimization pitfalls of hard low-rank factorization.

## Practical Applications
1. **Robotic control**: Systems that must track continuous joint angles or positions in real-time benefit from stable, continuously-deformable state representations; RDNN could improve sample efficiency and robustness.

2. **Signal processing**: Audio or sensor data that requires maintaining continuous latent variables (pitch, frequency, trend) over long windows.

3. **Neuroscience simulation**: Building accurate, minimal computational models of cortical circuits for closed-loop brain–computer interfaces or predictive neuroscience.

4. **Time-series forecasting**: Financial or climate data where smooth, non-discretized state evolution is crucial; the low-rank structure could reduce overfitting.

5. **Robotics learning**: Training agents that integrate proprioceptive feedback into continuously-variable working memory without discretization artifacts.

## Technical Limitations
1. **Scalability unclear**: Analysis focuses on canonical toy tasks (e.g., sine-wave tracking); performance on high-dimensional, realistic working memory tasks (large images, complex temporal sequences) is not demonstrated.

2. **Biological plausibility trade-off**: Divisive normalization is biologically plausible but may not scale or compete with standard RNNs on large benchmarks; no direct comparison to state-of-the-art LSTMs or transformers on real datasets.

3. **Hyperparameter sensitivity**: The paper does not thoroughly explore sensitivity to divisive normalization parameters or architectural variants; optimal configurations may remain task-dependent.

4. **Discrete vs. continuous**: While the paper claims to prevent manifold shattering, it is unclear whether true continuous manifolds emerge or whether the network achieves a fine-grained discretization that is indistinguishable in practice.

5. **Generalization**: All analyses use relatively simple synthetic tasks; generalization to realistic working memory tasks (e.g., n-back, context-dependent reasoning) is unverified.

6. **Comparison fairness**: No direct side-by-side comparison of RDNN vs. carefully tuned LSTM/GRU baselines on the same tasks under identical optimization conditions.

## Open Questions
1. Does RDNN scale to high-dimensional inputs and outputs? How does it perform on ImageNet-scale vision tasks or language modeling?

2. Can divisive normalization be incorporated into modern architectures (transformers, state-space models) and, if so, do similar low-rank properties emerge?

3. What is the relationship between the emergent low-rank structure and the implicit regularization of BPTT? Can this be formalized as a limiting theorem?

4. Can RDNN learn multiple orthogonal continuous manifolds simultaneously (e.g., separate memories for position and velocity)?

5. How does the learning dynamics change with network width, depth, and divisive normalization strength? Is there a phase transition?

6. Does RDNN exhibit better generalization or transfer learning compared to standard RNNs on a distribution shift?

7. Can neurophysiological recordings validate that biological circuits implement RDNN-like computations during working memory tasks?

## Key Takeaway
Divisive normalization, a brain computation, naturally makes RNNs learn stable, continuous memories without discretization and without explicit low-rank penalties.
