# Continuous-Time Reinforcement Learning for Controlled Hawkes Jump-Diffusions

**Authors:** Tomasz R. Bielecki, Thibaut Mastrolia, Haoze Yan
**Published:** 2026-08-19 | **arXiv:** [2608.19151v1](http://arxiv.org/abs/2608.19151v1)

## Summary
This paper develops a machine learning method to control complex financial systems (Hawkes jump-diffusions) that have memory effects and don't fit standard control theory. The key innovation is "Markovianizing" non-Markovian processes — converting them into simpler forms that RL algorithms can handle — then using continuous-time policy gradients to find optimal control strategies. This matters because many real financial phenomena (like market microstructure and event clustering) are naturally described by Hawkes processes, but controlling them has been mathematically intractable.

## Theoretical Background
Classical stochastic control theory (optimal control of systems with randomness) assumes Markovian dynamics — the future depends only on the present state, not history. **Hawkes processes** are self-exciting point processes where the intensity (likelihood of an event) depends on all past event times, creating memory. This path dependence breaks the Markovian assumption. **Jump-diffusions** are continuous-time stochastic systems with both smooth diffusive components and discrete jumps. The paper builds on [[DDPG]] (a continuous-time policy gradient RL algorithm) and approximation theory for converting non-Markovian systems into Markovian ones using exponential basis expansions. The mathematical foundation rests on convergence proofs for these approximations and value function convergence in stochastic control.

## Core Contributions
1. **Markovianization algorithm**: A finite-dimensional procedure that approximates arbitrary Hawkes kernels using mixtures of exponential kernels, with convergence guarantees for the process, its intensity, and the optimal control value.
2. **Hawkes-CT DDPG**: A continuous-time deterministic policy gradient algorithm adapted to work on the Markovianized approximation of Hawkes-driven systems.
3. **Model-free learning with unknown kernels**: An algorithm that learns optimal control observing only event times, SDE realizations, and decay filters — without knowing the true Hawkes kernel coefficients.
4. **Empirical comparison**: Testing across three kernel types (exponential, Erlang, power-law) against discrete-time RL baselines.

## Connections to Other Work
This paper bridges **stochastic control** (classical optimal control under uncertainty) and **deep reinforcement learning** (model-free policy optimization). It extends [[DDPG]] from standard diffusions to non-Markovian settings, similar in spirit to how [[attention mechanisms]] capture temporal dependencies in neural networks. The Markovianization technique relates to **basis function approximations** in control theory and **sufficient statistics** in filtering. It addresses limitations of prior work that either assumed Markovian kernels or used discrete-time approximations that lose efficiency in continuous-time systems.

## Practical Applications
- **High-frequency trading**: Optimize order placement and cancellation strategies in markets where event clustering (order arrivals) is self-exciting.
- **Market making**: Control inventory and spreads in a Hawkes-driven order flow to manage adverse selection risk.
- **Credit portfolio management**: Optimize hedging strategies when defaults cluster in time (defaults drive higher intensity of further defaults).
- **Execution algorithms**: Minimize market impact and slippage when order flow itself is self-exciting and depends on past trades.
- **Liquidity management**: Dynamically adjust positions when trading intensity responds to recent market events in a path-dependent way.

## Product & Startup Ideas
1. **"HawkesAI" — AI trading infrastructure**: SaaS platform offering Hawkes-calibrated execution algorithms for institutional traders, leveraging this model-free learning approach to adapt to changing market microstructure.
2. **Risk dashboard for self-exciting markets**: Real-time risk monitoring that learns optimal hedging strategies in clusters of market events, sold to hedge funds and asset managers.
3. **Credit event forecasting and management**: Software that models correlated default risk using Hawkes intensity estimation and recommends portfolio hedges via learned control policies.
4. **Market microstructure consulting service**: Data + ML service that profiles a client's market (kernel type, clustering behavior) and generates custom execution policies without requiring kernel specification upfront.
5. **Institutional smart order router**: Next-gen router that uses continuous-time RL to dynamically split and time orders across venues in response to Hawkes-driven order flow patterns on each venue.

## Technical Limitations
- **Curse of dimensionality**: Multivariate Hawkes processes scale poorly; the Markovianization requires choosing the number of exponential basis functions, which grows with dimension and desired accuracy.
- **Kernel approximation error**: Power-law and other non-exponential kernels may require many exponential terms for good approximation; convergence rates are not characterized.
- **Model-free assumption**: While the algorithm doesn't need the kernel analytically, it still observes decay filters — in practice, choosing which filters to use requires domain knowledge.
- **Exploration in continuous time**: The policy gradient algorithm must explore in a continuous-action space; exploration efficiency and convergence rates are not analyzed.
- **Assumption of observability**: Assumes clean observations of event times and SDE realizations; in reality, market data is discrete-time and noisy.
- **No discussion of computational complexity**: Wall-clock time for training and deployment not addressed.

## Open Questions
1. What are the finite-sample convergence rates for Hawkes-CT DDPG? How does approximation error propagate through RL learning?
2. How sensitive is the algorithm to the choice and number of decay filters? Can we learn optimal filter selection?
3. How does this method perform in high dimensions (e.g., order books with 10+ asset classes)?
4. Can this framework extend to **partially observable** settings where the true Hawkes intensity is latent?
5. What is the sample complexity compared to discrete-time methods in wall-clock time?
6. Does this generalize beyond Hawkes processes to other non-Markovian point process models?

## Key Takeaway
Machine learning can now optimize strategies in non-Markovian financial systems by first converting them to Markovian approximations, then applying continuous-time policy gradients.
