# Fast Learning Rate Transfer in Shallow Linear Networks at Growing Training Horizons

**Authors:** Mana Sakai, Masaaki Imaizumi
**Published:** 2026-09-28 | **arXiv:** [2609.35029v1](http://arxiv.org/abs/2609.35029v1)

## Summary
This paper studies how learning-rate hyperparameters can be efficiently transferred across neural networks of different widths when training time also grows. The authors prove that for shallow linear networks trained with gradient descent, fast transfer is possible under specific spectral conditions—specifically when training steps grow slower than the square root of network width. This matters because hyperparameter tuning is expensive for large models; understanding when transfer works helps practitioners avoid redundant tuning.

## Theoretical Background
The paper builds on **fast hyperparameter transfer** (Ghosh et al., 2026), a framework that characterizes when hyperparameter settings from smaller models generalize to larger ones. It analyzes this in the setting of shallow linear networks—neural networks with one hidden layer where weights are linear in the inputs—trained with **full-batch gradient descent**, which updates parameters using all training data at once. A key analytical tool is the **data Gram matrix** (the matrix of all pairwise inner products of training examples), whose eigenvalues govern optimization dynamics. The authors extend prior transfer results to a "growing-horizon" regime where both model width *n* and training time *T* increase together, requiring new mathematical treatment of how these two dimensions interact.

## Core Contributions
1. **Main transfer result**: Proves that fast learning-rate transfer holds when $T = o(\sqrt{n})$ (training steps grow slower than the square root of width), with explicit convergence rates.
2. **Characterization of transfer rates**: Shows that transfer speed depends on three interpretable quantities—the finite-width perturbation scale (how much adding width changes the loss), first-order sensitivities of loss and its gradient with respect to width, and local loss curvature.
3. **Limiting distributions**: Derives asymptotic distributions for optimal learning rates and optimized losses, driven by fluctuations of extreme eigenvalues of the data Gram matrix, revealing how spectral structure governs transfer.

## Connections to Other Work
This extends [[fast hyperparameter transfer]] to a previously unanalyzed regime. It complements existing work on [[neural scaling laws]] and [[implicit regularization in gradient descent]], which study how neural network behavior changes with width and training time separately. The spectral analysis connects to classical results on random matrix theory and eigenvalue behavior in learning, similar to techniques used in [[kernel methods]] analysis. The growing-horizon setting is distinct from fixed-training regimes and more relevant to modern deep learning where both model and training budget scale together.

## Practical Applications
- **AutoML systems**: Reduce tuning cost when scaling models by reusing learning rates from smaller experiments.
- **Transfer learning pipelines**: Initialize learning rates for larger fine-tuned models based on smaller pre-trained versions.
- **Resource-constrained settings**: Practitioners with limited compute can validate hyperparameters on small models, then confidently scale up.
- **Distributed training**: Help select learning rates when parallelizing across more workers (analogous to width scaling in communication cost).

## Product & Startup Ideas
1. **Hyperparameter transfer service**: Cloud API that predicts optimal learning rates for scaled models given a small reference run, charging per prediction.
2. **AutoML optimization layer**: Integrate into MLflow/Weights & Biases to auto-suggest learning rates when users scale model width, reducing tuning overhead.
3. **Neural architecture search accelerator**: Use transfer principles to prune the hyperparameter search space during NAS, speeding up full-width model training.
4. **Open-source tuning library**: Easy-to-use Python package implementing transfer formulas for practitioners training linear networks and shallow architectures.
5. **Consulting service for large-model teams**: Advise enterprises on which learning rates to inherit when scaling proprietary models, backed by this theory.

## Technical Limitations
- **Shallow linear networks only**: Results apply to a single trainable hidden matrix; they don't directly extend to deep networks or nonlinear activations, which are ubiquitous in practice.
- **Spectral assumptions**: The main results require additional spectral conditions on the data Gram matrix; clarity on how restrictive these are (e.g., what fraction of real datasets satisfy them) is absent.
- **Full-batch gradient descent**: Analysis assumes all training data is used per step; stochastic gradient descent (mini-batch), which dominates modern practice, is not covered.
- **Growing-horizon constraint**: Transfer works only if $T = o(\sqrt{n})$; for larger $T$ the theory breaks down, leaving a gap for practitioners training very long.
- **No nonconvexity**: Linear networks have convex loss; behavior in nonconvex deep learning may differ fundamentally.

## Open Questions
- Does the $T = o(\sqrt{n})$ threshold hold for nonlinear shallow networks (e.g., ReLU networks)?
- How do the spectral assumptions relate to properties of real data (e.g., rank, conditioning, signal-to-noise)?
- Can the theory extend to stochastic gradient descent with decay schedules, which is how learning rates are used in practice?
- Do similar transfer principles apply to other hyperparameters (momentum, weight decay) or only learning rates?
- What happens in the regime $T = \Theta(\sqrt{n})$ or $T = \omega(\sqrt{n})$ where fast transfer may fail—how degraded is transfer there?

## Key Takeaway
Learning rates can be safely reused across wider networks if training time grows slower than the square root of model width.
